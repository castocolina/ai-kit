## The splicer contract (Tasks 1 and 2 implement it exactly)

Module `skills/ai-kit-spec-review/ai_kit_spec/toml_splice.py`, stdlib only, imports `copy`, `tomllib`, `typing.NamedTuple`, and `from ai_kit_spec.config_io import ConfigError, _toml_value, cfg_parse_toml_bytes`. Never reuse `tools/setup.py` `_KEY_RE` (it reads a `#` inside a quoted value as a comment start).

- Constants: `OWNED_TOP = ("strategy",)`; `OWNED_POLICY = ("mode", "ladder", "timeout_tiers")`; `OWNED_REVIEWER = ("key", "model", "vendor", "runtime", "command", "purpose", "is_router", "fallback_quota", "effort", "service_tier", "cursor_mode", "task_affinity", "context_limit", "timeout_tiers", "strength", "cli", "native_runtime", "route")`. In one table, the keys this writer may change are the owned keys plus every key of the new table; any other key is unknown and is never touched. A dict value (`extra = { ... }`, a `[reviewers.extra]` sub-table) is never owned.
- `class Stmt(NamedTuple)`: `kind` (one of `"blank"`, `"comment"`, `"table"`, `"array"`, `"key"`), `name` (header name without brackets and surrounding spaces, or the key text before `=` stripped of spaces and of one pair of surrounding `"` or `'`; `""` for blank and comment), `start`, `end` (offset just after the statement's line ending, or `len(text)`), `value_start`, `value_end` (key statements only; `-1` otherwise).
- `class Doc(NamedTuple)`: `text`, `stmts`, `nl` (`"\r\n"` when the old text contains `"\r\n"`, else `"\n"`).
- `scan(text) -> list[Stmt]`: walks logical lines. A whitespace-only line is `blank`; a line whose first non-space character is `#` is `comment`; `[[` starts an `array` header and `[` a `table` header (name up to `]]` / `]`); anything else is a `key` statement: the key ends at the first `=` outside quotes, `value_start` is the first non-space character after `=`, `value_end` comes from `_value_end`, and the statement runs on to its line ending (trailing spaces and an optional `# comment` belong to the statement).
- `_value_end(text, i) -> int`: `"""` or `'''` at `i` ends after the matching triple; `"` ends after the next unescaped `"` (a backslash escapes the next character); `'` ends after the next `'`; `[` or `{` ends after the matching close, counting `[ {` and `] }` while skipping strings of every kind and `#` comments to their line end; anything else ends at the first `#`, `\n` or `\r`, with trailing spaces and tabs not counted. No end found raises `ValueError("unterminated value")`.
- `class Block(NamedTuple)`: `kind` (`"preamble"`, `"table"`, `"array"`), `name`, `first`, `last` (statement indices, `last` exclusive). `blocks(stmts) -> list[Block]`: a block starts at its header statement, or at the first statement of the unbroken run of `comment` statements directly above the header (no `blank` between that run and the header); the preamble is every statement before the first block start (it may be empty). An `array` block named `reviewers` together with the directly following `table` blocks whose name starts with `reviewers.` is one roster entry.
- `intended(old: dict, new: dict) -> dict`: a deep copy of `old` where (a) each `OWNED_TOP` key takes `new`'s value or is removed when absent from `new`; (b) when `"policy"` is in `old` or `new`: the policy becomes old's policy minus each `OWNED_POLICY` key absent from new's policy, updated with new's policy; (c) `reviewers` becomes, for each new entry in order, the old entry with the same `key` minus every owned or new key, updated with the new entry (an entry with no old match is the new entry); an empty list removes the `reviewers` key. Every other top-level key of `old` stays.
- `_edit_span(doc, first, last, tables, owned) -> str`: the text of statements `first..last-1` with key edits applied, where `tables = (old_table, new_table)`. For each `key` statement whose name is owned or in `new_table`: when the name is in `new_table` and `old_table.get(name) != new_table[name]`, the text from `value_start` to `value_end` becomes `_toml_value(new_table[name])` (everything else on the line, the trailing comment included, stays); when the name is owned and not in `new_table`, the whole statement text from `start` to `end` is dropped. Keys of `new_table` with no statement are appended as `f"{key} = {_toml_value(value)}{doc.nl}"`, in `new_table` order, right after the end of the span's last `key` statement, else after its header statement, else at the span start. A missing final newline before an appended line gets `doc.nl` first. Text not edited is copied byte for byte.
- `splice_roster(old_raw: bytes, rendered: str, path: str) -> str`: when `old_raw.strip()` is empty, return `rendered`. Else `old = cfg_parse_toml_bytes(old_raw, path)` (ConfigError for malformed or non-UTF-8 bytes), `text = old_raw.decode("utf-8")`, `new = tomllib.loads(rendered)`; build the output by walking the blocks in order: the preamble through `_edit_span` with the `OWNED_TOP` keys; the `policy` table through `_edit_span` with `OWNED_POLICY`; roster entries by the slot rule (Task 2); every other block copied verbatim. A `policy` table that `new` has and `old` lacks is created as `[policy]` plus its key lines plus one blank line, inserted before the first roster entry, else at the end. Finally the gate: `tomllib.loads(result)` must equal `intended(old, new)`, else raise `ConfigError(path, "the comment-keeping write could not reproduce the intended config; nothing written")`. A `ValueError` from the scanner becomes the same ConfigError.
- A `# shortcut:` comment above `splice_roster`: `shortcut: the generated "# Priority fallback order" comment is not refreshed on a splice, upgrade when the ladder comment must track saves` (a fresh render still writes it).
