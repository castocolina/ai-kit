## The runner migration contract (Task 1 implements it exactly)

All new functions sit right above `resolveRetry` (helpers first), node built-ins only.

- `plainObject(v)`: `v !== null && typeof v === 'object' && !Array.isArray(v)`.
- `writeFileAtomic(file, text, mode = 0o600)`: `tmp = path.join(path.dirname(file), `.${path.basename(file)}.${process.pid}.${crypto.randomUUID()}.tmp`)`; `fd = fs.openSync(tmp, 'wx', mode)`; inside `try`: `fs.fchmodSync(fd, mode)`, `fs.writeFileSync(fd, text)`, `fs.fsyncSync(fd)`; `finally` `fs.closeSync(fd)`; then `fs.renameSync(tmp, file)`; on any error after the open, `fs.unlinkSync(tmp)` (ignore its failure) and rethrow. `writeCycleState` keeps its folder `mkdirSync`/`chmodSync` and its final file `chmodSync`, and replaces its own temp/write/rename lines with `writeFileAtomic(file, JSON.stringify(data))`.
- JSON span scanner (JSON has no comments): `jsonSkipWs(text, i)` (index of the next non-whitespace character); `jsonSkipString(text, i)` (`text[i]` is `"`; index after the closing quote, a backslash skipping the next character; -1 when unterminated); `jsonSkipValue(text, i)` (a string through `jsonSkipString`; `{`/`[` to the index after the matching close, counting depth and skipping strings; any other value up to the first whitespace, `,`, `}` or `]`; -1 when unterminated); `jsonMembers(text, open)` (`text[open]` is `{`; returns `[{ key, keyStart, valueStart, valueEnd }]` for that object's members in order, `key` decoded with `JSON.parse` of the key's source text, or `null` on any syntax surprise).
- `removeWorkflowMember(text)`: returns the new text or `null`. Root object at `jsonSkipWs(text, 0)`; its members must hold `workflow` exactly once (twice or none: `null`) and `workflow`'s value must start with `{`; that object's members must hold `cross_ai_retry` exactly once. With member list `inner` and the block at index `k`: when a member follows, cut from `inner[k].keyStart` to `inner[k + 1].keyStart`; else when one precedes, cut from `inner[k - 1].valueEnd` to `inner[k].valueEnd`; else (the only member) cut everything between `{` and the closing `}` of `workflow`'s object. Gate: `const want = JSON.parse(text); delete want.workflow.cross_ai_retry;` return the result only when `JSON.stringify(JSON.parse(result)) === JSON.stringify(want)`, else `null`.
- `GSD_LOCK_WAIT_MS = 2000`. `withGsdLock(cfgPath, fn)`: `lock = path.join(path.dirname(cfgPath), '.lock')` (gsd-core's planning lock for that scope, `.claude/gsd-core/bin/lib/planning-workspace.cjs` `withPlanningLock`); `body = JSON.stringify({ pid: process.pid, cwd: process.cwd(), acquired: new Date().toISOString() })`; loop `fs.writeFileSync(lock, body, { flag: 'wx' })`; on `EEXIST` wait 50 ms with `Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, 50)` until the deadline, then return `{ skipped: true }`; any other error returns `{ skipped: true }`. Once held: `try { return { value: fn() }; } finally { try { fs.unlinkSync(lock); } catch { /* gone */ } }`. Never remove a lock this call did not create.
- `dropRetryBlock(cfgPath)`: `real = fs.realpathSync(cfgPath)`; re-read `text` under the lock; when the parsed object no longer holds `workflow.cross_ai_retry`, return `'gone'`; `out = removeWorkflowMember(text)`; `null` returns `'refused'`; else `writeFileAtomic(real, out, fs.statSync(real).mode & 0o777)` and return `'removed'`.
- `mergeRetryBlock(data, scope, block, rel)`: returns `'invalid'`, `'unchanged'` or `'changed'`. `block` not a plain object, `data.scopes` present and not a plain object (scope set), `data.scopes[scope]` present and not a plain object, or the target `cross_ai_retry` present and not a plain object: `'invalid'` (check all of these before creating anything). An empty `block` returns `'unchanged'` without creating a holder. Else the holder is `data` (scope `''`) or `data.scopes[scope]` (created when absent); for each key of `block`: present in the holder's `cross_ai_retry` with a different `JSON.stringify` value, log `cross-ai: config ${rel} workflow.cross_ai_retry.${key} differs from .aikit/cross-ai.json; the .aikit/cross-ai.json value is kept` and skip it; present and equal, skip; absent, copy it. Returns `'changed'` when a key was copied.
- `migrateGsdBlocks(cwd, env)`: `planning = path.join(cwd, '.planning')`, `aikit = path.join(cwd, '.aikit')`, `projectFile = path.join(aikit, 'cross-ai.json')`. (1) Candidates: for each `cfgPath` of `scopedConfigPaths(cwd, env)` that exists, `rel = path.relative(cwd, cfgPath).split(path.sep).join('/')`; `read = readJsonObject(cfgPath, planning)`; an error logs `cross-ai: config ${rel} ${read.error}; workflow.cross_ai_retry not migrated` and skips it; a file whose `workflow` is not a plain object or has no own `cross_ai_retry` is skipped silently (never written); else it is a candidate `{ cfgPath, rel, scope, block }` with `scope = path.relative(planning, path.dirname(cfgPath)).split(path.sep).join('/')`. No candidate: return. (2) `proj = readJsonObject(projectFile, aikit)`; an error logs `cross-ai: config .aikit/cross-ai.json ${proj.error}; GSD workflow.cross_ai_retry blocks not migrated` and returns. `data = proj.obj || {}`; `migrated = Array.isArray(data.migrated_from) ? [...data.migrated_from] : []`; `before = JSON.stringify(data)`. (3) For each candidate in order, inside `try`/`catch` (a thrown error logs `cross-ai: config ${rel} not migrated (${e.code || e.message})` and the run goes on): a `rel` already in `migrated` logs `cross-ai: config ${rel} holds workflow.cross_ai_retry again; ignored (already moved to .aikit/cross-ai.json)`; else `mergeRetryBlock` (`'invalid'` logs `cross-ai: config ${rel} workflow.cross_ai_retry not migrated: it or its .aikit/cross-ai.json slot is not an object`); when `JSON.stringify(data) !== before`, write the project file (`fs.mkdirSync(aikit, { recursive: true })`, `writeFileAtomic(projectFile, JSON.stringify(data, null, 2) + '\n', <existing file mode & 0o777, or 0o600>)`) and refresh `before`; then `const res = withGsdLock(cfgPath, () => dropRetryBlock(cfgPath))`: `res.skipped` logs `cross-ai: config ${rel} is locked by a GSD write; workflow.cross_ai_retry stays until a later run removes it`; `res.value === 'refused'` logs `cross-ai: config ${rel} cannot drop workflow.cross_ai_retry and keep every other byte; left in place`; `'removed'` or `'gone'`: push `rel` to `migrated`, set `data.migrated_from = migrated`, write the project file as above, and log `cross-ai: moved workflow.cross_ai_retry from ${rel} to .aikit/cross-ai.json${scope ? ` (scope ${scope})` : ''}; .aikit/ is per checkout and may be git-ignored` (on `'gone'` only the marker is written, no move notice).
- `resolveRetry(cwd, env)` calls `migrateGsdBlocks(cwd, env)` as its first statement. The comment above it becomes: "Read once per call, after migrateGsdBlocks moved any GSD workflow.cross_ai_retry block into .aikit/cross-ai.json (the runner's one config write). Each key falls through the sources on its own; a refusal names the key and the source and the next source fills it in."
