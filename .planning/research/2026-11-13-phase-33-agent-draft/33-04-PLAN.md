## The migration contract (Task 1 implements it exactly)

`skills/ai-kit-spec-review/ai_kit_spec/config_migrate.py`, stdlib plus `from ai_kit_spec.trust import is_trusted, record_trust`; it never imports `config_io` (config_io imports it).

- `LEGACY_FILE = "review-spec.toml"`, `LEGACY_TRUST_DIR = "review-spec-trust"`, `MIGRATED_SUFFIX = ".migrated"`.
- `legacy_path(new_path) -> str`: `os.path.join(os.path.dirname(new_path), LEGACY_FILE)`.
- `legacy_trust_store(trust_store) -> str`: `os.path.join(os.path.dirname(trust_store), LEGACY_TRUST_DIR)`.
- `pending_legacy(new_path) -> str | None`: the legacy path when it exists and `new_path` does not, else None.
- `pending_note(old, new) -> str`: `f"migration pending: {old} -> {new} (read in place; this command writes nothing)"`.
- `_publish_if_absent(dest, data) -> bool`: a port of `tools/setup.py` `create_if_absent` (mkstemp in the destination folder with prefix `.lanes-create-`, write, flush, fsync, `os.link`; `FileExistsError` returns False; any other `OSError` from `os.link` falls back to `os.open(dest, O_WRONLY | O_CREAT | O_EXCL, 0o600)` and writes there, `FileExistsError` returning False; the temp is unlinked in `finally`).
- `_free_target(path) -> str`: `path` when it does not exist, else the first of `f"{path}.1"`, `f"{path}.2"`, ... that does not exist.
- `migrate_file(new_path, load, trust_store, warn_fn) -> str`, where `load(path) -> tuple[bytes, dict]` raises config_io's ConfigError for unreadable, non-UTF-8 or malformed files and `trust_store` is the new store for the project layer or None for the user layer. Steps: (1) `old = legacy_path(new_path)`; no old file returns `"none"`. (2) `raw, _ = load(old)` (ConfigError propagates; nothing written). (3) When `new_path` exists: `new_raw = load(new_path)[0]`; different bytes: `warn_fn(f"ai-kit-spec: {old} is not migrated: {new_path} already exists and is used; copy any edits you still need by hand, then remove or rename {old}")` and return `"conflict"`; equal bytes: state `"resumed"`. Else: `_publish_if_absent(new_path, raw)`, then re-read the new file's bytes; different from `raw`: the same conflict warning and `"conflict"`; equal: state `"migrated"`. (4) When `trust_store` is not None and `is_trusted(legacy_trust_store(trust_store), os.path.realpath(old), raw)`: `record_trust(trust_store, os.path.realpath(new_path), raw)` (written before step 5). (5) `target = _free_target(old + MIGRATED_SUFFIX)`; `os.replace(old, target)`; a `FileNotFoundError` there returns `"raced"` (another process finished). (6) `warn_fn(f"ai-kit-spec: migrated {old} to {new_path}; the old file is kept as {target}")` and return the state.

Additions to `config_io.py` (it imports `from ai_kit_spec import config_migrate`):
- `ROSTER_FILE = "lanes.toml"`, `ROSTER_TRUST_DIR = "lanes-trust"`; `cfg_local_path`, `cfg_global_path` and `cfg_trust_store_dir` build their paths from them.
- `_read_and_parse(path) -> tuple[bytes, dict]`: `raw = cfg_read_bytes(path)`; return `raw, cfg_parse_toml_bytes(raw, path)`.
- `cfg_migrate_path(path, env, warn_fn=None) -> str`: the project layer is any folder other than `os.path.realpath(cfg_config_base(env))`; it calls `config_migrate.migrate_file(path, _read_and_parse, cfg_trust_store_dir(env) if project else None, emit_warn)`; an `OSError` is caught and reported as `ai-kit-spec: migrating {legacy} did not finish ({exc}); it resumes on the next run` (legacy from `config_migrate.legacy_path(path)`), returning `"failed"`.
- `cfg_ensure_migrated(cwd, env, warn_fn=None) -> None`: `cfg_migrate_path` for `cfg_local_path(cwd)`, then for `cfg_global_path(env)`.
- `class RosterSources(NamedTuple)`: `project`, `user`, `trust_store`, `pending` (a tuple of `pending_note` strings).
- `cfg_roster_sources(cwd, env, migrate=True, warn_fn=None) -> RosterSources`: when `migrate`, `cfg_ensure_migrated(cwd, env, warn_fn)` first; then each layer reads `config_migrate.pending_legacy(path) or path` (a pending legacy file is read in place and its note added to `pending`); `trust_store` is `cfg_trust_store_dir(env)` unless the project path is the legacy file, then `config_migrate.legacy_trust_store(cfg_trust_store_dir(env))`.
- `cfg_resolve(cwd, env, warn_fn=None, migrate=True)`: `sources = cfg_roster_sources(cwd, env, migrate, emit_warn)`; each `sources.pending` note goes to `emit_warn(f"ai-kit-spec: {note}")`; the trust gate uses `sources.trust_store`; `cfg_load_layers(sources.project, sources.user, trusted, _local_only)`; `local_path=sources.project` in `cfg_combine` and in the untrusted warning.
