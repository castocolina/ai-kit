## Interfaces fixed for this phase (plans 01-07)

- `fold.py index [--repo DIR]`: refresh this checkout now (codegraph, then graphify, then the GSD copy when it applies); prints the report; exit 0 even when a tool is missing or fails. Registered in `fold.py main()`'s `handlers` dict (like `gsd-health`), not in `_FLOW_HANDLERS`.
- `fold.py index --detach [--repo DIR]`: the `post-checkout` hook mode. Acts only when env `PRE_COMMIT_FROM_REF` is forty `0` characters (a new worktree or clone); queues the checkout top level and starts the detached runner; prints nothing; always exits 0.
