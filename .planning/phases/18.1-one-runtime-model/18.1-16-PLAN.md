<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> project tree | writes `.planning/scripts/cross-ai.mjs` and the guidance file into the user's project |
| hook string -> GSD config | a command GSD later expands unquoted in a shell |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-39 | Tampering | unquoted hook tokens | high | mitigate | `HOOK_TOKEN_RE` allowlist (no whitespace, quotes, `$`, backtick, `;`, `&`, `|`, `<`, `>`, `*`, `?`, `(`); a failing token returns None (degraded, nothing written); `TestProjectRunnerCommand` |
| T-18.1-41 | Tampering | overwriting a user's runner | high | mitigate | only a pristine (sha-matching) script is upgraded; edited/unstamped/foreign -> `.new` with a note; tests assert original bytes unchanged |
| T-18.1-42 | Elevation of privilege | outdated project runner | medium | mitigate | `ensure_runner` upgrades pristine older scripts and reports `ready: false` otherwise; the hook is written only when ready |
| T-18.1-62 | Tampering | guidance file | medium | mitigate | sha-headed like the runner; user edits produce `.new`; content reaches the CLI on stdin only (`--prepend-file`) |
| T-18.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | this plan installs nothing |
</threat_model>
