# Routing per call, ephemeral route on resolve-reviewers

Every reviewer is now routed per call from the host and the runtimes inventory, and `resolve-reviewers` emits that route without ever storing it.

## Accomplishments

- Added `routing.route` with the full decision order (custom, session default, unknown runtime, no model, native, review-only, not installed, no inventory, unverified, subprocess, bad model) plus suffix stripping for cursor, opencode and pi model ids.
- Added a bounded refresh that re-lists only the runtime that missed, at most once per process and never inside the 60-second floor. Claude is never re-listed; its ids come from the catalog.
- `resolve-reviewers` now attaches an ephemeral `route` to each reviewer, skips unroutable entries through an in-memory quota overlay, and prints one stderr line per skipped key and per unverified dispatch.
- A stored `route` is rejected at save and dropped with a note at load. Step 1 of the review skill branches on `route` instead of the stored fields.
