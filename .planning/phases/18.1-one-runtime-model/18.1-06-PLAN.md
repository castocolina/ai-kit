- `_FACTORY_TOKENS: dict[str, frozenset[str]]`: the literal tokens the reviewer factory
  (`commands.build_reviewer_command`, deleted in 18.1-18) emitted, per runtime:
  codex `{"codex", "exec", "--sandbox", "read-only", "--skip-git-repo-check", "-m", "{model}", "-c"}`;
  claude `{"claude", "-p", "--model", "{model}", "--output-format", "text"}`;
  opencode `{"opencode", "run", "-m", "{model}"}`;
  cursor `{RUNTIMES["cursor"].binaries[0], "-p", "--output-format", "text", "--mode", "--trust",
  "--model", "{model}"}` (the binary comes from the table: Rule 10 bans the literal outside detection.py).
  Copy each set from the current builders in commands.py and cite the builder in a one-line comment.
- `_legacy_command_knobs(rid, command) -> dict | None`: `shlex.split` (ValueError -> None); the first
  token must be the runtime's binary; walk the tokens: a token in `_FACTORY_TOKENS[rid]` passes; the
  token after `-c` must be `model_reasoning_effort=<v>` -> `effort` or `service_tier=<v>` ->
  `service_tier` (one level of surrounding `'`/`"` quotes stripped from `<v>`); the token after
  `--mode` must be `plan` or `ask` -> `cursor_mode`; any other token returns None (hand-tuned, D-32).
  A runtime with no `_FACTORY_TOKENS` row (pi) returns None.
- `normalize_legacy_entry(entry) -> tuple[dict, list[str]]`: never raises, never mutates; a non-dict
  returns `(entry, [])`. Rules on a copy, in this order; every note is prefixed `<key>: `:
  1. `cli` present and not None: `rid = runtime_id(cli)`; drop `cli` and `native_runtime`.
     - `rid in RUNTIMES and RUNTIMES[rid].runner`: no `command` -> `runtime = rid`, note
       `cli=<cli> -> runtime=<rid>`; `command` with `_legacy_command_knobs` returning a dict ->
       `runtime = rid`, drop `command`, add knobs the entry does not already set, note
       `cli=<cli> -> runtime=<rid>; command dropped (the runner builds the argv)[; kept <knob names>]`;
       `command` with knobs None -> custom entry (keep `command`, no `runtime`), note
       `cli=<cli>: command has flags the runner formula does not reproduce; kept as a custom command entry`.
     - otherwise, with a `command` -> custom entry, note `cli=<cli> has no runner formula; kept as a
       custom command entry`; without one -> `runtime = rid`, note `cli=<cli> has no runner formula
       and no command; this entry is skipped`.
  2. `native_runtime` present (and no `cli`): drop it. `"unknown"` or a non-str -> session default
     (`model = ""`; note `native_runtime=unknown: model '<m>' dropped; now the session default` when a
     model was set). Else `runtime = runtime_id(value)` unless `runtime` is already set; note
     `native_runtime=<v> -> runtime=<id>`.
  3. `runtime` is a str whose `runtime_id` differs: replace it, note `runtime=<old> -> <id>` (D-20).
- `normalize_legacy_reviewers(reviewers) -> tuple[list, list[str]]`: rules 1-3 per entry, order kept,
  non-dict items untouched.
- `infer_legacy_native(reviewers) -> tuple[list, list[str]]`: for an entry with no `runtime`, no
  `command` and a non-empty `model`: model in `RUNTIMES["claude"].native_selectors` -> `runtime =
  "claude"`, note `<key>: model '<m>' had no runtime; inferred runtime=claude (pre-1.2 native meaning)`;
  else `model = ""`, note `<key>: model '<m>' had no runtime; dropped, now the session default`.
- `_LEGACY_NOTED: set[str]`; `_emit_legacy_note(label, notes, emit_warn)` emits once per label per
  process: `ai-kit-spec: <label>: legacy reviewer fields loaded in memory (<notes joined by "; ">); the
  file is unchanged -- re-save it with the ai-kit-spec-config wizard or render-toml --out`.
