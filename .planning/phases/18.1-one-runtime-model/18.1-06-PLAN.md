routing.py additions (stdlib + `detection` only):
- `RouteInput(NamedTuple)`: `runtime: str | None`, `model: str`, `command: str | None = None`;
  `RouteInput.of(resolved)` classmethod from a ResolvedReviewer.
- `Inventory(NamedTuple)`: `installed: frozenset[str]`, `models: Mapping[str, tuple[str, ...] | None]`.
- `inventory_from_snapshot(snapshot: dict | None) -> Inventory`: for each `clis[rt]` with
  `installed` true, add rt to `installed`; models: claude -> `aliases` + `models` (keep first-seen
  order, drop duplicates; when `models` is missing use `CLAUDE_FALLBACK_MODEL_IDS`); other rows ->
  `tuple(models)` when `models` is a list, else None. A None or malformed snapshot -> empty Inventory.
- `strip_model_suffix(runtime, model) -> str`: `re.sub(RUNTIMES[runtime].model_suffix, "", model)`
  when the row has one, else `model`.
- `route(entry: RouteInput, host: str, mode: str, inventory: Inventory) -> str`: the order in
  must_haves truth 1. `mode` is `"review"` or `"exec"`.
- `SKIP_ROUTES = frozenset({"bad_model", "no_inventory", "not_installed", "unknown_runtime",
  "no_model", "review_only"})`; dispatchable routes: `native`, `subprocess`, `custom`, `unverified`.
- `unroutable_quota(quota: dict, routes: Mapping[str, str]) -> dict`: a copy of `quota` where every
  key whose route is in `SKIP_ROUTES` maps to `{"available": False, "reason": <route>}` (never written
  to the quota cache).
- `RuntimesSeams(NamedTuple)`: `which_fn`, `run_fn`, `popen_fn`, `urlopen_fn` (the
  `build_runtimes_snapshot` seams).
- `runtimes_cache_is_fresh(path, env) -> bool`: the existing three-part test moved out of
  `_cmd_detect_runtimes` (mtime within `RUNTIMES_TTL_SECONDS`, `runtimes_schema_is_current`,
  `claude_runtime_is_current` against the catalog at `cache_catalog_path(env)`).
- `load_runtimes_snapshot(env, seams, force=False) -> tuple[dict, bool]`: returns the cached snapshot
  when not `force` and fresh; otherwise builds one with `build_runtimes_snapshot` (the seams plus the
  catalog reader), writes it to `cache_runtimes_path(env)` with `cache_write_json`, and returns
  `(snapshot, True)`. Public so the execute lanes (18.1-08, 18.1-12) reuse it. routing.py may import
  `detection`, `cache` and `model_catalog` (no cycle: neither imports routing).
- `RouteContext(NamedTuple)`: `host: str`, `mode: str`, `env: dict`, `seams: RuntimesSeams`.
- `route_all(entries: list[dict], ctx: RouteContext) -> dict[str, str]`: key -> route for every dict
  entry with a `key`: load the snapshot (`force=False`), route each entry; when any route is
  `bad_model`, `not_installed` or `unverified` and the load did not already refresh, refresh once
  (`force=True`) and re-route every entry (D-19). Never a second refresh. Public so 18.1-08's
  superpowers lane reuses the same bounded-refresh logic.

cli.py:
- `_cmd_detect_runtimes --if-stale` keeps its output (`{}` when fresh) but takes its freshness test
  from `routing.runtimes_cache_is_fresh` (below), so the two callers cannot drift.
- `_cmd_resolve_reviewers`: `env = deps.env_fn()`; `config = cfg_resolve(args.cwd, env)`;
  `host = detect_current_runtime(env)`; `routes = routing.route_all(<config reviewers>,

  `resolve_reviewers(config, unroutable_quota(quota, routes), ...)`; print each reviewer's `_asdict()`

|----------|-------------|
| runtimes cache -> routing | a cached file under the user's cache dir decides subprocess vs skip |
| resolve-reviewers -> live CLI listing | a refresh runs the installed CLIs' listing commands |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-16 | Tampering | runtimes cache | low | mitigate | `inventory_from_snapshot` treats malformed data as an empty inventory (never raises); a forged list can only allow a model the runner then preflights again |
| T-18.1-17 | Denial of service | D-19 refresh | medium | mitigate | at most one forced refresh per resolve-reviewers call (test counts snapshot builds) |
| T-18.1-18 | Tampering | stored `route` | medium | mitigate | rejected at save, dropped with a note at load (`TestRouteNeverStored`) |
| T-18.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | this plan installs nothing |
</threat_model>
