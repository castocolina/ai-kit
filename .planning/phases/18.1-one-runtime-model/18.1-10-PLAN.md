`AIKIT-XAI status=<s> cli=<rt> model=<m> exit=<n> cli_rc=<..> elapsed=<..> out=<..> tree=<..> action=<..>`;

error_classifier.py:
- `REASONS` appends `"capacity"` and `"billing_or_access"` (module docstring updated: they now live
  here, mapped from the runner status line).
- `STATUS_TO_REASON: dict[str, str | None]`: ok -> None; quota, quota_wait -> "quota"; auth -> "auth";
  billing, billing_or_access -> "billing_or_access"; capacity -> "capacity"; timeout, idle_stall ->
  "timeout"; bad_model, bad_prompt, permission_blocked, usage, no_model, empty_stdin ->
  "configuration"; not_installed -> "dispatch_unavailable"; no_change, empty_answer, crash,
  contract_violation, signal, unverified -> "real_error".
- `reason_for_status(status: str | None, returncode: int | None) -> str | None`: the map value when
  `status` is a key; else returncode 0 -> None, 127 -> "dispatch_unavailable", anything else ->
  "real_error".

runner_dispatch.py:
- `RUNNER_OUTER_MARGIN_S = 30`; `_KILL_GRACE_S = 10`.
- `RunnerSpec(NamedTuple)`: `runtime`, `model`, `mode`, `timeout_s: int`, `cwd: str | None = None`,
  `effort: str | None = None`, `service_tier: str | None = None`, `cursor_mode: str | None = None`.
- `build_runner_argv(spec, runner_path, node) -> list[str]`: the argv in must_haves truth 1; codex
  knobs only when `spec.runtime == "codex"` and set; `--cursor-mode` only when `spec.runtime ==
  "cursor"`, `spec.mode == "review"` and set.
- `RunnerSeams(NamedTuple)`: `which_fn=shutil.which`, `popen_fn=subprocess.Popen`,
  `time_fn=time.monotonic`, `kill_fn=os.killpg`, `print_fn` (writes a line to stderr),
  `runner_path_fn=resolve_cross_ai_template_path`, `env_fn=lambda: dict(os.environ)`.
- `RunnerResult(NamedTuple)`: `returncode: int | None`, `stdout: str`, `status: dict | None`,
  `reason: str | None`, `timed_out: bool`, `argv: list[str]`.
- `parse_status_line(line) -> dict | None`: `None` unless the line starts with `AIKIT-XAI `; else the
  `key=value` tokens as a dict (values keep brackets and slashes).
- `run_runner(spec, prompt, seams=RunnerSeams()) -> RunnerResult`: no node -> print the D-13 line,
  `reason="dispatch_unavailable"`, `returncode=None`, no spawn; no template -> print
  `ai-kit-spec: runner template not found` and the same reason; Popen `OSError` -> same reason. Spawn
  with `stdin` = a temp file holding the prompt, `stdout` = a temp file, `stderr=PIPE`,
  `start_new_session=True`, `cwd=spec.cwd`, `env=child_env(env=seams.env_fn())`, `text` mode; a daemon
  thread reads stderr lines, relays each through `print_fn`, and keeps the last status line; wait in
  slices until `timeout_s + RUNNER_OUTER_MARGIN_S + _KILL_GRACE_S`, then `kill_fn(pgid, SIGTERM)`,
  2 s later `SIGKILL`, `timed_out=True`; join the thread; read stdout; delete both temp files;
  `reason = reason_for_status(status.get("status"), returncode)` (timed out with no status ->
  "timeout").
- `run_runner_tiers(spec, tiers, prompt, seams=RunnerSeams()) -> RunnerResult`: loops `tiers` in
  order with `spec._replace(timeout_s=t)`; continues only on status `timeout` or returncode 124.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python -> node runner | argv and prompt cross into a child process tree with full CLI permissions in exec mode |
| runner stderr -> Python | the last status line decides the reason Python stores |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-28 | Tampering | argv construction | high | mitigate | list argv, no shell; model ids validated again by the runner's own charset; prompt only on stdin |
| T-18.1-29 | Denial of service | orphaned process group | high | mitigate | `start_new_session=True`, backstop `killpg` after the deadline plus margin and grace; e2e leak check |
| T-18.1-30 | Spoofing | forged status line in CLI output | medium | mitigate | only the LAST `AIKIT-XAI ` stderr line counts, which the runner prints after its child is reaped; stdout is never parsed for status |
| T-18.1-31 | Information disclosure | prompt temp files | low | mitigate | `tempfile` files created 0600 by default and deleted after the call |
| T-18.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | this plan installs nothing |
</threat_model>
