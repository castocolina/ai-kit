# Phase 18.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Seeded from
> `18.1-RESEARCH.md` §Validation Architecture (V1-V17); the planner maps each V-row to task IDs.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `unittest` via `tools/run_unittest_parallel.py` (groups unit, unit-uv, integration, e2e, arch) |
| **Config file** | Makefile group listing (`tools/gen_test_groups.py`), `pyproject.toml` |
| **Quick run command** | `python3 -m unittest tests.<module> -k <TestClass>` |
| **Full suite command** | `make test && make validate` (plus `make e2e-docker` once at phase end) |
| **Estimated runtime** | ~240 seconds (full); quick < 30 seconds |

---

## Sampling Rate

- **After every task commit:** Run the touched module's quick command
- **After every plan wave:** Run `make test`
- **Before `/gsd-verify-work`:** `make test`, `make validate`, `make e2e-docker` green
- **Max feedback latency:** 30 seconds (quick)
