<interfaces>
runner_dispatch.py:
- `SpawnSeams(NamedTuple)`: `popen_fn`, `time_fn`, `kill_fn`, `print_fn`, `env_fn` (the subset of
  `RunnerSeams` the core needs; `RunnerSeams` builds one).
- `SpawnResult(NamedTuple)`: `returncode`, `stdout`, `stderr_tail: str`, `timed_out`, `last_status_line:
  str | None`.
- `_spawn_supervised(argv, prompt, deadline_s, cwd, seams) -> SpawnResult`: the body `run_runner`
  has today (temp stdin/stdout files, stderr reader thread that relays each line through `print_fn`,
  keeps the last 2048 characters and the last `AIKIT-XAI ` line, SIGTERM then SIGKILL to the group at
  `deadline_s`); raises `OSError` from Popen to the caller.
- `run_runner` calls it with `deadline_s = timeout_s + RUNNER_OUTER_MARGIN_S + _KILL_GRACE_S`.
- `CustomSpec(NamedTuple)`: `key`, `argv: list[str]`, `timeout_tiers: list[int]`, `cwd: str | None = None`.
- `run_custom_command(spec, prompt, seams=SpawnSeams()) -> RunnerResult`: empty tiers or empty argv ->
  ValueError (kept messages from the deleted polling supervisor); per tier `_spawn_supervised(argv,
  prompt, tier, cwd, seams)`; on timeout print `tier <i> (<s>s) timed out -- escalating to tier <i+1>
  (<s2>s)` and continue; OSError -> `reason="dispatch_unavailable"`; else `reason =
  reason_for_exit(returncode, timed_out)`; `status=None`, `argv=spec.argv`.
reviewer_dispatch.py: custom branch builds `argv = render_reviewer_command(resolved, full_prompt)`
(prompt substitution unchanged) and calls `run_custom_command`; `ReviewerSeams.dispatch_fn` becomes
`custom_fn = run_custom_command`; same result keys as the runner branch.
quota.py: the custom probe calls `run_custom_command(CustomSpec(key, argv, [30]), probe_prompt,
SpawnSeams(print_fn=<collector>))`; `run_fn` parameter kept as an unused keyword for callers.
dispatch.py: delete `dispatch_with_heartbeat`, `dispatch_with_polling`, `HeartbeatDispatchSeams`,
`PollingDispatchSeams`, `_POLL_SLICE_SECONDS`, `_default_print_fn`, `_default_kill_process_group`,
`_read_output`, `_TierProgress`, `_PollingTierWork`, `_report_tier_progress`, `_PollLoopCtx`,
`_poll_tier_process`, `_spawn_polling_tier`; keep `child_env`, `write_resumable_state` and the module
docstring rewritten to say what is left. execute_dispatch.py and superpowers dispatch_injection.py:
docstring mentions of the deleted names removed.
tests/test_arch.py: `_DELETED_DEFINITIONS` adds `dispatch_with_heartbeat`, `dispatch_with_polling`.
