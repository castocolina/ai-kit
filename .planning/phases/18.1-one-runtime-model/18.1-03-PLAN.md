<objective>
Migrate legacy caches in memory (D-04, D-17 step 1, cache side): the model catalog's
`runtimes.cursor-agent` keys become `runtimes.cursor` at the one read choke point
(`split_catalog_meta`, schema 3), and curated-config normalizes a cached snapshot's `cursor-agent`
key, so a user's existing cache gives the same candidates as a fresh id-keyed one. Nothing is written
back; user-confirmed catalog entries are never wiped.

Purpose: RTM-02 / SPEC R1 and D-04: old caches keep working after the id switch of 18.1-01/02.
Output: catalog schema 3 with the migration, snapshot normalization in curated-config, the
`detection` -> `model_catalog` import inverted, the fixture at schema 3.

Dependency inversion (needed to avoid an import cycle): `detection.py` stops importing
`model_catalog` (its `claude_runtime_fields` reads `_meta` through a private `_catalog_meta(raw)`
helper with the same never-raise contract), so `model_catalog.py` can import `normalize_runtime_keys`
from `detection`.
