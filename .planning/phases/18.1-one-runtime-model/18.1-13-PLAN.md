<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| adapter -> GSD config | a command string GSD later expands unquoted in a shell |
| v1 apply-execution -> project tree | writes `.planning/scripts/cross-ai.mjs` into the user's project |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-39 | Tampering | unquoted hook expansion | high | mitigate | `project_runner_command` rejects tokens with whitespace, quotes, `$`, backtick, `;`, `&`, `|`, `<`, `>` or backslash; adapter reports `unsafe_hook_token`; tests |
| T-18.1-40 | Tampering | glob characters in cursor bracket ids | low | accept | unchanged from the old hook (it also expanded `{model}` unquoted); a match needs a file named like the model id in the project root |
| T-18.1-41 | Tampering | overwriting a user's runner | high | mitigate | v1 renders only when no script exists; an existing file is never touched (`runner: present` test) |
| T-18.1-42 | Elevation of privilege | outdated project runner | medium | mitigate | template below 3 -> `no_project_runner` notice, no hook written |
| T-18.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | this plan installs nothing |
</threat_model>
