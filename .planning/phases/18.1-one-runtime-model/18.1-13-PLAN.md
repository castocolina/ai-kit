pid = pgid. The runner's own SIGTERM/SIGINT/SIGHUP handler kills the live CLI group within its 2.5 s
signal budget.

runner_dispatch.py:
- `RUNNER_OUTER_MARGIN_S = 30`; `_KILL_GRACE_S = 10` (deadline slack after the runner's own outer
  timeout); `_TERM_GRACE_S = 4` (SIGTERM to SIGKILL; above the runner's 2.5 s signal budget);
  `_DRAIN_S = 2` (stderr relay join bound); `_STDERR_TAIL_CHARS = 2048`.
- `MODEL_ID_SRC` and `CURSOR_MODEL_ID_SRC`: the template's regex sources verbatim
  (`^[A-Za-z0-9][A-Za-z0-9._:/#@+-]*$` and the 18.1-12 cursor form); `model_id_ok(runtime, model)`
  applies `re.fullmatch(src[1:-1], model)` with the cursor source for `cursor`.
- `RunnerSpec(NamedTuple)`: `runtime`, `model`, `mode`, `timeout_s: int`, `cwd: str | None = None`,
  `effort: str | None = None`, `service_tier: str | None = None`, `cursor_mode: str | None = None`,
  `codex_sandbox: str | None = None`.
- `runner_flags(spec) -> list[str]`: `--prefer <rt> --model-<rt> <model> --mode <mode>`; codex adds
  `--codex-effort`/`--codex-service-tier` when set and `--codex-sandbox <v>` when set and mode is
  `exec`; cursor adds `--cursor-mode` only in review mode when set.
- `build_runner_argv(spec, runner_path, node) -> list[str]`: `[node, runner_path, *runner_flags(spec),
  "--timeout", t, "--outer-timeout", t + RUNNER_OUTER_MARGIN_S, "--no-preamble"]`.
- `RunnerSeams(NamedTuple)`: `which_fn=shutil.which`, `popen_fn=subprocess.Popen`,
  `time_fn=time.monotonic`, `sleep_fn=time.sleep`, `kill_fn=os.killpg`, `print_fn` (one line to stderr),
  `runner_path_fn=resolve_cross_ai_template_path`, `env_fn=lambda: dict(os.environ)`.
- `RunnerResult(NamedTuple)`: `returncode: int | None`, `stdout: str`, `status: dict | None`,
  `reason: str | None`, `timed_out: bool`, `argv: list[str]`, `stderr_tail: str`.
- `parse_status_line(line) -> dict | None`: None unless the line starts with `AIKIT-XAI `; else the
  `key=value` tokens as a dict (values keep brackets and slashes).
- `SpawnRequest(NamedTuple)`: `argv: list[str]`, `prompt: str`, `deadline_s: float` (seconds after
  the spawn), `cwd: str | None = None`, `pgid_file: str | None = None`.
- `_spawn_supervised(request, seams) -> RunnerResult` (reason None; callers fill it): stdin = a temp
  file holding the prompt, stdout = a temp file, `stderr=PIPE`, `start_new_session=True`, `cwd`,
  `env=child_env(env=seams.env_fn())`, text mode; a daemon thread relays each stderr line through
  `print_fn`, keeps the last `_STDERR_TAIL_CHARS` and the last `AIKIT-XAI ` line (parsed into
  `status`); wait in slices until `deadline_s`; past it `timed_out=True`. Then, in a `finally` that
  runs on every exit path, in this order:
  1. group cleanup: `kill_fn(pgid, SIGTERM)`; when the child is still running wait for it up to
     `_TERM_GRACE_S`; then `kill_fn(pgid, SIGKILL)` (clears descendants left in the group even after
     a normal exit), followed by a bounded `proc.wait(timeout=_TERM_GRACE_S)` (a `subprocess.TimeoutExpired` there is swallowed, as `dispatch.py:196-199` does today) that reaps the child
     (no zombie; `returncode` set) (cross-AI review cycle 3); `ProcessLookupError` ignored on every kill;
  2. recorded groups, when `request.pgid_file` is set: parse its lines; every `spawn N` with no
     `exit N` line, where N is an int above 1 and not `os.getpgrp()`, gets `kill_fn(N, SIGTERM)`, then
     polling `kill_fn(N, 0)` with `sleep_fn` up to `_TERM_GRACE_S`, then `kill_fn(N, SIGKILL)`;
     malformed lines are skipped; a missing or unreadable file means nothing recorded;
  3. join the relay thread for at most `_DRAIN_S`; if it is still alive print
     `ai-kit-spec: stderr still open after the child exited; stopped reading` and leave the daemon
     thread (never close the pipe from this thread: a buffered close blocks while the reader holds its
     lock);
  4. read stdout; delete both temp files.
  Split into helpers to stay within the pylint limits. Popen `OSError` propagates (nothing spawned,
  nothing to clean).
- `run_runner(spec, prompt, seams=RunnerSeams()) -> RunnerResult`: no node -> print the D-13 line,
  `reason="dispatch_unavailable"`, no spawn; no template -> print `ai-kit-spec: runner template not
  found`, same reason; `model_id_ok` false -> print `ai-kit-spec: model id <m> is not a valid <rt>
  model id`, `reason="configuration"`, no spawn; Popen OSError -> `dispatch_unavailable`; else
  `tempfile.mkdtemp(prefix="aikit-pgid-")` (0700), and `_spawn_supervised(SpawnRequest(argv +
  ["--child-pgid-file", <dir>/child-pgids], prompt, spec.timeout_s + RUNNER_OUTER_MARGIN_S +
  _KILL_GRACE_S, spec.cwd, <dir>/child-pgids), seams)`; the temp dir is removed in a `finally`.
  `RunnerResult.argv` is the `build_runner_argv` list without the pgid flag.
  Trailer validation: the parsed last status line counts only when its `exit` equals
  `str(returncode)` and its `cli` is `-` or `spec.runtime` and its `model` is `-` or `spec.model`;
  otherwise print `ai-kit-spec: ignoring a runner status line that does not match this run` and set
  `status=None`. Reason: `"timeout"` when `timed_out`; else
  `reason_for_status(status["status"] if status else None, returncode)`.
- `run_runner_tiers(spec, tiers, prompt, seams=RunnerSeams()) -> RunnerResult`: loops `tiers` with
  `spec._replace(timeout_s=t)`; continues only on status `timeout` or returncode 124 (a `git_timeout`
  exits 1 and stops the loop).
- `CustomSpec(NamedTuple)`: `key`, `argv: list[str]`, `timeout_tiers: list[int]`, `cwd: str | None = None`.
- `run_custom_command(spec, prompt, seams=RunnerSeams()) -> RunnerResult`: empty tiers or empty argv ->
  ValueError (messages kept from `dispatch_with_polling`); per tier
  `_spawn_supervised(SpawnRequest(argv, prompt, tier, cwd), seams)`; on timeout print `tier <i> (<s>s) timed out -- escalating to tier <i+1> (<s2>s)`
  and continue; OSError -> `dispatch_unavailable`; else `reason = classify_error(returncode,
  stderr_tail, timed_out)` (D-28); `status=None`.
