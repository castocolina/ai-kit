## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reviewers.json -> dispatch-reviewer | a JSON file the orchestrator wrote decides what runs |
| quota probe -> real CLI | one short review-mode call per probed key |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-32 | Elevation of privilege | review mode | high | mitigate | every review call passes `--mode review` (the runner's read-only formulas); test asserts the spec mode |
| T-18.1-33 | Spoofing | `route: native` in reviewers.json | medium | mitigate | dispatch-reviewer refuses native routes (no spawn), so a hand-edited file cannot turn a host reviewer into an unexpected subprocess |
| T-18.1-34 | Information disclosure | trust-local display | low | mitigate | the prompt is never in argv (stdin only); display shows `<runner>` when the template is not found |
| T-18.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | this plan installs nothing |
</threat_model>
