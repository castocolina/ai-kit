runner_dispatch.py:
- `RUNNER_OUTER_MARGIN_S = 30`; `_KILL_GRACE_S = 10`; `_STDERR_TAIL_CHARS = 2048`.
- `MODEL_ID_SRC` and `CURSOR_MODEL_ID_SRC`: the template's regex sources verbatim
  (`^[A-Za-z0-9][A-Za-z0-9._:/#@+-]*$` and the 18.1-10 cursor form); `model_id_ok(runtime, model)`
  applies `re.fullmatch(src[1:-1], model)` with the cursor source for `cursor`.
- `RunnerSpec(NamedTuple)`: `runtime`, `model`, `mode`, `timeout_s: int`, `cwd: str | None = None`,
  `effort: str | None = None`, `service_tier: str | None = None`, `cursor_mode: str | None = None`,
  `codex_sandbox: str | None = None`.
- `runner_flags(spec) -> list[str]`: `--prefer <rt> --model-<rt> <model> --mode <mode>`; codex adds
  `--codex-effort`/`--codex-service-tier` when set and `--codex-sandbox <v>` when set and mode is
  `exec`; cursor adds `--cursor-mode` only in review mode when set.
- `build_runner_argv(spec, runner_path, node) -> list[str]`: `[node, runner_path, *runner_flags(spec),
  "--timeout", t, "--outer-timeout", t + RUNNER_OUTER_MARGIN_S, "--no-preamble"]`.
- `RunnerSeams(NamedTuple)`: `which_fn=shutil.which`, `popen_fn=subprocess.Popen`,
  `time_fn=time.monotonic`, `kill_fn=os.killpg`, `print_fn` (one line to stderr),
  `runner_path_fn=resolve_cross_ai_template_path`, `env_fn=lambda: dict(os.environ)`.
- `RunnerResult(NamedTuple)`: `returncode: int | None`, `stdout: str`, `status: dict | None`,
  `reason: str | None`, `timed_out: bool`, `argv: list[str]`, `stderr_tail: str`.
- `parse_status_line(line) -> dict | None`: None unless the line starts with `AIKIT-XAI `; else the
  `key=value` tokens as a dict (values keep brackets and slashes).
- `_spawn_supervised(argv, prompt, deadline_s, cwd, seams) -> RunnerResult` (reason None; callers
  fill it): stdin = a temp file holding the prompt, stdout = a temp file, `stderr=PIPE`,
  `start_new_session=True`, `cwd`, `env=child_env(env=seams.env_fn())`, text mode; a daemon thread
  relays each stderr line through `print_fn`, keeps the last `_STDERR_TAIL_CHARS` and the last
  `AIKIT-XAI ` line (parsed into `status`); wait in slices until `deadline_s`, then
  `kill_fn(pgid, SIGTERM)`, 2 s later `SIGKILL`, `timed_out=True`; join; read stdout; delete both temp
  files. Popen `OSError` propagates.
- `run_runner(spec, prompt, seams=RunnerSeams()) -> RunnerResult`: no node -> print the D-13 line,
  `reason="dispatch_unavailable"`, no spawn; no template -> print `ai-kit-spec: runner template not
  found`, same reason; `model_id_ok` false -> print `ai-kit-spec: model id <m> is not a valid <rt>
  model id`, `reason="configuration"`, no spawn; Popen OSError -> `dispatch_unavailable`; else
  `_spawn_supervised(..., spec.timeout_s + RUNNER_OUTER_MARGIN_S + _KILL_GRACE_S, ...)` and
  `reason = reason_for_status(status.get("status"), returncode)` (timed out with no status ->
  "timeout").
- `run_runner_tiers(spec, tiers, prompt, seams=RunnerSeams()) -> RunnerResult`: loops `tiers` with
  `spec._replace(timeout_s=t)`; continues only on status `timeout` or returncode 124.
- `CustomSpec(NamedTuple)`: `key`, `argv: list[str]`, `timeout_tiers: list[int]`, `cwd: str | None = None`.
- `run_custom_command(spec, prompt, seams=RunnerSeams()) -> RunnerResult`: empty tiers or empty argv ->
  ValueError (messages kept from `dispatch_with_polling`); per tier `_spawn_supervised(argv, prompt,
  tier, cwd, seams)`; on timeout print `tier <i> (<s>s) timed out -- escalating to tier <i+1> (<s2>s)`
  and continue; OSError -> `dispatch_unavailable`; else `reason = classify_error(returncode,
  stderr_tail, timed_out)` (D-28); `status=None`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python -> node runner | argv and prompt cross into a child process tree with full CLI permissions in exec mode |
| Python -> custom command | a user-written argv runs outside the runner |
| runner stderr -> Python | the last status line decides the reason Python stores |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-28 | Tampering | argv construction | high | mitigate | list argv, no shell; model ids checked in Python against the runner's charset and again by the runner; prompt only on stdin |
| T-18.1-29 | Denial of service | orphaned process group | high | mitigate | `start_new_session=True`, backstop `killpg` after the deadline plus margin and grace on both lanes; pid-snapshot leak check |
| T-18.1-30 | Spoofing | forged status line in CLI output | medium | mitigate | only the LAST `AIKIT-XAI ` stderr line counts, which the runner prints after its child is reaped; stdout is never parsed for status |
| T-18.1-31 | Information disclosure | prompt temp files | low | mitigate | `tempfile` files created 0600 by default and deleted after the call |
