## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv -> runner | model ids and file paths arrive as flags from Python or GSD |
| PATH -> spawned binary | the runner picks which executable to run for a runtime |
| runner -> codex exec | write confinement of the executing CLI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-24 | Spoofing | bare `agent` | high | mitigate | `resolveBin` realpath basename check; `bare-agent-guard` and `agent-cursor-realpath` cases |
| T-18.1-25 | Tampering | bracket model id charset | medium | mitigate | brackets only for `--model-cursor`, closed charset with no space, quote, `$`, `;` or leading dash; `cursor-bracket-other-rt` case; argv spawn (no shell) unchanged |
| T-18.1-35 | Tampering | `--prepend-file` | medium | mitigate | read-only use of one caller-named file; content goes to stdin only, never argv; unreadable file fails closed with usage (`prepend-file-missing` case) |
| T-18.1-36 | Elevation of privilege | codex exec confinement | high | mitigate | `--codex-sandbox workspace-write` restores `--sandbox workspace-write -C <cwd>`; retries stay in the sandbox (fresh run, no resume); cases `codex-sandbox-exec`/`-default`/`-bad`; ai-kit's exec dispatch passes it (18.1-15, 18.1-16, 18.1-17); `.git` writability under it stays labeled unverified (D-27) |
| T-18.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | this plan installs nothing |
