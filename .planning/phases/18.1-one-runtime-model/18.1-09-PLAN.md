- `RouteInput(NamedTuple)`: `runtime: str | None`, `model: str`, `command: str | None = None`;
  `RouteInput.of(resolved)` classmethod from a ResolvedReviewer or an entry dict.
- `Inventory(NamedTuple)`: `installed: frozenset[str]`, `models: Mapping[str, tuple[str, ...] | None]`.
- `inventory_from_snapshot(snapshot: dict | None) -> Inventory`: for each `clis[rt]` (keys through
  `normalize_runtime_keys`) with `installed` true, add rt to `installed`; models: claude -> `aliases`
  + `models` (first-seen order, duplicates dropped; `models` missing -> `CLAUDE_FALLBACK_MODEL_IDS`);
  other rows -> `tuple(models)` when `models` is a list, else None. None or malformed -> empty.

  when the row has one, else `model`.

  must_haves truth 1; `mode` is `"review"` or `"exec"`.
- `SKIP_ROUTES = frozenset({"bad_model", "no_inventory", "not_installed", "unknown_runtime",
  "no_model", "review_only"})`; dispatchable routes: `native`, `subprocess`, `custom`, `unverified`.
- `unroutable_quota(quota: dict, routes: Mapping[str, str]) -> dict`: a copy of `quota` where every
  key whose route is in `SKIP_ROUTES` maps to `{"available": False, "reason": <route>}` (never written
  to the quota cache).
- `RuntimesSeams(NamedTuple)`: `which_fn`, `run_fn`, `popen_fn`, `urlopen_fn`.
- `runtimes_cache_is_fresh(path, env) -> bool`: the existing three-part test moved out of
  `_cmd_detect_runtimes` (mtime within `RUNTIMES_TTL_SECONDS`, `runtimes_schema_is_current`,
  `claude_runtime_is_current` against the catalog at `cache_catalog_path(env)`).
- `load_runtimes_snapshot(env, seams, force=False) -> tuple[dict, bool]`: the cached snapshot when
  not `force` and fresh, else a `build_runtimes_snapshot` written with `cache_write_json`; the bool
  says it was built in this call. Public: the execute lanes (18.1-10, 18.1-15) reuse it.

- `_refresh_runtime(snapshot, rid, seams) -> bool`: re-resolve the binary with
  `resolve_runtime_binary(rid, seams.which_fn)`; found -> `installed` true, `path`, and `models` from
  `list_runtime_models` (key removed when None); not found -> `installed` false. Adds rid to
  `_REFRESHED`; returns True when the row changed.
- `RouteContext(NamedTuple)`: `host: str`, `mode: str`, `env: dict`, `seams: RuntimesSeams`.
- `route_all(entries: list[dict], ctx: RouteContext) -> dict[str, str]`: key -> route for every dict
  entry with a `key`: load (`force=False`), route each entry; the runtimes whose entries routed
  `bad_model`, `unverified` or `not_installed` are refreshed with `_refresh_runtime` unless the
  snapshot was built in this call, the cache file is younger than `REFRESH_FLOOR_S`, or the runtime
  is in `_REFRESHED`; when any row changed, write the snapshot back with `cache_write_json` and
  re-route the affected entries. Public: 18.1-10 and 18.1-15 reuse it.
