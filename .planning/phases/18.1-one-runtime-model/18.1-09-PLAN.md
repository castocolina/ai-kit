<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv -> runner | model ids and deadlines arrive as flags from Python or GSD |
| PATH -> spawned binary | the runner picks which executable to run for a runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-24 | Spoofing | bare `agent` | high | mitigate | `resolveBin` realpath basename check; `bare-agent-guard` and `agent-cursor-realpath` cases |
| T-18.1-25 | Tampering | bracket model id charset | medium | mitigate | brackets only for `--model-cursor`, closed charset with no space, quote, `$`, `;` or leading dash; `cursor-bracket-other-rt` case; argv spawn (no shell) unchanged |
| T-18.1-35 | Tampering | `--append-file` | medium | mitigate | read-only use of one caller-named file; content goes to stdin only, never argv; unreadable file fails closed with usage (`append-file-missing` case) |
| T-18.1-26 | Denial of service | `--outer-timeout` | low | accept | the caller (Python) sets it from its own tier plus a fixed margin; `< 2` is still rejected; values above 1800 are intended for tier 3 |
| T-18.1-27 | Tampering | live supervisor | high | mitigate | `.planning/scripts/cross-ai.mjs` untouched (acceptance `git diff --quiet`) |
| T-18.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | this plan installs nothing |
