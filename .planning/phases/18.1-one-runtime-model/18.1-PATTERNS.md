## Pattern Assignments

### SKR `ai_kit_spec/runner_dispatch.py` (service, process wrapper)

**Analog:** `ai_kit_spec/dispatch.py` (retire `dispatch_with_*` into this).

**Seam style** (dispatch.py:51-56): injectable seams via NamedTuple, no globals.
```python
class HeartbeatDispatchSeams(NamedTuple):
    popen_fn: Callable[..., Any] = subprocess.Popen
    time_fn: Callable[[], float] = time.time
    kill_fn: Callable[[Any], None] = _default_kill_process_group
    print_fn: Callable[..., None] = _default_print_fn
```
**Env scrub** (dispatch.py:69-79): reuse `child_env()` (applies `HOST_SIGNAL_ENV_VARS`, `extra` last). Do not re-implement.

**Spawn core** (dispatch.py:92-107): no shell, stdin prompt via `communicate(input=...)`, own session, `OSError` -> rc 127 dict.
```python
proc = active.popen_fn(argv, stdin=subprocess.PIPE, stdout=subprocess.PIPE,
    stderr=subprocess.PIPE, text=True, encoding="utf-8", errors="replace",
    start_new_session=True, env=child_env())
...
except OSError as exc:
    return {"returncode": 127, "stdout": "", "stderr": str(exc), "timed_out": False}
```
**Timeout loop** (dispatch.py:109-140): `communicate(timeout=min(heartbeat, remaining))`, kill group on expiry. New wrapper: node argv is `["node", runner_path, "--prefer", rt, "--model-<rt>", model, "--mode", mode, "--timeout", n, "--outer-timeout", n]` (flags per `parseArgs`, cross-ai.mjs:801-833). Pass `--outer-timeout` to avoid Pitfall 1 (270 s cap).

**Stderr relay + last-line parse:** runner contract is exactly one `AIKIT-XAI ...` last stderr line (cross-ai.mjs:15-16, validated at 1161-1163). Parse the last non-empty stderr line with `re.fullmatch` on `key=value` tokens; relay all earlier stderr lines via `print_fn`, never swallow them (Pitfall 4). Format source (cross-ai.mjs:207-208):
```js
`AIKIT-XAI status=${status} cli=${fields.cli ?? '-'} model=${fields.model ?? '-'} ` +
`exit=${exit} cli_rc=${fields.cli_rc ?? '-'} elapsed=${elapsed}s out=${fields.out ?? 0} ` +
`tree=${tree} action=${action}`
```
Return a NamedTuple/dict; keep functions within pylint `max-args=5`, `max-statements=50` (Pitfall 7): split into `build_runner_argv`, `run_runner`, `parse_status_line`. Status -> reason is data in `error_classifier.REASONS` (D-23).

## Shared Patterns

- **No shell, argv lists only:** `dispatch.py` spawn core; enforced by Rule 8 over `skills/ai-kit-spec-*`.
- **Env scrub:** `dispatch.child_env` for every child (runner and custom launcher).
- **Atomic config writes:** reuse `_read_json()`/`_write_json()` (tempfile.mkstemp + os.replace) for runtimes.json / catalog; never ad hoc writes.
- **Visible notes, never silent:** `warn_fn` injection (config_io.py:139, quota.py:113); stderr default.
- **Stdlib-only runtime code** (AGENTS.md); no new deps.
- **Confidence labels:** inferred/migrated items flagged in docstrings (Pitfall 9).
