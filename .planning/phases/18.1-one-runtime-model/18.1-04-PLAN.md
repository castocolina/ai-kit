     knobs for keys the entry does not already set; note `cli=<cli> -> runtime=<rid>; command dropped

     Else `runtime = rid` (skipped at routing), note `cli=<cli> has no runner formula; this entry is

  order and non-dict items untouched.

  "claude"`, note `<key>: model '<m>' had no runtime; inferred runtime=claude (pre-1.2 native meaning)`;
