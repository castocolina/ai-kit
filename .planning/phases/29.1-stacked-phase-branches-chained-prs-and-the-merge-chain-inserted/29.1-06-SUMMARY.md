## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug, plans 29.1-01 and 29.1-03] `start` and `restack` failed on a detached HEAD**
- **Found during:** Task 3, the live-check round. `merge-chain --unit-id` on the hotfix left HEAD detached, and `restack` returned `git_error: symbolic-ref --short -q HEAD` instead of its intended `detached_head` refusal.
- **Root cause:** both call sites read `symbolic-ref` through `run_git`, which raises on the exit status 1 that a detached HEAD returns.
- **Fix:** `flow_git.head_branch(repo)` returns `''` when detached; `flow_unit._start` and `flow_stack.cascade` use it. Two regression tests in `TestRemainingBehaviours`.
- **Files:** `skills/ai-kit-commit-fold/scripts/flow_git.py`, `flow_stack.py`, `flow_unit.py`; tests in `tests/test_flow_contract.py`.
- **Commits:** `a132373` (fix), `72c138a` (tests).

### Deviations in the test seam

**2. [Rule 3 - test seam] The fixture gh has no `stack --help`, so the gh-stack probe chose plain gh**
- **Found during:** Task 3, round 1 reported `gh-stack fallback` on its first checkpoint.
- **Fix:** the fixture classes install a `gh` wrapper that answers `stack --help` with exit 0 (`STACK_PROBE`), so round 1 selects gh-stack by the probe, as the plan requires. The shared `tests/forge_fakes.py` is unchanged: giving it `stack --help` would move every existing flow test onto gh-stack.

**3. [Rule 3] Round 1 `restack` needs a unit branch checked out**
- **Found during:** Task 3, after fix 1. A merged hotfix leaves HEAD detached, and `restack` refuses `detached_head` ("check out a unit branch before restacking").
- **Fix:** the live script runs `git switch -q live/r<n>/z` (the top stacked unit) before `restack`. The restack refusal itself is unchanged.
