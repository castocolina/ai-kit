## Pattern Assignments

### `fold.py` and new flow modules (CLI plus services)

**Analog:** `skills/ai-kit-commit-fold/scripts/fold.py`. Keep the non-required subparsers, `_add_common(--repo)`, `_phase` type check, exit codes (0 ok, 1 refused, 2 bad input), and the one-render `_emit(result)` that prints `fold_engine.render_report`.
```python
sub = parser.add_subparsers(dest="command")          # fold.py build_parser
status = sub.add_parser("status", help="list each plan of a phase as folded or not")
status.add_argument("--phase", required=True, type=_phase)
_add_common(status)
```
**Error type:** raise `fold_engine.FoldError(reason, detail)`; map to a refused `Result` in the CLI layer (`_refused`, fold.py ~75). New commands reuse the same shape (reason code plus detail, report at real certainty).
**Subprocess rule:** argv list, never `shell=True`, `_run`/`_git` helpers in `fold_engine.py` (162-190); put `gh`/`git push` calls behind one small `flow_forge.py` function so tests fake only that PATH entry.
**Checkpoint = fold, then push:** call `fold_engine.fold(...)` as `_gsd` does (fold.py ~100), then push with `--force-with-lease=<ref>:<expected-old>` (never plain `--force`). Arch rule below enforces it.
**Lookup:** modules find sibling skills only via the D-13 installed-skill lookup (`SKILLS_ROOTS` mirrored in `ai-kit-fold.cjs`); no cross-skill imports.

### Atomic stack record and `.aikit/` settings

**Analog:** `tools/setup.py` 1857 (`_read_json_checked`) and 1878 (`_atomic_write_json`, `tempfile.mkstemp()` + `os.replace()`). Runtime flow code is stdlib-only and must not import `tools/`; re-implement the same ~15 lines in `flow_store.py` and note the origin. Stack record path: `git rev-parse --git-dir` + `/ai-kit-stack.json`; lock file beside it (D-15). `.aikit/` ignore check: `git check-ignore -q .aikit`; offer `.git/info/exclude`.

### GSD capability (`capability.json`, `ai-kit-fold.cjs`)

**Analog:** itself. Add one `steps[]` entry per hook, same shape as the existing one:
```json
{"point": "execute:wave:post", "ref": {"command": "ai-kit-fold run"},
 "produces": [], "consumes": [], "onError": "skip"}
```
Use `"onError": "skip"` for checkpoint/ready, but a guard (`execute:wave:pre`) and `ship:pre` gate must be able to refuse: spike first whether `onError` can block (Phase 29 D-02 rule: if a hook form cannot run the command, planning returns to the owner). `route({args, cwd})` currently accepts only `run --phase N`; extend the verb switch (`start|guard|checkpoint|ready|gate`) keeping fixed argv via `spawnSync`, no shell. `findFold()` lookup stays the single copy.

### Tests

**Analog:** `tests/fold_fixtures.py` (`git_env(home)` pins `GIT_CONFIG_GLOBAL/SYSTEM=/dev/null`, identity, scrubs `HOST_CONFIG_VARS`; `run_git`, `make_repo`, `commit`, `merge_no_ff`, `set_ref`). Add `make_remote(root, env)` (`git init --bare`, add as `origin`) beside them, so tests use local bare remotes.
**Fake helper:** `tests/host_fakes.py` is the only file allowed to name host binaries; it writes executable fakes that log JSON lines and answer from a table keyed by argv tuple.
```python
bin_dir = write_host_fakes(bin, answers={"gh": {("pr","create",...): (0, "https://...\n")}}, log_path=log)
env["PATH"] = host_path(bin_dir)
calls = fake_calls(log)
```

Extend it (or a sibling `forge_fakes.py` re-using its `_FAKE` template) to cover `gh` and `gh-stack`; add `gh` and `gh-stack` to `HOST_NAMES`/the tripwire list in `tools/run_unittest_parallel.py` (`HOST_CLI_NAMES`, 189-193, pinned by a drift test; update that test). `git push` is real against the bare remote; only `gh` is faked. Each test under 0.3 s, no sleeps, `AI_KIT_REFUSE_REAL_HOME=1`.
**Test header shape** (`test_ai_kit_commit_fold_adapters.py` 1-20): imports from `tests.fold_fixtures`, `tempfile` roots with `addCleanup(shutil.rmtree, ...)`.

## Shared Patterns

- **Refuse, never half-apply:** `FoldError` plus the guard-before-write order in `fold_engine._guard` (379); restack/cascade must restore every branch on a failed resolution (D-07).
- **No real host or home:** `git_env(home)`, scratch HOME, `AI_KIT_REFUSE_REAL_HOME=1`, tripwire PATH.
- **Installed-skill lookup, one copy per language:** Python `SKILLS_ROOTS` in the ladder code and the JS copy in `ai-kit-fold.cjs`; the drift test pins them.
- **Atomic writes** for every config or record file.
- **Report at real certainty:** `render_report` style, at most about five lines, no colour codes.
