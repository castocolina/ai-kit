### Deviations from the plan's wording

**2. [Scope - sync pre-empts a moved remote target] `trunk_moved` refuses before `mvp_diverged`** (open, for the orchestrator)
- **Found during:** Task 3 test of a remote main moved by a non-merge commit.
- **Issue:** `flow_stack.sync` (plan 01) refuses `trunk_moved` before the MVP checks run, so the remote-moved case reports `trunk_moved`, not `mvp_diverged`. Main is unchanged in both cases. The `mvp_diverged` remote check is a second line of defence, reached only when sync does not see the move.
- **Action:** the test asserts `trunk_moved` and carries a comment. Not edited here: `flow_stack.py` is plan 01's file and plan 03 is replacing the trunk_moved refusal with a cascade in parallel. The orchestrator should decide after plan 03 lands whether the MVP refusal order needs a change.

**3. [Test seam] `AI_KIT_FLOW_PR_BACKEND=gh-stack`** (open, for the orchestrator)
- The fake gh (`tests/forge_fakes.py`, not edited by this plan) does not answer `gh stack --help` (exit 1), so the probe would always pick plain gh under test. The env value `gh-stack` forces the stack path. The probe itself is untested. Suggested change for the orchestrator: make the fake answer `stack --help` with exit 0 when `GH_STACK` is set.

**4. [Design] Lease after the first push**
- The plan's Task 1 wording asked for a plain push when the branch was not rewritten. The plan 01 contract says the lease is the recorded `pushed` sha for every push after the first, so a concurrent push is refused as `stale_lease`. Implemented as the contract says.

**5. [Design] Ready order is stricter than the plan's catch-up wording**
- The plan asked for bottom-up ready inside a catch-up run. The fix cycle enforces it in `_ready` instead: a unit cannot become ready while an unmerged stacked unit below it is not ready. Any run that tries the top first is refused with `signal_order`, which is the R4 ordering rule in its strictest form.

**6. [Process] No jev-fast-decision calls**
- The decisions above were design and lint choices made directly; none was routed through the jev ladder. Recorded here rather than logged as jev calls.
