<objective>
Make the pre-summary hook its own setup knob through a hook registry that Phase 21.3 extends:
headless install by id and host, grouped atomic writes, symlink rows for pi and opencode, and
per-id uninstall (SPEC R10; D-10..D-13).

Purpose: the owner wants each hook installable and removable on its own, with the default per
host following the measured verdict; the registry is the one table every later hook joins
(PCH-02).
Output: setup.py registry and wiring, the unit and e2e test modules, README headless and
uninstall docs.

Rules binding every task: `tools/setup.py`'s non-wizard paths stay stdlib-only; every config write
goes through `_read_json_checked`/`_atomic_write_json`; every test runs under temp `HOME`,
`AI_KIT_DIR`, `CLAUDE_CONFIG_DIR`, `CURSOR_CONFIG_DIR`, `PI_CODING_AGENT_DIR`,
`OPENCODE_CONFIG_DIR`, `XDG_CONFIG_HOME` and `XDG_STATE_HOME` (absent dirs where a host must be
absent), never the real home; keep every Phase 21.1 addition to setup.py (`pi_dir`,
`PI_SKILLS`, `sync_pi_links`, `replace_existing`, `--replace-existing`) exactly as it is, and read
the file first: line numbers in older plans have drifted, so this plan names functions only. The
existing tests in tests/test_setup.py and tests/test_tool_substitution_hook.py stay green
unchanged.
</objective>
