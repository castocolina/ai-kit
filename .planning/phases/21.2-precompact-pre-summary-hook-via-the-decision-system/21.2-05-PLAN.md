<interfaces>
opencode plugin API (local `@opencode-ai/plugin` 1.18.5 types and opencode.ai/docs/plugins, read
at planning time):
- `export const X = async ({client, directory, worktree, project, $}) => hooks`; opencode calls
  every exported plugin function, so the module exports one function only.
- `"experimental.session.compacting": (input: {sessionID: string}, output: {context: string[];
  prompt?: string}) => Promise<void>`; `context` strings are appended to the default compaction
  prompt; setting `prompt` replaces it entirely and then `context` is ignored.
- `client.session.messages({path: {id}, query?: {limit}})` resolves `{data, error, ...}` where
  `data` is `Array<{info: Message, parts: Part[]}>`; `info.role` `user`/`assistant`,
  `info.time.created` (ms), assistant `summary?: boolean`; parts: `text` (`text`, `synthetic?`,
  `ignored?`), `tool` (`tool`, `state.status`, `state.output`, `state.time.compacted?`),
  `reasoning`, `file` (`url` may be a `data:` URI), `compaction` (`auto`), plus step and snapshot
  parts to ignore.
Core and shim precedent from 21.2-04: `main(argv)` with the `opencode` branch, `run_pi`,
`messages_from_pi`, `presummarize`, `private_dir`, `write_presummary`; the pi shim's `corePath`,
`replacer`, `runCore` and `TIMEOUT_MS`, which the plugin repeats inside its own file (a plugin file
cannot import a sibling: each link is one file).
