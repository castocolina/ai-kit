<objective>
Deliver the pre-summary to pi, where it replaces the summarization call, and to opencode, where
it adds compaction context, through two thin TypeScript shims over the core's `pi` and `opencode`
entries (SPEC R6, R7, R8; D-07, D-08, D-09, D-18).

Purpose: pi is the host where the saving can be real, and it must never lose earlier history;
opencode's hook is experimental, so its plugin must be harmless whenever it adds nothing (PCH-01).
Output: both shims, the two core entries and `main`, one shared node harness, unit and e2e tests,
the README host rows.

Rules binding every task: the plan 21.2-01 rules. The shims use only erasable TypeScript (type
annotations and `import type`; no enums, namespaces or parameter properties) so node's type
stripping and pi's loader both run them; no npm dependency, no runtime import from a host
package. Node tests run `node` from PATH (no `npx`, no install) and skip only when node is absent
or lacks type stripping; no test runs pi or opencode. Failure cases common to both hosts are one
parametrized test each (`subTest` per host). Live host behavior is the orchestrator's S3/S4 check
in `21.2-SPIKE.md`.
</objective>
