# Plan 21.2-01: Pre-summary core and the Claude PreCompact-to-SessionStart route — Summary

**A stdlib pre-summary core turns a Claude PreCompact payload into a private, classified, 9,500-character-capped file that the compact SessionStart hook injects once, deletes, and can never block on.**

## Performance

- **Duration:** ~75 min (across two executor runs)
- **Completed:** 2026-10-23
- **Tasks:** 3 of 3
- **Files modified:** 10

## Accomplishments
- `tools/hooks/precompact_core.py`: host-neutral chunking (whole messages, line-boundary splits, cut markers), one-client-process-per-chunk classification newest-first inside an 8 s budget, extractive build capped at `CAP_CHARS = 9500`, private 0700 dir with cache fallback, atomic 0600 writes, 24 h sweep, and the defensive Claude transcript reader whose `last_boundary` is a verbatim copy of status-line's rule, pinned by a parity test.
- `tools/hooks/claude_precompact.py`: one script, two events — PreCompact prepares (`{}`, exit 0), compact SessionStart injects the matching session's file via `os.scandir` + header equality and deletes it; no path emits a `decision` field.
- `read_stdin(limit)` extracted in `tools/hooks/claude_session_start.py` with a real ceiling (EOF / 0.5 s idle / over-limit / 5 s), no fixed round count; existing briefing tests stay green.
- 41 new tests across two modules (22 core, 19 Claude), the env-driven stub client, a realistic two-boundary transcript fixture, the README `## PreCompact pre-summary` section, and regenerated test-group listings.

## Decisions Made
- `CHUNK_STATE_CHARS = 1600` is provisional (0.8 x the client's laya `state_chars_limit`); plan 21.2-03 S1 lowers it to the measured Laya bound (D-03).
- No live host was used anywhere in this plan: every verification runs the hook as a subprocess against the stub client in a scratch HOME/XDG tree, per plan scope. Live checks and measurements belong to plan 21.2-02 and the orchestrator.
- T-21.2-05 (second-order prompt injection: old tool output promoted into `additionalContext`) is reduced, not removed: tool results are cut to head lines, thinking and `<system-reminder>` spans are dropped, and the header tells the reader to treat excerpts as data. Residual risk stands.
- `classify_all` walks chunks newest first and never starts a call below a 0.01 s remainder; unclassified chunks count as `keep` content and are what the cap trims first.
