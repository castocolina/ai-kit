# Plan 21.2-04 Summary: pi and opencode pre-summary shims over the core

Replaced pi's compaction summarization call and added opencode compaction
context through two thin, self-contained TypeScript shims over the shared
Python core, both fail-open with a hard 10 s budget, unit- and node-run-e2e
tested without starting either host.

## Accomplishments

- pi shim: on `session_before_compact` passes preparation (messagesToSummarize,
  turnPrefixMessages, previousSummary, fileOps) plus session id/name/cwd to
  `python3 -S precompact_core.py pi`, returns `{compaction: {summary,
  firstKeptEntryId, tokensBefore, details}}` with the event's own ids, and
  returns `undefined` on any failure so pi's default compaction runs (SPEC R6).
- opencode plugin: one named export `AiKitPrecompact` with only
  `experimental.session.compacting`; fetch raced against the shared deadline,
  result pushed onto `output.context` exactly once, `output.prompt` never set
  (SPEC R7, D-09, T-21.2-19/20).
- Core: `messages_from_pi` (role map incl. bashExecution head lines,
  compactionSummary skipped, unknown roles counted), `file_list_block`
  (pi's read/modified semantics), `run_pi` (pinned previous summary + file-list
  tail, write-then-unlink), `messages_from_opencode` (created-order sort, last
  boundary, `boundary_unrecognized` flag), `run_opencode`, `main` with the
  MAX_STDIN_BYTES contract (`{}` on over-cap/bad input, always exit 0).
- D-08: `apply_cap` gained `pinned` (never trimmed) and `tail` (path-by-path
  trimming with `(+N more)`) entries; header+pinned+newest-kept over cap → None.
- Failure paths proven e2e for both hosts: missing interpreter, exit-0-empty
  stdout, backend down, hanging interpreter killed at exactly TIMEOUT_MS
  (exec'd in-process sleeper, elapsed asserted 9.5–11 s, pid reaped), aborted
  signal, empty input, image `data`/`data:` URLs blanked before stdin.
- README host rows (pi; opencode labelled experimental pending S4) and
  D-08/file-list sentences in the PreCompact section.
