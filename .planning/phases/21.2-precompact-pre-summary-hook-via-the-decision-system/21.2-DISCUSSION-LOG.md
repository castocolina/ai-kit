## Live facts that changed the plan

- pi's `session_before_compact` can return the summary itself. pi's preparation also carries
  `previousSummary` and `turnPrefixMessages`, so a replacement summary must carry them (D-08,
  SPEC R6 amended).
- opencode's compacting hook input has only `sessionID`, so messages come through the SDK
  client (D-09). The installed opencode is v2.0.31, while the local plugin types are 1.18.5
  (spike).
- `--headless --with-hooks install` parses `install` as the option value (live argparse),
  which is why ids are validated (D-13).
- Claude Code measures each hook output string on its own (docs), so the briefing and the
  pre-summary each have their own 10,000-character budget.
