## 21.1-02

### Summary
Escalation, consent and logging have the right shared owner. The prior retry, append-log and deadline-classification findings are addressed. However, the current ladder can finalize a known-truncated answer, and the proposed timeout mechanism does not establish the promised total wall-clock deadline.

### Cycle-1 dispositions
| Finding | Disposition | Evidence |
|---|---|---|
| Exhausted 503 loses ladder eligibility | **RESOLVED** | P02:218,231–234 tests and preserves its `escalate` trail entry. |
| Unenforced 4-KiB premise and short writes | **RESOLVED for accepted residue** | P02:282,288–297 removes the size premise and stops after a short write. The regular-file/`PIPE_BUF` rejection remains valid. |
| In-flight deadline expiry becomes network failure | **RESOLVED as classification** | P02:283–285,304–312 explicitly returns final `deadline` errors. Actual deadline enforcement remains a separate concern below. |

### Strengths
- Consent migration preserves the existing path, per-backend record and hostname binding (**P02:243–251**; `skills/ai-kit-gsd-spec-discuss/scripts/decide.py:174–219,427–440`).
- The log uses an explicit field list, with distinct tests for excluded content, permissions, symlinks, concurrent append and short writes (**P02:278–303**).

### Concerns
- **HIGH — High-probability truncated answers can become final.** P01:240,299–301 requires truncation/state-size conditions to set `needs_fallback: true`. But **P02:229–231** declares `top >= threshold` sufficient for finality, without consulting that flag. The inherited code also overwrites `needs_fallback` from probability alone (**V3:482–487**). A truncated local answer at 0.95 can therefore stop escalation.
- **HIGH — Socket timeout is not a total deadline.** **P02:304–312** shrinks each request timeout and classifies failures after expiry. The retained transport uses `open(timeout=...)` followed by `stream.read()` (**V3:345–346**). A server continuously delivering bytes can exceed the total deadline without the exception on which this mechanism depends. The sleeping-response test at **P02:283** does not exercise that case.

### Suggestions
- Define confidence as sufficient probability **and absence of forced-fallback conditions**. Preserve truncation flags when applying thresholds.
- Test a high-top truncated answer in both auto and explicit-local modes.
- Enforce an absolute monotonic deadline throughout response consumption and include probe time in the budget. Test a slow-drip response, retained earlier answers and zero post-deadline escalation.

### Risk Assessment
**HIGH.** These gaps affect whether incomplete evidence is accepted and whether partial results return before the caller kills the process.
