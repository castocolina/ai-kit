# Plan 21.1-04: installer pi root, backups and --replace-existing Summary

**`jev-fast-decision` now installs for pi as well (a derived second link root), every unlink/prune path covers both roots, and a real copy at a link path is backed up to XDG state and replaced only on an explicit `--replace-existing`.**

## Performance

- **Duration:** ~95 min
- **Completed:** 2026-10-22T23:15-03:00
- **Tasks:** 3
- **Files modified:** 8 (1 created)

## Accomplishments
- `resolve_paths` gains `pi_dir` (`PI_CODING_AGENT_DIR` or `~/.pi/agent`) and `backups_dir` (`${XDG_STATE_HOME:-~/.local/state}/ai-kit/backups`); `PI_SKILLS = frozenset({"jev-fast-decision"})` is the constant set (D-14, Phase 22 widens it).
- `sync_pi_links` runs on exactly two paths: the wizard commit (mirror — unlinks only a `PI_SKILLS` repo entry the commit's selection leaves unchecked) and headless with `--skills` (additive only). Bare `--headless` and hooks/statusline-only runs never touch the pi root (T-21.1-30).
- `cmd_uninstall`, the stale gate (`skills/<name> (pi)` entries) and the predecessor gate all cover the pi root; housekeeping runs quiet on the Textual worker thread and returns its `log`; a pi-only repoint pre-checks the skill in the returned selection so the commit keeps it — even when `link_one` leaves a real dir or foreign link at the claude path alone (pinned by `test_pi_repoint_kept_when_claude_blocked`).
- Predecessor detection now requires a dangling target (a live ai-kit-shaped link is foreign content for the replace path), and every predecessor repoint/removal first moves the old link into `<backups_dir>/<root>/<name>.bak-<stamp>/` (exclusive `os.mkdir` claim, `-1`/`-2` numbering; a failed move keeps a non-empty claim, names source and destination, and re-raises).
- Headless `--replace-existing` (requires `--headless --skills`) moves real dirs/files/foreign or dangling links into the per-root backup, links the repo copy, restores the entry and exits 1 when linking or the move fails; e2e module `tests/test_jev_skill_install_e2e.py` (8 tests, HOME with a space) registered in `E2E_MODULES` via `gen_test_groups.py`.
- All five PTY env dicts in `tests/test_wizard_pty.py` now set the five scratch roots; the static `test_every_pty_env_isolates_host_roots` guard (AST over the module's own source, with a non-vacuity case) enforces it.
- README installer and headless sections document the pi root, `--replace-existing` and the backup path.

## Decisions Made
- Deliberate claude-root behavior change (Task 2): a **live** ai-kit-shaped agent, command or skill link is no longer offered for repoint — skills go to the replace path (`--replace-existing` / 21.1-05's wizard gate), agents and commands are left alone with `link_one`'s warning.
- The wizard gate text no longer claims ownership or irreversibility: both answers keep the old link in the backups dir.
- Housekeeping never calls `sync_pi_links`; the prune, the repoint and (21.1-05) the replace act on the pi root themselves.
