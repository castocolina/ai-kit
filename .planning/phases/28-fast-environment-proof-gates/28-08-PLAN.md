Facts for the environments (verified at planning time):
- The runner always runs modules with cwd = the checkout and (after plan 28-01) the tripwire first on PATH, a temp HOME and its own TMPDIR under the caller's TMPDIR. So the environments differ mainly before the runner (make, uv) and in TMPDIR placement and checkout path.
- `.claude/gsd-core` is gitignored but the e2e tier runs it; `.venv` is gitignored and `pyproject.toml` has `[tool.uv] package = false`, so a second checkout can reuse the source venv through `UV_PROJECT_ENVIRONMENT` without uv installing anything into it.
- `tests/test_arch.py` skips git-history checks with a named reason outside a git work tree, so the long-path copy must be a real clone with history, not a file copy.
- `copilot` lives in the same directory as `python3` on this machine, so "no host CLI on PATH" cannot drop whole PATH directories; it needs a farm of symlinks to every other executable.
- The Makefile rule `test_tiers_run_through_the_runner` forbids a `-m unittest` recipe; the new target calls the tool.
- `make test` runs about as long as its four tiers together; six runs take about six times that, so run the matrix in the background and wait for its exit.
- Nested runners exist on purpose: `tests/test_run_unittest_parallel.py` starts the runner on `tests.test_arch tests.no_such_module` (lines 24-38) and on synthetic and timeout modules; an inherited report folder would publish those intentional child failures.
- `git ls-files -m -o` and `-d` compare the working tree with the index only, so a staged-only change would be missing from a clone overlay built on them; `git diff --name-only -z HEAD` lists every path that differs from HEAD, staged or not.
- `uv run` syncs the project env by default; `UV_NO_SYNC=1` (uv 0.11.28 here: `[env: UV_NO_SYNC=]`, implies `--frozen`) stops it.
- A scratch HOME hides `~/.volta` and `~/.local/share/uv/python`: plan 28-01's `tool_cache_forwards` computes them only when the folder exists under the HOME it is given, so the matrix must call it on the caller's environment before replacing HOME, or the volta `node` shim fails (`Volta error: Node is not available`) and nested `uv` finds no Python 3.12.
- `Makefile` `test` lists four independent tier prerequisites, each with its own runner pool; an inherited `MAKEFLAGS=-j` (or an outer `make -jN`) would run them together.
- `git diff --name-only HEAD` reports a rename as one new path unless `--no-renames` is given; `shutil.copy2` onto an existing symlink writes through it, and `os.path.exists` is false for a dangling symlink.
- Run rules: the list in 28-01-PLAN.md `<context>`. This plan is the only plan of wave 7, so its matrix runs have the machine to themselves.
