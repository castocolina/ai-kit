<objective>
No test reaches a real host CLI, and every module starts from the same pinned environment.

The runner puts a tripwire folder first on every module's PATH (one stub per host CLI name, logging and exiting 127), fails any module whose tripwire log is non-empty, and gives every module a baseline environment: no host signals, no inherited git state, a temporary HOME. The two real host callers (the goal-prompt eval module and the curated-config eval helper) move to one shared fake helper. The real Mermaid render, which needs Chrome from the caller's HOME, moves to an e2e module with named skips.

Purpose: GATE-02 (fakes only, which removes the 162 s pole of the push) and the environment half of GATE-03 (D-04, D-05 run-time layer, D-06, D-09).
Output: tripwire and baseline env in the runner, `tests/host_fakes.py`, the reworked callers, `tests/test_markdown_to_pdf_e2e.py`, drift tests.

This plan verifies only its own modules. The all-tier run of the tripwire and baseline (and the fix of every module they break) is plan 28-02 Task 4, after wave 1 (this plan and 28-03) has landed and 28-02's own edits are in, so no all-tier run overlaps another plan's edits (Addresses review concern: wave 1 verification not independent).
</objective>
