## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Session-log file → raw capture parser | Untrusted-shaped input: a Claude Code JSONL line's content (including any command text a past session ran) flows into this pipeline's parsers. The FILES themselves are already local and already readable by this user (no privilege boundary crossed), but their CONTENT (arbitrary command strings, file paths) must never be trusted to be well-formed JSON, valid UTF-8, or free of characters meaningful to a downstream consumer (SQL, HTML). |
| Refined SQLite → dashboard HTML generator | The refined store's `command_text` column can contain ANY string a past AI-CLI session ever ran, including one deliberately or accidentally shaped to break out of an HTML `<script>` embedding context. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | `dashboard.py::generate`'s embedded JSON payload | medium | mitigate | Every literal `</script` substring inside the serialized JSON is replaced with `<\/script` before embedding, so a captured command like `echo '</script><script>alert(1)</script>'` can never prematurely close the embedding tag or inject a second script context into the locally-opened dashboard HTML. Pinned by an executed test in Task 1. |

Pinned by a structural grep-based check in this plan's `<verify>`. |
| T-05-03 | Information Disclosure | Raw/refined store location | medium | mitigate | **[Round 1, revised from "low/accept"]** The raw and refined stores hold verbatim session content (commands, file paths, and now — per this Round's losslessness fix — even malformed-line raw text) under `~/.local/share/ai-kit/usage-metrics/`.
