In `gsd_catalog.py`, add `query_agent_catalog(node_bin, model_catalog_path,
run_fn=subprocess.run)`. Build the argv
`[node_bin, "-e", <inline script>, model_catalog_path]` where `<inline
script>` is a single-line Node expression that requires
`process.argv[1]` (so the path is passed as a real argv element, never
string-interpolated into the script body — avoids any quoting hazard from a
path containing a space or quote character) and writes
`JSON.stringify({tiers: m.AGENT_DEFAULT_TIERS, phaseTypes:
m.AGENT_TO_PHASE_TYPE})` to stdout, wrapped so that if `require()` throws (a
future gsd-core version without these exports) the script instead writes the
literal string `null` to stdout and exits 0 rather than a non-zero exit with a
stack trace on stderr — this makes "exports missing" and "require failed"
both collapse to the SAME detectable signal (`stdout == "null"`) rather than
needing the caller to parse a Node stack trace. Run it via `run_fn` with
`capture_output=True`, `text=True`, `check=False`, a bounded `timeout` (10
seconds — this is a pure, instant `require()` + `JSON.stringify()`, never a
network call, so a hang here means something is fundamentally wrong and the
caller should treat it as a failure, not wait indefinitely). Parse stdout with
`json.loads`, catching `json.JSONDecodeError`/`subprocess.TimeoutExpired`;
return `None` whenever: the exit code is non-zero, parsing fails, the parsed
value is not a dict, `"tiers"`/`"phaseTypes"` keys are missing, or either is
not itself a non-empty dict. Otherwise return the parsed `{"tiers":...,
"phaseTypes":...}` dict unchanged.
