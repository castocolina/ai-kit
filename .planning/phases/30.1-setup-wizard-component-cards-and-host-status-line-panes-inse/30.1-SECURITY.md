> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| user config file -> doctor applier | a hand-edited, possibly broken settings.json / opencode.jsonc / config.toml is read and rewritten | user config (may hold keys; never printed) |
| doctor -> backups folder | backup files are created and pruned in XDG state | copies of user config |
| doctor screen -> applier | a confirmed row apply writes a user config file | one config value |
| renderer subprocess output -> terminal | the status-line render, with third-party segment output inside it, is shown in the wizard | untrusted text with escape sequences |
| wizard Review -> setup commit | the view's states decide which host files are written | host config writes |
| host config file -> setup | a foreign tool may own or rewrite `statusLine` while the wizard is open | `statusLine` command |
| user key presses -> host config writes | Review confirm and the foreign modal decide which files the commit touches | consent |
| PTY test -> real filesystem | the installer runs for real; every root must stay inside the scratch HOME | test writes |
