# Phase 30.1 — UI Design Contract

> Visual and interaction contract for a Textual terminal UI (`tools/wizard_app.py`, `tools/config_doctor_app.py`). Not a web frontend: spacing is in terminal cells, typography is bold/dim/reverse, colour is hex that Textual downgrades to 256 colours on limited terminals. Every decision tagged D-nn is locked in `30.1-CONTEXT.md` and copied here, not re-decided. Items marked "(discretion)" were open under Claude's Discretion and are picked here.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Textual 8.2.7 TUI, no shadcn, no `components.json`) |
| Preset | not applicable |

## Spacing Scale

Unit: one terminal cell (columns) or one row. No web scale.

| Token | Value | Usage |
|-------|-------|-------|
| gap | 1 cell | Between chips is 2 spaces (existing); band padding, tray `padding: 0 1` |
| indent | 2 cells | Item row marker column (`▌ ` or two spaces), same as today |
| name column | 30 cells | Item name padded to 30 (D-02, `_choose_component_row`) |
| block gap | 1 row | `margin-bottom: 1` between lanes, tray and preview (existing) |
| band | 1 row | Host band is exactly one row high (D-03) |
| tab row | 1 row | Sits directly above the card, no blank row between |

Exceptions: item descriptions are cut at the card width, not wrapped (D-02). Minimum supported terminal is today's wizard minimum; Line 2 needs 20 rows and Line 3 needs 30 rows (existing `LANE_GATE`), unchanged.

---

## Typography

Terminal text has one size. Roles are bold, dim and reverse on the existing palette.

| Role | Style | Usage |
|------|-------|-------|
| Body | regular, `FG #c9d1d9` | Item rows, descriptions, review lines |
| Muted | `DIM #6e7681` | Inactive tabs, off-board, hints, counts, notices that are not warnings |
| Strong | bold | Active tab, band host name, step title, section heads |
| Cursor | reverse | Existing row/chip highlight; unchanged |

Weights: exactly two (regular, bold). Line height is one row; no blank row inside a card.

## Color

Palette constants stay in `wizard_app.py`; this phase adds two named constants beside them (D-03).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d1117` | Screen background, band text colour |
| Secondary (30%) | `LINE #30363d`, `KEYCAP #21262d`, `FG #c9d1d9` | Borders, footer keycaps, body text |
| Accent (10%) | `ACCENT #58a6ff` | Active tab, step title, modal border, focus chrome (existing) |
| Host accent: Claude | `HOST_CLAUDE #D97757` | Claude Code band fill only (contrast 6.06 with `#0d1117`) |
| Host accent: Cursor | `HOST_CURSOR #8B949E` | Cursor CLI band fill only (contrast 6.15 with `#0d1117`) |
| Destructive/warn | `WARN #d29922` | Foreign remove/replace modal heading, "incomplete" states |
| Other existing | `GREEN #3fb950` done/on, `PINK #db61a2` chip focus, `CYAN #39c5cf` lane borders (unchanged, D-03) | |

Accent (ACCENT) reserved for: active tab label, step title, modal border, `d`/`o` keycap emphasis in the footer. Host band fills are not the accent; they identify the host. White text on either band fails contrast, so band text is always `#0d1117`. State is never colour alone: active tab has brackets plus bold, off toggle has a glyph position (`●` marks the active side), locked board is dimmed and carries a text line.

## Interaction Contract

Keys (footers use the existing `FOOTERS` shape: label, keycap, primary):

| Screen | Keys |
|--------|------|
| Choose | `←→` Kind (wraps), `↑↓` move in card (wraps), `Space` toggle, `a/n` this kind, `A/N` all, `Enter` Continue, `?` Help, `q` Quit. Each kind keeps its own cursor. |
| Host pane (on) | existing board keys plus `o` Status line on/off; `Enter` Continue, `Esc` Back |
| Host pane (off) | only `o`, `Enter`, `Esc`, `?`, `q` act; `Space ↑↓←→ Tab r` are ignored and show the locked-key notice |
| Host pane (foreign entry; amended 2026-11-06) | `o` cycles keep → remove → customize → keep; keep and remove act like the off pane (locked, foreign locked-key notice); customize acts like the on pane, starting from ai-kit's default arrangement; the arrangement is kept across the cycle, so customize shows the owner's last arrangement |
| Every detected host's pane is visited, including an already-ours host (D-04) |
| Review | `Enter` Install, `Esc` Back, `?` Help |
| Foreign modal | `n`/`Enter`/`Esc` = No (default focus on No), `y` = Yes |
| Done | `Enter` Finish & exit, `d` open doctor (only after commit finished), `q` |
| Doctor screen | existing doctor keys (`a` Apply, per-row confirm `y`/`n`); `Esc` pops back to Done in the wizard, `q` quits `--config-doctor` |

Preview behaviour: debounce 150 ms (discretion, inside the 100-300 ms range), only the newest result is applied, 2 s timeout falls back to samples. Render width is the preview panel's inner width; rows unlimited (D-10, D-11).

## Focal Points

- Choose: the active tab and its card.
- Host panes: the host band (name and toggle) above the board.
- Review: the per-host outcome lines and the confirm line.
- Done: the outcome text, then the `d` hint line.
