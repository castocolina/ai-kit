## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Textual App swallows Resize, so `on_resize` never ran**
- **Found during:** Task 1 test run (resize test)
- **Issue:** `App._on_resize` calls `event.stop()`, so a WizardApp `on_resize` method never fires.
- **Fix:** Override `async def _on_resize`, calling `super()._on_resize(event)` first, then scheduling the re-key with a 0.05 s timer (the screen takes the new size after Textual's own deferred check).
- **Acceptance impact:** the plan's `grep -c 'def on_resize'` prints 0; the hook is `_on_resize`.
- **Commit:** `20cd724`

**2. [Rule 1 - Bug] Textual timers reject a zero interval**
- **Found during:** Task 1 test run
- **Issue:** `debounce_s = 0` raises `ZeroDivisionError` inside Textual's timer loop.
- **Fix:** the tests use `debounce_s = 0.01`; the default stays 0.15 s.
- **Commit:** `20cd724`

**3. [Rule 3 - Blocking] pylint and pyright gates**
- `PreviewState` has the eight fields the plan specifies; pylint `too-many-instance-attributes` is disabled on that dataclass, with the reason on the line above the class.
- `HostView.engine` is untyped (`object`); the worker casts it to `Any` at its one call site.
- `_key_review` returns more often after the `g` branch; `too-many-return-statements` is disabled on that one method.
- **Commit:** `20cd724` (pylint), `3589487` (pyright), `a23d8a3` (pylint on `_key_review`)

**4. [Rule 1 - Bug] Choose card scroll ran before layout**
- **Found during:** Task 2 test run (25-skill scroll test)
- **Issue:** `scroll_to` ran in the render before `#step-choose` had its size, so the cursor row never scrolled into view.
- **Fix:** the scroll is deferred with `call_after_refresh`.
- **Commit:** `a23d8a3`

**5. [Rule 3 - Blocking] PTY checks written against the old flat Choose**
- `tests/test_wizard_pty.py` asserted the old `select components` title and the uppercase `HOOKS` category, and one test expected every hook row on the first Choose screen. Now the first frame is checked for the step title `Choose what to install`, the hooks card is checked after `→ →`, and the curl|bash path checks the `skills ` tab. Selection is unchanged by tab switching.
- **Commit:** `a23d8a3`
