Doctor helpers (`tools/config_doctor_appliers.py`, plan 01):
- `backups_root(env) -> str`: `os.path.join(env.get("XDG_STATE_HOME") or os.path.join(env.get("HOME", ""), ".local", "state"), "ai-kit", "backups")`, the same formula as `setup.resolve_paths(env).backups_dir` (plan 04 makes `resolve_paths` call it).
- `backup_before_write(path, backups_dir, label, keep=10, now=None) -> str`: missing `path` returns `""`; a relative `backups_dir` raises `OSError("backups dir is not absolute: ...")`; creates `<backups_dir>/<label>/` (mode 0o700); claims `<basename>.<%Y%m%dT%H%M%S%fZ>.bak` exclusively (write a temp file in that folder, fsync, `os.link` to the name; on `FileExistsError` try `-1`, `-2`, ... before `.bak`), mode 0o600, removes the temp file; then `prune_backups(folder, basename, keep, exclude=new_path)`; returns the new path. `now` is a timezone-aware `datetime` (default `datetime.now(timezone.utc)`). Raises `OSError` on any failure.
- `prune_backups(folder, basename, keep, exclude) -> list[str]`: files matching `^<re.escape(basename)>\.\d{8}T\d{12}Z(-\d+)?\.bak$`, sorted newest first by `(st_mtime_ns, name)`, `exclude` never deleted and counted first; deletes beyond `keep`; returns the deleted paths.
- `apply_guarded(path, compute, dry, *, parse, kind, write, backups_dir, label, before_replace=None) -> dict`: reads the bytes of `path` (missing: `None`) and decodes them as UTF-8; when present, `parse(text)` must return a dict, else (exception in `(ValueError, TypeError, UnicodeDecodeError)` or a non-dict) it returns `{"ok": False, "reason": "refused: <path> was not changed: it cannot be parsed as <kind>. Nothing was written; fix the file by hand, then run the check again"}` (`kind` is "a JSON object", "a JSONC object" or "a TOML table"); `compute(text_or_None, parsed_or_None) -> (payload, result)` or a refusal dict with `ok` False (returned as is); `dry` returns `result` with no backup and no write; else `backup = backup_before_write(path, backups_dir, label)` (an `OSError` returns `{"ok": False, "reason": "refused: backup failed (<exc>); nothing was written"}`), calls `before_replace()` when given (test hook), re-reads the bytes and refuses with `"refused: <path> changed since it was read; nothing was written (backup kept at <backup>)"` on a difference, then `write(path, payload)` (an `OSError` from `write` returns `{"ok": False, "reason": "refused: write failed (<exc>); backup kept at <backup>"}`); returns `result` plus `"backup": backup` (`""` for a missing target).
