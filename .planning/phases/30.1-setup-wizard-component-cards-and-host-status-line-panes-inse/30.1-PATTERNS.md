## Pattern Assignments

### `tools/wizard_app.py` (component, event-driven)

**Analog:** `tools/wizard_app.py` (same file).

**Worker + `call_from_thread` pattern** (lines 1037-1070, `_apply_housekeeping`):
```python
    @work(thread=True, exclusive=True)
    def _apply_housekeeping(self) -> None:
        """Worker: apply the housekeeping decision(s) off the event loop, then
        refresh the Choose selection/state and unblock the gate. Any failure is
        captured so the UI never hangs in the 'Applying…' state, ..."""
        try:
            if self.ctx.apply_housekeeping is None:
                outcome = {...}
            else:
                outcome = self.ctx.apply_housekeeping(prune, repoint, **kwargs)
        except Exception as exc:  # pylint: disable=broad-exception-caught
            outcome = {}
            self.hk.error = f"housekeeping failed: {exc}"
        ...
        self.hk.applying = False
        if self.hk.error:
            self.call_from_thread(self.notify, self.hk.error, severity="error")
        self.call_from_thread(self._render)
```
Apply to: the board preview render worker (D-10). Use `exclusive=True` so only the newest render is kept, and
compare a render sequence number before applying (drop older results). Never touch widgets off the UI thread;
use `call_from_thread` for every widget update.

**Commit worker and Done gating** (lines 1288-1326, `_run_commit`): the same shape. It is decorated
`@work(thread=True, exclusive=True)`, catches any exception from `ctx.commit` into an outcome dict, and ends with
`self.call_from_thread(self._render)`. `_key_done` (line ~1329) ignores keys while `self.commit.committing` is set.
Apply to: `d` on Done. Gate the `d` key on `not self.commit.committing` and `self.commit.outcome is not None`.

**Key dispatch convention:** every step has `_key_<step>(self, event) -> bool` (e.g. `_key_arrange_gate` at
line ~1080, `_key_done`), returning `True` when the key was consumed. Apply to: `_key_arrange` (toggle `o`), `_key_done` (`d`).

**Injected context seam** (lines 140-163, `class WizardContext(NamedTuple)`): fields are typed, with defaults, and
callables are documented with their signature. Pattern to copy for the doctor factory:
```python
    commit: CommitFn | None = None
    apply_housekeeping: ApplyHousekeepingFn | None = None
```
Add `doctor_factory: DoctorFactoryFn | None = None` in the same style. `wizard_app.py` must not import `tools/setup.py`.

**Error-handling convention:** `# pylint: disable=broad-exception-caught` is used on the worker's
`except Exception` (lines 1062, 1305). Keep it on every worker boundary.

### `tools/config_doctor_appliers.py` and `tools/config_doctor_checks.py` (utility, file-I/O)

**Atomic writer** (lines 23-52): `mkstemp` in the realpath dir, fsync, `chmod` to the existing mode (0o600 for a new
file), `os.replace`, fsync the directory, and unlink the temp file on `OSError`. Reuse as the write step of the shared

**Dispatcher that never raises** (`apply_row`, lines 146-181):
```python
def apply_row(row_id, ctx, dry):
    row = _row_by_id(row_id)
    if row is None or row.apply is None:
        return {"ok": False, "reason": "not apply-eligible"}
    try:
        result = apply_fn(ctx, row.apply_target, dry)
    except Exception as exc:  # pylint: disable=broad-exception-caught  # TUI backstop
        return {"ok": False, "reason": f"applier error: {exc}"}
    if not isinstance(result, dict):
        return {"ok": False, "reason": f"applier error: non-dict result {result!r}"}
    return result
```
The applier contract is: return a dict, `{"ok": True, "before", "after", "current_display", ...}` on success, or
`{"ok": False, "reason": ...}` on refusal.

**The current unsafe pattern to replace (D-14, R6):** both Claude appliers fall back to `{}` on an unparseable file.

## Shared Patterns

### Atomic writes
**Source:** `tools/config_doctor_appliers.py` lines 23-52 (`atomic_write_json`); `tools/setup.py` lines 1878-1900 (`_atomic_write_json`)
**Apply to:** every doctor applier (via the shared helper, D-14), the Claude foreign `statusLine` removal (D-07), and
the Playwright apply (R7). Never write with plain `open(path, "w")`.

### Refuse, never overwrite
**Source:** `tools/setup.py` `unwire_statusline` (line 2697): `JSON_STATE_UNREADABLE` → warn and return `False`.
**Apply to:** the shared applier helper (D-14). An unparseable or non-object target returns `{"ok": False, "reason": ...}`.

### Worker threads for slow work
**Source:** `tools/wizard_app.py` `_run_commit` (line 1293) and `_apply_housekeeping` (line 1037).
**Apply to:** the preview render (D-10) and the doctor catalog build on `d`. Use `@work(thread=True, exclusive=True)` and
`call_from_thread` for every widget update.

### Scratch HOME and env baseline
**Source:** `tests/test_wizard_pty.py` `_scratch_roots` (lines 78-98); `tests/test_config_doctor.py` `setUp` (line 63).
**Apply to:** every new test. No test reads real `~/.claude`, `~/.cursor`, `~/.config/opencode`, `~/.codex`, `~/.pi`
or `~/.gsd`.

### Preserve unrelated keys
**Source:** `_apply_claude_retention` (`config_doctor_checks.py` line 199-201): `data = dict(parsed)` then one key set.
**Apply to:** the Playwright apply (only `env.PLAYWRIGHT_MCP_EXECUTABLE_PATH`) and the foreign `statusLine` removal (only
`statusLine` popped). SPEC R3 and R7 require every other key to stay equal.

## Risks Noted for the Planner

- **`{}` fallback is live today:** `_apply_claude_retention` and `_apply_claude_sandbox_enabled` (`config_doctor_checks.py`
  lines 184-226) replace an unparseable `settings.json` with `{}`. That is the exact bug R6 fixes; the first plan task should
  change this.
- **`ConfirmApplyScreen` uses `enter` as confirm** (line 45-46). The foreign-removal confirmation must default to No, so
  it needs its own modal, not this one unchanged.
- **Two writers exist:** `setup._atomic_write_json` and `config_doctor_appliers.atomic_write_json` are near-copies. Keep
  both, per the existing layering rule (`tools/` modules do not import each other's helpers beyond what already exists).
  Confirm with `tests/test_arch.py` before adding an import.
- **`WizardContext` is a `NamedTuple`:** adding a field needs a default, or every constructor call in `tests/` breaks.
