<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| review-spec.toml `command` → process spawn | a config string becomes an executed command |
| document paths/prompt text → argv | free text built from file paths and content reaches the child |
| host environment → child environment | the orchestrating host's identity variables leak into children |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16.1-13 | Elevation of Privilege | render_reviewer_command, dispatch_*, probe | critical | mitigate | argv only, no shell; prompt is one element; shell syntax in templates raises ValueError naming the reviewer |
| T-16.1-14 | Spoofing | child environment | high | mitigate | `child_env` removes HOST_SIGNAL_ENV_VARS before every spawn; real-child tests through every dispatcher |
| T-16.1-15 | Denial of Service | empty command template | low | mitigate | ValueError naming the reviewer key; spawn functions refuse an empty argv |
| T-16.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package installs; uv/make calls run with `UV_NO_SYNC=1 UV_OFFLINE=1` |
</threat_model>
