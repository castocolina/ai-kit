### Pattern 1: Hook-selection check without PyYAML
**What:** `tests/test_gate_scope.py` must stay stdlib-only, so extract each hook's `files:` regex from `.pre-commit-config.yaml` with a line scan (the file's shape is regular: `- id: <hook>` ... `files: <regex>`), then compile and apply it to `git ls-files '*.py'` (or an `os.walk` of `tools skills tests`). `pre-commit --all-files` only sees tracked files, so new files must be `git add`-ed before the hook run can see them.
**Non-vacuity:** run the same checker on a synthetic list that includes an unselected path and assert it fails.

### Pattern 2: Runner groups (D-06)
**What:** `run_unittest_parallel.py --group core|uv|e2e` discovers `tests/test_*.py`, subtracts explicit exception sets, and exits non-zero on an unclassified module. Facts that shape the groups:
- uv-only (fail under system python, verified): `test_wizard_app`, `test_framework_profiles` (need `textual` / PyYAML).
- `test_config_doctor` skips 6 safety tests under system python (verified "OK (skipped=6)"); today it is in BOTH the core and wizard hooks. "Exactly one group" means it moves to the uv group only.
- `test_wizard_pty` (6 tests) and `test_config_doctor_pty` (4 tests) pass under system python and are launched from subprocesses; today `test_wizard_pty` is in the wizard hook AND `make e2e-test`. The SPEC names only `test_worktree_e2e` and `test_system_memory_e2e` as e2e exceptions, so pick one group per module and note `test_wizard_pty` and `test_config_doctor_pty` explicitly (planner decision, record it in the test).
- A zero-test module exits 5 on Python 3.12+ (verified: "NO TESTS RAN", rc=5), so the runner already fails it; pin with a runner test.

### Pattern 3: Argv end to end (D-10), shape of the change
`render_reviewer_command(resolved, prompt) -> list[str]`: `shlex.split(template)`; reject operator tokens (`shlex.shlex(..., posix=True, punctuation_chars=True)` with `whitespace_split=True`) and any `$` or backtick; then `tok.format(model=..., prompt=prompt, **extra)` per token; empty result raises `ValueError` (Open Question 1). Verified facts:
- The user's real global templates (6 reviewers, read-only look) contain no shell operators; the codex template `-c model_reasoning_effort='"high"'` splits to the single token `model_reasoning_effort="high"`, identical to what a shell passes.
- grok's review template `grok -p {prompt} -m {model} --output-format plain` splits to separate tokens so `{prompt}` becomes one argv entry with no quoting.
- Detection of `&`: `--x=1&2` splits at `&` under `punctuation_chars` (that is correct, an unquoted `&` is a shell operator).

### Anti-Patterns to Avoid
- **Formatting a template that embeds a quoted path:** `execute_dispatch.py` does `command_template.format(model=...)` on a template that already contains `shlex.quote(target_dir)`; a `target_dir` containing `{` or `}` breaks `format` today and will break the per-token format too. Escape braces in the builder (`replace("{","{{")`) or substitute only `{model}`/`{prompt}`/extra keys; add a test with a brace in `target_dir`.
- **Parsing the local file twice:** hash then re-open for parse reintroduces the TOCTOU the single read removes.

### Known Threat Patterns for this stack

| Pattern | STRIDE | Standard Mitigation |
|---------|--------|---------------------|
| Cloned repo's `.aikit/review-spec.toml` runs a command (current `shell=True` default) | Elevation of privilege | Trust gate (R5) + argv without shell; untrusted file ignored entirely |
| TOCTOU between hash and parse | Tampering | One read of the bytes; hash and parse the same buffer (D-08) |
| Trust bound to path only, or to mutable content | Spoofing | Key = sha256(realpath NUL content-sha256); moved or edited file needs new trust |
| Agent auto-runs `trust-local` because the cloned repo's text tells it to (prompt injection) | Elevation / Repudiation | Consent wording in SKILL.md (the agent must show `--show` argv and get explicit user approval); wizard never auto-trusts; revocation via `--revoke` |
| Option injection through `{model}`/`extra` values starting with `-` | Tampering | Only trusted configs reach argv; keep values per-token (no word re-splitting); note as residual for config authors |
| `<script>` breakout in the usage dashboard | Tampering / Info disclosure | Escape every `<` as `<` after serialization |
| Inherited host identity changes child CLI behavior (nested-agent confusion) | Spoofing | `child_env` scrub of 11 variables on every cross-AI spawn |
| Misclassified output (model answer text) triggers futile retries over a half-edited tree | Tampering | stderr-only classification, exit 0 never classified |
| `install.sh --branch` argument injection (`--upload-pack=…`) | Elevation | `git check-ref-format --branch` before any git call; quote all expansions |
| Concurrent cache writers corrupt JSON | Tampering / DoS | `mkstemp` + `os.replace`, unlink temp on error |
| Symlinked or out-of-repo link targets in the AGENTS.md checker | Info disclosure | existing `realpath` containment retained; binary targets not read |
