## Pattern Assignments

### `S/commands.py` render_reviewer_command (D-10)
Current (`:370`, `:398-413`) returns a shell string with `shlex.quote(prompt)`:
```python
if not resolved.command:
    raise ValueError(f"reviewer {resolved.key!r} has cli={resolved.cli!r} set but no command template")
try:
    return resolved.command.format(model=resolved.model, prompt=shlex.quote(prompt), **resolved.extra)
except (KeyError, IndexError, ValueError, TypeError) as exc:
    raise ValueError(f"reviewer {resolved.key!r} has a malformed command template: {exc}") from exc
```
Keep that exact `ValueError` wrapping. New order: `shlex.split(template)`, reject operator tokens
(`shlex.shlex(posix=True, punctuation_chars=True)`, `whitespace_split=True`), `$` and backticks, then
`tok.format(...)` per token, then reject empty argv, return `list[str]`. Drop the `shlex.quote` docstring
paragraph. Do not format a template that embeds a quoted `target_dir` (see `execute_dispatch.py`); escape braces.
