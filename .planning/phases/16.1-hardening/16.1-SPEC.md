## Goal

## Background

Verified in the v1.3 checkout (gsd/v1.3-curated-config-v2 at ef2daf6) on 2026-10-14:

- **Gate scope.** The ruff/py-compile `files:` regex selects 157 of 191 Python files. The 34
  skipped ones include all of `skills/ai-kit-spec-review/ai_kit_spec/` (21 files), the
  superpowers package, `markdown-to-pdf/scripts`, `mermaid-audit`, `cst-refactor` and the
  `ai-kit-spec-review` shim. Running ruff on them gives 19 findings. pylint covers 3 files; over
  all 160 shipped files it gives 400 findings, 177 of them missing docstrings. Four test modules run in neither
  `make validate` nor its hooks: `test_ai_kit_spec_superpowers`, `test_framework_profiles`,
  `test_markdown_to_pdf`, `test_mermaid_style`. The two e2e modules (`test_worktree_e2e`,
  `test_system_memory_e2e`) run only in `make e2e-test`.
- **Imports.** `model_detect.py:26-46` tries `$CLAUDE_PLUGIN_ROOT`, then `~/.claude/skills`, and
  only then the sibling directory; `ai-kit-project-rules-all/.../dispatch.py:50-72` puts the
  sibling last too. `~/.claude/skills` links to main, so v1.3 tests run main's `ai_kit_spec`.
- **Security.** `quota.py:237` and `dispatch.py:70,150` run reviewer command strings with
  `shell=True`, including commands from a project-local `.aikit/review-spec.toml`, during the
  default `--cross-ai` flow. `dashboard.py:2040` escapes only the lowercase `</script`.
- **Correctness.** A `Status: Failure` lane can merge into Approved in double mode (audit A6).
  `quota.py:17` and `dispatch_injection.py:25` match "quota"/"rate limit" anywhere in the output,
  including the model's answer. No child environment scrub exists (`AI_AGENT` is never
  removed). The claude and grok execute builders nest `sh -c` and cannot run under GSD's
  no-shell word splitting. `gsd_config.py` writes the config through `cache_write_json`.
- **Smaller items.**
  - `detection.py:611` silently runs `codegraph install --location=global --yes` and has no
    timeout.
  - `config_io.py:38` turns a TOML parse error into `{}`.
  - `install.sh` ignores `--branch` on an existing clone and pulls even with `--dry-run`.
  - `cache.py:26` uses one shared `path + ".tmp"`.
  - Uninstall writes `settings.json` non-atomically (`setup.py:1387-1392`).
  - The AGENTS.md checker crashes on image links (`ai_kit_project_rules_agents/cli.py:82-101`).
  - `gsd_catalog.py` looks only for a global gsd-core.
- **Phase 16:** all 6 plans executed, code review fixed. There is no VERIFICATION.md, the live
  checks never ran, and STATE, REQUIREMENTS and ROADMAP still show it pending.

## Requirements

1. **Ruff and py-compile scope**: the hooks select every shipped Python file.
   - Current: the regex selects 157 of 191 files, and 19 ruff findings sit in the unselected ones.
   - Target: every `.py` under `tools/`, `skills/` and `tests/` is selected (only `.planning/` and `docs/` are excluded), with zero ruff findings. `make lint` delegates to the hook-backed targets, and `[tool.pyright] include` / `[tool.vulture] paths` cover the same tree (amended 2026-10-14: the discuss analysis found both omit `ai_kit_spec`).
   - Acceptance: `uv run pre-commit run ruff --all-files` and `py-compile` pass, and a check that lists `fd -e py tools skills tests` against the hook's selection finds no unselected file. pyright and vulture pass over the widened paths.

2. **pylint scope**: pylint covers every shipped Python file under `tools/` and `skills/`.
   - Current: 3 files are covered; the rest have 400 findings.
   - Target: every finding is fixed except the missing-docstring family (C0114, C0115, C0116), which `pyproject.toml` disables with a one-line reason. The design thresholds in `[tool.pylint.design]` stay unchanged. The copy-me template `skills/cst-refactor/codemod_template.py` ships as the non-Python asset `codemod_template.py.txt` (amended 2026-10-14).
   - Acceptance: `uv run pre-commit run pylint --all-files` passes over all of them, and `pyproject.toml`'s pylint disable list adds nothing beyond C0114/C0115/C0116.

3. **Test-module coverage**: every test module runs in a gate.
   - Current: 4 modules run nowhere in `validate`.
   - Target: every `tests/test_*.py` runs in `make validate`, except `test_worktree_e2e` and `test_system_memory_e2e`, which run in `make e2e-test`.
   - Acceptance: a test enumerates `tests/test_*.py` and fails when a module is in neither list. All four missing modules pass in `make validate`.

4. **Sibling-first resolution**: skill code resolves its sibling skill before installed copies.
   - Current: the sibling directory is the last candidate.
   - Target: `model_detect.resolve_ai_kit_spec_path` and the rules-all dispatcher try `<skills root>/<name>` first.
   - Acceptance: a test with both a sibling and a fake `~/.claude/skills/<name>` picks the sibling, and a branch-checkout test asserts the imported `ai_kit_spec` file lives under the checkout.

5. **Trust gate for project-local reviewer commands**: a cloned repository cannot run commands.
   - Current: project-local commands run through the shell automatically.
   - Target: a command from a project-local `.aikit/review-spec.toml` runs only after the user trusts that file. Trust is recorded per file content hash, so any edit needs a new trust. An untrusted command is skipped with a message naming the trust command. Trusted commands run as argv lists without a shell.
   - Acceptance:
     - With an untrusted project-local command, `probe-quota` and dispatch spawn nothing and print the trust message.
     - After trust, the command runs.
     - After editing the file, it is skipped again.
     - No reviewer path calls `subprocess` with `shell=True`.

6. **Dashboard script escape**: no `</script` breakout in any letter case.
   - Current: only the lowercase form is escaped.
   - Target: every `<` in the embedded JSON becomes `<`.
   - Acceptance: a test embeds `</SCRIPT>`, `</ScRiPt>` and `<!--`, and the rendered HTML contains none of them inside the data block. The JSON still parses to the original value.

7. **Failure never reads as Approved**: double-mode merging.
   - Current: a Failure lane plus an Approved lane can yield Approved.
   - Target: any lane with `Status: Failure`, or with no report at all, makes the merged verdict a failure.
   - Acceptance: tests for Failure+Approved, Approved+missing and Failure+Failure all yield a non-Approved verdict.

8. **Classifiers ignore answer text**: quota and transient errors are read only from stderr and structured error fields.
   - Current: a matching word anywhere in the output triggers them.
   - Target: the model's answer is never classified.
   - Acceptance: an answer containing "quota exceeded" with exit 0 and an empty stderr is classified as success. The same text on stderr with a non-zero exit is classified as quota.

9. **Child environment scrub**: cross-AI children do not inherit the host's identity.
   - Current: no scrub.
   - Target: `AI_AGENT`, `CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT`, `CLAUDE_CODE_SSE_PORT`, `OPENCODE`, `CURSOR_AGENT`, `PI_CODING_AGENT`, `CODEX_THREAD_ID`, `CODEX_SANDBOX` and `GROK_AGENT` are removed before every cross-AI spawn, review or execute. Every variable runtime detection reads is removed too, including `CODEX_VERSION` (amended 2026-10-14).
   - Acceptance: a test spawns through each dispatcher with all of them set, and the child sees none of them. Unrelated variables (`PATH`, `HOME`) pass through.

10. **Remove the unrunnable execute builders**: claude and grok are not execution targets.
    - Current: both builders exist and are broken.
    - Target: the claude and grok execute builders and their call sites are deleted. A config naming either as an execution CLI fails with an error naming the supported CLIs.
    - Acceptance: no execute builder for claude or grok remains (by AST test or grep), and naming one exits non-zero with that message. The review builders are unchanged.

11. **GSD config writes through gsd-tools**: `gsd_config.py` uses `gsd-tools query config-set`.
    - Current: it writes the JSON directly.
    - Target: every key change goes through `config-set`, including `null` for unsets, so the active workstream's config path is honored.
    - Acceptance: a test with a fake gsd-tools records one `config-set` call per key and no direct write to `config.json`.

12. **Codegraph probe never installs**: consent and ownership (tools-installer owns installs).
    - Current: a silent global install with `--yes`, and no timeout.
    - Target: the probe has a timeout and only reports. When codegraph is missing or unhealthy, it prints the exact install command.
    - Acceptance: a test with a fake runner sees no `install` invocation, and the probe returns within its timeout when the binary hangs.

13. **TOML parse errors are loud**: a broken `review-spec.toml` stops the review.
    - Current: it parses to `{}`, and cross-AI review is silently off.
    - Target: the error names the file and the parser message, and the command exits non-zero.
    - Acceptance: a malformed local file makes `ai-kit-spec` exit non-zero with the path on stderr. A missing file stays a silent default.

14. **install.sh branch and dry run**: the documented flags work on an existing clone.
    - Current: `--branch` is ignored, and `--dry-run` still pulls.
    - Target: on a clean clone, `--branch X` fetches X and switches to it; with local changes it refuses with a message. `--dry-run` prints what it would do and runs no fetch, pull or switch.
    - Acceptance: `tests/test_install.sh` cases with a fake git cover clean+branch, dirty+branch and dry-run (no git mutation recorded).

15. **Atomic writes**: concurrent cache writes and uninstall are safe.
    - Current: one shared `.tmp` name, and a non-atomic uninstall write.
    - Target: `cache_write_json` writes through `tempfile.mkstemp` in the target directory, and uninstall writes `settings.json` through `_atomic_write_json`. The non-atomic `_write_json`/`_read_json` helpers are deleted (amended 2026-10-14: the SPEC first named `_write_json`, which is the non-atomic helper).
    - Acceptance: a test runs two concurrent writers to the same path, and both complete with a valid final file. An uninstall test confirms `os.replace` is used.

16. **AGENTS.md checker robustness**: image and anchored links.
    - Current: it crashes on `![alt](path)`, and anchored links are missed.
    - Target: image links are checked as file links, `path#anchor` checks the path, binary targets are not read as text, and a missing link target is reported as a broken-link finding.
    - Acceptance: fixtures with an image link, an anchored link and a missing target produce the correct findings (a broken-link finding for the missing one), with no traceback.

17. **Project-local gsd-core first**: GSD is installed per repo.
    - Current: `gsd_catalog.py` and `ai-kit-spec-execute-gsd/SKILL.md` assume a global gsd-core.
    - Target: both look for `<project>/.claude/gsd-core` first, then the global installs.
    - Acceptance: a test with both a project-local and a global fake gsd-core picks the local one. The SKILL.md lookup snippet lists the local path first.

      - `16-VERIFICATION.md` exists.

## Constraints

- Runtime code stays stdlib-only. The trust store and argv split use only `json`, `hashlib` and `shlex`.
- Trust records live under ai-kit's own state directory (`~/.config/ai-kit/`), never inside the project or another tool's config.
- Every config write is atomic, reusing the existing helpers.
- The phase is executed through `.planning/scripts/cross-ai.mjs` (pi first) as the dogfood run for Phase 18's runner.
- Existing user-global `review-spec.toml` commands keep working. A command that relies on shell features gets a clear argv-split error that names the command, not a silent change.
- `make test` and `make validate` are green at the end.
