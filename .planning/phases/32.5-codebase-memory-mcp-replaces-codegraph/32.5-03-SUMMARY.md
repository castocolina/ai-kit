## Accomplishments

- `tools/global_rules.py` rewrites only a leftover codegraph block (both legacy markers) to the codebase-memory-mcp block, bytes in and bytes out, with a backup before each write.
- A file that already holds the codebase-memory-mcp markers is left byte-equal and reported as `already holds the codebase-memory-mcp block`.
- A file where any marker appears more than once, or a reversed pair, is skipped (`repeated or nested block markers`, `block with only one marker`) and stays byte-equal.
- The doctor row is `cbm-global-block` (reader `read_cbm_global_block`, applier `apply_cbm_global_block`) and remains the one applier exempt from `apply_guarded`.
- `--with-global-rules` keeps its name; its help, the wizard Review bullet and the preview name the codebase-memory-mcp block.
