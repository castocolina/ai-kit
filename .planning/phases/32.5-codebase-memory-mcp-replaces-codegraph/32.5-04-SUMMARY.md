# Phase 32.5 Plan 04: Read-only codebase-memory-mcp registration per host, one index refresh call, and the renamed alternative step

**Per-host codebase-memory-mcp registration read as data (registered, not registered, disabled or unknown) with a single index refresh call, and spec-config's alternative step and detect-tools key moved to the new tool.**

## Performance

- **Duration:** unmeasured (the start time was not recorded at the start of this run)
- **Tasks:** 2
- **Files modified:** 11 (1 created)

## Accomplishments

- `cbm_registration(cli, env)` reads Claude, opencode, Cursor, Copilot, Codex and pi registration from their config files as data. An absent file or entry is not registered; a disabled entry is not registered with a `disabled in <path>` detail; an unreadable or malformed file is unknown; grok has no reader and reads unknown.
- pi's registration is its extension file `cbmem.ts`, labelled `inferred` in the detail.
- `run_cbm_index(target_dir)` runs exactly `codebase-memory-mcp cli index_repository --repo-path . --mode full` with cwd set to the target and a 120 s timeout. It writes only the tool's own cache, and returns True only for rc 0 with status `indexed`.
- `jsonc_read.opencode_user_config_paths` is extracted; `opencode_config_paths` returns the same output as before.
- `check-codegraph-alternative` is renamed `check-code-index-alternative`, backed by `find_code_index_alternative`; `detect-tools` prints `codebase-memory-mcp`.
- `tests/test_cbm_detection.py` is a new unit module (18 tests), and `write_cbm_registration` is a new `tests/host_fakes.py` helper.

## Decisions Made

- The highest-precedence file that holds the entry or cannot be read decides; opencode's `$OPENCODE_CONFIG` is the highest-precedence file, so a disabling entry there beats the user `opencode.jsonc`.
- A relative registration path is dropped, never read. A runtime with no resolvable path reads unknown, not not-registered.
- `CBM_REGISTRATION_KEYS` includes copilot and pi, so the alternative check returns None for them. Only grok can receive an alternative now. This follows the plan's rule that a CLI with no reader gets the alternative.
- The `detect-tools` key and the alternative step are renamed in place with the same meaning. The codegraph probe and its callers stay for Plan 06.
