- **Found during:** Task 2 (first matrix run: custom-tmpdir had 4 differences: make rc 2, and logic shards 1-3 failed; plain passed)
- **Issue:** Two assertions in the template's self-test assumed no whitespace in argv. The `argv-exec-cursor` check rejected any token with whitespace, and the scratch path under a spaced TMPDIR is such a token (`whitespace token`). The `argv-retry-codex-review` check parsed the stderr argv with `argv=(\S+)`, which stopped at the first space (`rung2 argv mismatch`). The same regex pattern appeared in four other rung matches.
- **Fix:** Whitespace check ignores tokens that start with `os.tmpdir()`; all five argv regexes capture to end of line.
- **Files modified:** `skills/ai-kit-spec-review/references/cross-ai.mjs`, `.planning/scripts/cross-ai.mjs`
- **Verification:** logic shards 1-4 pass under a spaced TMPDIR; `make test` rc 0 after the fix; second matrix run identical in all six environments.
