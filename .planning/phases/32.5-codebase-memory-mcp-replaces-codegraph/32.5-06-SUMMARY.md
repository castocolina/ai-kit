## Accomplishments

## Decisions Made

- The guidance composer normalizes the CLI name with `runtime_id`, so `cursor-agent` gets the same line as `cursor`.
- A runtime with no registration reader (grok) gets the CLI form only, even with an inconsistent `True`.
- pi's line says its registration is inferred from its extension file (its `CBM_REGISTRATION_KEYS` value is `None`); the other registered runtimes say the registration is read from their config. Both say "not tested in this session".
- A failed pre-dispatch index keeps the registration `True` and reports on its own stderr line, so the lane still gets the MCP guidance and the operator sees the real cause.
