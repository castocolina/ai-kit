<decisions>
## Implementation Decisions

- **D-01: The owner's words decide (2026-11-14):** find every reference to codegraph and change it to
  codebase-memory-mcp, knowing agents in opencode and pi can use it too; keep `.planning/` out of its index.
- **D-02: The boundary refresh calls `codebase-memory-mcp cli index_repository`** with `repo_path` set to the checkout
  or worktree root and `mode` `full` (4.2 s on this repo); it parses the JSON result (`status`, `nodes`, `edges`,
  coverage gaps) and reports a failure in one line. The codegraph-only paths (status parsing, `init`/`sync`/`index`
  choice, lock retry, worktree-mismatch handling) go; the existing deadline and lock wait of the boundary step stay.
- **D-03: The unit brief reads changed functions through `codebase-memory-mcp cli`** (`search_graph` filtered by the
  changed files, or `detect_changes` when it serves), keeping today's brief format.
- **D-04: Lane guidance** names the MCP tools (`search_graph`, `trace_path`, `get_code_snippet`, `query_graph`,
  `get_architecture`, `check_index_coverage`) for hosts that register the server, and the CLI form otherwise; it is
  shown only when the binary is on the child's PATH.
- **D-05: Detection reads registration per host without writing:** the host config files the tool's installer writes
  (Claude `~/.claude.json`, opencode `opencode.jsonc`, Cursor `mcp.json`, Copilot `mcp-config.json`, Codex
  `config.toml`, pi's extension) are read as data; ai-kit never runs `codebase-memory-mcp install` and never writes
  them. A host whose file is absent reads "not registered".
- **D-06: `make setup-dev` checks the binary and prints the tool's own install command when it is missing** (its
  installer owns client wiring); the guarded step still exits 0.
- **D-07: `.cbmignore` at the repo root holds `.planning/`** (owner); its syntax is verified against the tool's docs
  before writing, and the effect is checked with `index_status` after a re-index. `.gitignore` swaps `.codegraph/` for
  `.codebase-memory/`. Existing `.codegraph/` folders are left and reported.
- **D-08: History stays; graphify stays.** No edit under the history paths of SPEC R7; a backlog entry evaluates
  whether codebase-memory-mcp's document graph makes graphify redundant (jev: choice 0.91, typesafe; keep and
  evaluate).
- **D-09: SKILL.md text that only swaps the tool name and its commands is not material** (listed, not judged); any
  other SKILL.md change meets the judge bar. Never judge `ai-kit-commit-fold` or a project-rules skill.
