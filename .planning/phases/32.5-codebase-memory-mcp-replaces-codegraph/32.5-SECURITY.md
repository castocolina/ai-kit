> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| git diff -> query_graph | changed file paths (names an attacker can influence) enter a Cypher string | file paths |
| index tool output -> report | JSON from the codebase-memory-mcp subprocess is parsed as data | index counts, hints |
| hook event cwd -> filesystem probe | an untrusted cwd walks up to `.git` and checks one cache file | a path |
| ai-kit -> user's global instruction files | the writer edits files under the user's home, only when the user applies | instruction text |
| user's host config files -> detection and doctor | files that may hold API keys are read as data | registration state only |
| host config -> lane prompt | the registration read decides which tool text a lane gets | guidance text |
| adapter -> target repo | the pre-dispatch index runs the tool in the target dir | the tool's own cache |
| setup-dev -> internet installer | the tool's installer is a curl-to-shell download | printed only, never run |
| runner template -> dogfood render | a template edit changes the runner every cross-AI lane runs | runner code |
| test modules -> real binaries on PATH | a test could reach the real tool and write its cache | tool calls |
| caller environment -> test module environment | a caller's override could point a test at owner state | env vars |
