(runner id -> inventory runtime), `EXEC_DEFAULT_HOSTS = ("claude", "codex")`,
`EXEC_EFFORT_TARGET = "medium"`, `CROSS_AI_FLAG = "--cross-ai"`.

`class Target(NamedTuple)`: `cli: str` (runner id), `model: str | None`, `source: str | None`
(`router-declared` | `catalog-score`), `why: str`, `router_backed: bool`, `candidates: list`.

Functions (all pure):
- `exec_targets(inv: dict, rigor: str, prefer=DEFAULT_PREFER) -> list[Target]`: for each id in
  `prefer`, skip when `id == inv["host"]` or `RUNNER_CLI[id]` is not in
  `inv["installed_runtimes"]`; cands = `inv["candidates"]` with that runtime; router = first by
  model of `is_router and router_confirmed and name_declared_purpose == "execute"`; else
  `roles.best_pick(cands, "execution", EXEC_EFFORT_TARGET, ceiling.value)` with
  `ceiling = roles.host_ceiling(cands, presets.PRICE_PERCENTILE[rigor])`, why from
  `roles.pick_why`; else `model None`, `candidates = roles.choice_candidates(cands, "execution",
  ceiling.value)`.
- `exec_default(host: str, targets: list) -> tuple[str, str]`: `("y", why)` when host in
  `EXEC_DEFAULT_HOSTS` and targets; `("n", "no installed cross-AI target (pi, cursor-agent,
  opencode)")` when host in `EXEC_DEFAULT_HOSTS` and none; `("n", "execution stays on the host
  for <host> (spec §6)")` otherwise.
- `timeout_value(existing) -> int`: existing when an int (not bool) >= 1800, else 1800.
- `manager_flags_value(existing) -> str`: `--cross-ai` when existing is not a non-empty str;
  existing unchanged when `--cross-ai` is already one of its whitespace tokens; else
  `existing.strip() + " --cross-ai"`.
- `script_artifact(targets: list, timeout: int) -> dict`: `{"kind": "cross-ai-script", "path":
  SCRIPT_PATH, "template": TEMPLATE_NAME, "version": TEMPLATE_VERSION, "config": {"prefer":
  [t.cli ...], "models": {t.cli: t.model for targets with a model}, "outer_timeout_s": timeout,
  "router_backed": {t.cli: t.router_backed ...}}, "targets": [{"cli", "model", "source", "why",
  "candidates"} ...], "status": "ok" | "needs_choice", "source": "preset", "why": "cross-AI
  execution runner (18 D-09)"}`.

Plan additions: top-level `"artifacts": [...]` (always present, `[]` when execution is off or no
target exists); `"schema_version": 2`.
