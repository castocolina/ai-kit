Design notes:
- `recommend` stays pure: the CLI loads the affinity file and passes the dict through
  `RecommendOpts.affinity` (default None means no skills layer output, so hand-built unit
  inventories keep their plans).
- The facts: `tdd_mode` is the plan's `workflow.tdd_mode` entry value (else the existing config
  value), `frontend` and `db` come from `inventory.project`, `system_one_backend` from
  `inventory.system_one_backend.detected`.
- A declined trusted root (plan-unset, D-41) leaves the escaping skill wired; apply's post-write
  check (18-13) then reports gsd-core's path-check warning. Say so in the entry's why.
