Design notes:
- A marker left by an earlier apply makes apply exit 2 with `an earlier apply did not finish
  (<marker>); its backup is <backup>; copy the backup over <config> to restore, then delete
  the marker` (the marker never auto-heals).
- The rendered script is not removed by a config restore: it is inert while
  `workflow.cross_ai_command` does not point at it; the report says so.
- The live config is re-read after `config-new-project` and before each family's writes are
  computed; a value already equal to the live one is skipped (this is what makes re-apply a
  no-op).
