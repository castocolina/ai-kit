Design notes:
- `recommend` stays pure: the CLI always loads `plan_io.AFFINITY_PATH` and passes the dict
  through `RecommendOpts.affinity` (default None means no skills layer output, so hand-built
  unit inventories keep their plans; tests pass a dict directly). There is no override flag.
- The facts: `tdd_mode` is the plan's `workflow.tdd_mode` entry value (else the existing config
  value), `frontend` and `db` come from `inventory.project`, `system_one_backend` from
  `inventory.system_one_backend.detected`.
- The plan records only `skill_affinity: {"schema_version", "as_of"}` (dated provenance of the
  curated data); no digest, since nothing compares it.

  install, stop and report its output verbatim.

  `# pyright: ignore` in `skills/`; in `tests/` the only allowed form is
  `# pyright: ignore[<ruleName>]  # deliberately ill-typed input: <what the test checks>`.
