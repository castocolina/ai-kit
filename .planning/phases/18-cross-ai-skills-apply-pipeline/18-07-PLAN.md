CONFIG markers: a line `// <config>`, then `const CONFIG = ` followed by
`JSON.stringify(cfg, sortedKeys, 2)` text and `;`, then a line `// </config>`. Default values:
`{"backoffS": [30, 60], "extraArgs": {}, "heartbeatS": 30, "models": {}, "outerTimeoutS": 1800,
"prefer": ["pi", "cursor", "opencode"], "retries": 2, "routerBacked": {}, "scrubEnv": [sorted
HOST_SIGNAL_ENV_VARS], "timeoutMarginS": 30}`.

PATTERNS markers: `// <patterns>` / `// </patterns>` around `const PATTERNS = {...};` (JSON, keys
in check order, values are regex source strings compiled with flag `i`):
- `permission_blocked`: `permission denied|requires approval|approval required|workspace trust required|pre-dispatch filters`
- `auth`: `\\b40[13]\\b|unauthori[sz]ed|token_expired|invalid_refresh_token|could not be refreshed|not logged in|log ?in required|please (?:log|sign) ?in|invalid api key|requires an opencode API key|credential gate`
- `billing`: `spending limit|billing|payment required|\\b402\\b`
- `bad_model`: `model not found|unknown model|invalid model`
- `quota`: `quota exceeded|insufficient_quota|usage limit`
- `capacity`: `overloaded|at capacity|service unavailable|\\b503\\b`
- `transient`: `temporarily unavailable|cooling down|is locked|rate.?limit|too many requests|\\b429\\b|\\b50[24]\\b|ECONNRESET|ETIMEDOUT|socket hang up|stream (?:closed|disconnected)`

Status table (status -> exit, action): ok 0 stop; no_change 1 fallback; empty_answer 1
fallback; crash 1 fallback; contract_violation 1 stop; usage 2 stop; no_model 2 stop;
empty_stdin 2 stop; permission_blocked 69 fallback; bad_model 69 fallback; auth 69 fallback;
billing 69 fallback (75 retry-later when `CONFIG.routerBacked[cli]`); quota 75 retry-later;
capacity 75 retry-later; timeout 124 stop; not_installed 127 fallback; signal 128+n stop. Any
fallback action becomes `stop` when the run left `tree=dirty`. Transient errors retry inside
the deadline (prototype loop) and become `capacity` when retries are exhausted.

Status line (stderr, last line, one per invocation in run mode):
`AIKIT-XAI status=<s> cli=<id or -> model=<m or -> exit=<n> cli_rc=<rc or -> elapsed=<int>s out=<stdout bytes> tree=<clean|dirty|unknown> action=<a>`.

Flags kept from the prototype: `--prefer`, `--model-<cli>`, `--mode`, `--timeout`,
`--print-argv`, `--no-preamble`, `--self-test`; new: `--header-state` (prints `pristine`,
