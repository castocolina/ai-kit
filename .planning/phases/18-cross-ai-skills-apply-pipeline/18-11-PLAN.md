  else write the backup bytes with the backup's mode through `cache_write_bytes`)
- `marker_path(config_path) -> str`, `write_marker(config_path, backup_path, config_existed,
  now_fn) -> None`, `read_marker(config_path) -> dict | None` (unparseable -> `{"corrupt":
  True}`), `clear_marker(config_path) -> None`
