- The Claude config dir is `os.path.dirname(gsd_core.skills_roots["claude"])` (gsd-core's own
  resolution, so `CLAUDE_CONFIG_DIR` handling stays gsd-core's); plugins are skipped when that
  root is null.

  the inventory adds the info note `enabledPlugins layering assumed per key (unverified)` when
  any plugin skill is listed. Research O13 was resolved in RUN-48 as "read user-level settings
  only"; that contradicts the locked D-32 layering (user, project, local; last wins), so it is
  routed back to the orchestrator as a revision conflict. Until D-32 is amended, follow D-32.

  `skills` paths and a root `SKILL.md` are not scanned (a `shortcut:` comment records it);

- The old `skills` shape (`.claude/skills`, `.agents/skills` under the project) is replaced;
  a project keeping skills in `.claude/skills` is a stated SKILL.md limit (D-31, 18-21).

<interfaces>
Constants (skill_scan.py): `SKILL_NAME_RE = re.compile(r"^[A-Za-z0-9_-]+$")`,
`PONYTAIL_SKILLS = ("ponytail", "ponytail-audit", "ponytail-debt", "ponytail-gain",
"ponytail-help", "ponytail-review")`, `DESCRIPTION_MAX = 300`, `CONNECT_TIMEOUT_S = 1.5`,
`URL_NOTE = "reachable, not verified as System One"`.

Functions:
- `scan_root(root: str, root_kind: str, label: str, home: str, plugin: str | None = None) -> list[dict]`
  (an entry per child dir holding SKILL.md; missing root -> [])
- `plugin_skills(claude_dir: str, project_dir: str, home: str) -> list[dict]`
- `scan_skills(project_dir, host_name, skills_roots, home) -> list[dict]` (sorted by
  `(root_kind, root, name)`)
- `ponytail_visibility(skills_roots: dict) -> dict[str, list[str]]` (every host in
  `host.HOSTS`; null root -> [])
- `system_one_backend(env: dict, connect_fn) -> dict`

Entry: `{"name", "root_kind", "root", "plugin", "real_dir", "real_dir_home", "escapes_root",
"addressable", "description"}`; `root` is `"skills"` for the project root, the global root path
for global, `<plugin>@<marketplace>` for plugin. `escapes_root` = realpath(skill dir) is not
inside realpath(root dir) (`os.path.commonpath`). `addressable` = name matches
`SKILL_NAME_RE` and, for plugin skills, the plugin name matches too. `real_dir_home` =
`"~/" + relpath` when realpath(skill dir) is inside realpath(home), else None.

Plugin data (live L9): `<claude dir>/plugins/installed_plugins.json` is `{"version": 2,
"plugins": {"<plugin>@<marketplace>": [{"scope": "user"|"project"|"local", "installPath": str,
"projectPath"?: str}]}}`. `enabledPlugins` maps the same id to bool in `<claude
dir>/settings.json`, `<project>/.claude/settings.json`, `<project>/.claude/settings.local.json`.
Plugin name = `.claude-plugin/plugin.json` `name` when a str, else the id before `@`. Skill
dirs: `<installPath>/skills/*` only, with the comment `# shortcut: custom plugin.json skill
paths and a root SKILL.md are not scanned; add them when a real plugin needs it`.

Backend: `{"detected": bool, "via": [subset of "url_reachable", "key_present" in that order],
"note": URL_NOTE when url_reachable else ""}`. URL check: `JEV_API_URL` stripped; empty ->
skip; `urllib.parse.urlsplit`; `.port` ValueError -> skip; port default 443 for `https`, 80
for `http`, otherwise skip; a daemon `threading.Thread` calls `connect_fn((hostname, port),
timeout=CONNECT_TIMEOUT_S)` (name resolution happens inside that call) and closes the socket;
the caller `join`s it for at most `CONNECT_TIMEOUT_S`, so DNS plus connect stay inside the 1.5 s
budget. A thread still running after the join counts as not reachable (a socket it gets later
is closed by the thread); OSError -> not reachable. The URL text is never stored or printed.
