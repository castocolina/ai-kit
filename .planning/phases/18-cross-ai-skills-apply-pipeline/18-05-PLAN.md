<objective>
Fill the review half of the cross-AI layer: a pure lane selector in `cross_ai.py` reads gsd-core's
own lane vocabulary from the inventory (D-24), applies the vendor and count rules (D-01, SPEC R2),
and `recommend` writes the convergence flag, default reviewers and per-lane model and effort keys.

Purpose: XAI-01 reviewers are another CLI and another vendor, never the host and never pi.
Output: lane selection in cross_ai.py, the review branch of `_cross_ai_layer`, regenerated
goldens, lane unit tests.

Design notes:
- The planner vendor is the inferred vendor of the `gsd-planner` slot model
  (`recommend._agent_slot_model` + `_facts` over host candidates). Unknown planner vendor means
  no lane can be proven different, so convergence is turned off with a note (17 D-14 strictness).
- A confirmed review router has no single vendor; it is exempt from the vendor rule (17 D-04,
  router wins its declared role). Say so in the entry's `why`.
- Lanes without enumerated models (agy, kimi-code, http lanes) are reachable only by `plan-set`.

<interfaces>
Inventory lane (18-02): `{"slug", "transport", "binary", "model_key", "effort_key",
"default_effort"}`.

cross_ai.py additions:
- `REVIEW_COUNT = {"mvp": 1, "standard": 1, "rigorous": 2}`, `REVIEW_EFFORT_TARGET = "high"`,
  `OPENCODE_EFFORT_EFFECT = "unverified: opencode 2.x run has no --variant flag (Phase 20 risk)"`.
- `class Lane(NamedTuple)`: `slug`, `model_key`, `effort_key`, `effort`, `model`, `vendor`
  (None for a router), `source` (`router-declared` | `catalog-score`), `why`.
- `eligible_lanes(inv: dict) -> list[dict]`: registry lanes passing the `<must_haves>` rule
  (binary in `inv["installed_runtimes"]`, `slug != inv["host"]`, `slug != "pi"`, `model_key`
  in `valid_keys.accepted`, at least one candidate with `runtime == binary` and `is_host` false).
- `select_lanes(inv: dict, rigor: str, planner_vendor: str | None) -> tuple[list[Lane], list[dict]]`
  returns the chosen lanes in order and notes. Per eligible lane: router pick (confirmed,
  `name_declared_purpose == "review"`, first by model) else
  `roles.best_pick(non-host lane cands, "review", REVIEW_EFFORT_TARGET, ceiling.value,
  keep=lambda c: c.get("vendor") not in (None, *excluded_vendors))` with
  `ceiling = roles.host_ceiling(lane cands, presets.PRICE_PERCENTILE[rigor])`. Rank the picked
  lanes by router first, then `roles.tie_key(candidate, "review")`, then slug. The second lane
  (Rigorous) is re-picked with the first lane's vendor also excluded.
- `lane_effort(lane: dict, rigor: str, candidate: dict) -> str | None`: None when `effort_key`
  is None; `xhigh` when rigor is rigorous and `"xhigh"` is in `candidate.get("reasoning_modes")
  or []`; else `default_effort`.

Plan entries for chosen lanes: `workflow.plan_review_convergence` true; `review.default_reviewers`
= list of slugs; per lane `<model_key>` = model and, when `lane_effort` is not None and the
effort key is accepted, `<effort_key>` = effort (opencode adds `effect=OPENCODE_EFFORT_EFFECT`).
</interfaces>
