<interfaces>
pi RPC response shape (18-RESEARCH L8, pi 1.2.0, verified live 2026-10-15): one stdout line
`{"id":"1","type":"response","command":"get_available_models","success":true,"data":{"models":[...]}}`.
Each model object carries `api`, `baseUrl`, `compat`, `contextWindow`, `cost{input,output,cacheRead,cacheWrite}`,
`id` (bare, e.g. `my-coding`), `input` (`["text"]` or `["text","image"]`), `maxTokens`, `name`,
`provider` (e.g. `router-env`), `reasoning`, optional `thinkingLevelMap` (level -> string or null),
`type`. pi accepts `--model provider/id`, so ids are emitted as `provider/id`.

Parser record: `{"id": "<provider>/<id>", "reasoning_modes": [levels whose map value is truthy, in map order],
"image_input": "image" in input, "context_window": contextWindow if int else None}`.

Snapshot entry: `clis.pi = {"installed": true, "path": <binpath>, "models": [ids],
"reasoning_modes": {id: [...] only when non-empty}, "image_input": {id: bool}}`.

Strict encoder table (18 D-16, live L2): None -> `null`; True/False -> `true`/`false`;
list/dict -> `json.dumps(v, separators=(",", ":"), sort_keys=True)`; int (non-bool) -> `str`;
finite float -> `str`; str -> itself unless refused; refused strings (after `.strip()`):
`true`, `false`, `null`, anything `float()` parses to a finite number (`12`, ` 12`, `1e3`,
`-0.5`), anything starting `[` or `{`. Non-finite floats and other types raise ValueError.
</interfaces>
