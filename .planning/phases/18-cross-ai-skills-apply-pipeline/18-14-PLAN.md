Design notes:
- The approval prompt itself is the agent's job (SKILL.md, 18-15); the CLI prints the block as
  data and runs it only with `--approve`.
- "Changed" keys are the plan entries whose op is `set` or `unset` and whose value differs from
  the live config at the time the block is built (so a re-run after a successful apply still
  shows effort sync when the earlier sync failed, and shows nothing when everything is current).
- The effort dry-run is read-only (`effort sync --dry-run`, gsd-core default) and runs while
  building the block; tests inject `run_fn`.

  branch or worktree, never install anything. Prefix every `uv`/`make` call with

followups.py:
- `HOST_DIRS = {"claude": ".claude", "codex": ".codex", "opencode": ".opencode"}`,
  `EFFORT_SYNC_HOSTS = ("claude", "codex", "opencode")`, `PACKAGE = "@opengsd/gsd-core"`
- `class FollowUp(NamedTuple)`: `id` (`installer` | `effort_sync`), `argv: list[str]`, `cwd:
  str`, `purpose: str`, `alternative: str`, `detail: str`
- `installer_argv(version, host) -> list[str]` = `["npx", "-y", f"{PACKAGE}@{version}",
  f"--{host}", "--local"]`
- `local_gsd_tools(project_dir, host) -> str | None` (`<project>/<HOST_DIRS[host]>/gsd-core/bin/gsd-tools.cjs` when it is a file)
- `effort_sync_argv(node, tools, host, project_dir, apply: bool) -> list[str]` (`[node, tools,
  "effort", "sync", "--apply" | "--dry-run", "--runtime", host, "--config-dir",
  <project>/<host dir>, "--project-dir", project_dir]`)
- `effort_dry_run_count(argv, run_fn, env) -> int | None` (`len(json["changes"])`; None on any failure)
- `build_followups(plan, inv, live, ctx) -> dict`: `{"required": [FollowUp as dict], "recommended":
  [{"id": "map_codebase", "text": ...}], "notes": [...], "disclosures": [...], "approve_with":
  "followups --plan <p> --inventory <i> --project-dir <d> --approve"}`
- `run_followups(block, deps) -> tuple[int, list[dict]]`: runs `required` in order (installer,
  then effort sync with gsd-tools re-resolved via `local_gsd_tools` after the installer);
  each result `{"id", "argv", "cwd", "returncode", "stdout_tail", "stderr_tail"}` (tails at most
  2000 chars); a failure stops the sequence, exit 1, and stderr prints
  `ai-kit-gsd-curated-config: <id> failed; run it yourself: <shlex.join(argv)> (cwd <cwd>)`

CLI: `followups --plan --inventory --project-dir [--approve]`; without `--approve` prints the block
JSON and exits 0; with it prints `{"results": [...]}`; exit 0 when nothing is required.
