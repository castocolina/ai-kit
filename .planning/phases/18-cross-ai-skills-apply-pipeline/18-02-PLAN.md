  `lib/model-catalog.cjs`), so the Python argv keeps its shape and every existing `FakeRun`
  that reads `json.loads(argv[6])` still works.

  managed key absent from a plan is unset by 17 D-08, which would delete a user's hand-set
  timeout whenever execution is off. Record this deviation in the SUMMARY.
