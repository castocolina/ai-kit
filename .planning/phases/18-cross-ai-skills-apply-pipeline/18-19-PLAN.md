<objective>
Prove 18-18's write path against the real checkout-local gsd-tools where it matters most: the
Nth-key failure returns the exact bytes (D-21), history keeps 3 backups (D-19), re-apply is a
no-op with the D-20 backup rule, and an absent config is created and reconciled (SPEC R13);
then pin the SPEC write prohibition with an AST discipline test.

Purpose: APP-03's "a way back" is only real if a failed real apply returns the user's bytes.
Output: four E2E cases, `TestWritePathDiscipline`, and any apply.py fix those cases force.

Design notes:
- D-20 decides idempotency, so the expected values below are fixed. When a case fails, fix
  apply.py (or config_backup.py through apply's call) until the case meets D-20; never change
  an expected value to match the code.
- The Nth-key failure is injected by wrapping the real run_fn (pass through every call, fail
  the chosen `config-set`); same-second backups come from `now_fn`.
- Tasks 1 and 2 also run the unit module, so an apply.py fix never leaves 18-18's unit cases
  red; those cases pin D-22 steps, so the fix goes in apply.py, never into a loosened case.
