  see the inventory's skills list"}`

`real_dir_home` is never wired (no `~/`-relative trusted root can name it); it adds the note
`not wired: <skill> resolves outside the home directory` (no path in the text). Project, plugin
and non-escaping global skills need no trusted root, so a null `real_dir_home` never affects
them (a project outside HOME keeps its `skills/<name>` wiring).

Trusted-root entry (from `_skills_layer`): key `agent_skills_security.trusted_global_roots`,
source `affinity`, `status="needs_choice"`, `value None`, candidates from `trusted_roots`, why
`approve with plan-set agent_skills_security.trusted_global_roots '<json list>' or keep the
current value with plan-unset; a declined root leaves the skill wired and gsd-core skips it
(apply reports the warning)`. No entry when the existing config already lists every proposed
root.
