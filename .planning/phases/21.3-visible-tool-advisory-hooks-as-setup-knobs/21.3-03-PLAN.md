<objective>
Give the advisor a memory and add its post-call half: one private, locked per-session state
file that makes each piece of advice appear on its first occurrence and every tenth repeat, and a
PostToolUse reminder that names the output size and the better tool without repeating advice the
pre-call hook already gave (SPEC R5, R6; D-09, D-11, D-17).

Purpose: advice on every call is noise and one line per session does not change habits; the
reminder reaches the model after the outcome is known (ADV-04, ADV-03).
Output: state functions and the reminder in `advisor_core.py`, three small generalizations in
`precompact_core.py`, `tools/hooks/claude_tool_reminder.py`, `tests/test_tool_advisor_state.py`.

Rules binding every task: the plan 21.3-01 rules. Every state test sets a fresh 0700
`XDG_RUNTIME_DIR` and `XDG_CACHE_HOME` under `tempfile.mkdtemp()`; no test touches a real
runtime or cache dir. Change `precompact_core.py` only as Task 1 says, keeping every 21.2 test of
that module green unchanged.
</objective>

| Boundary | Description |
|----------|-------------|
| hook process -> private state dir | parallel hook processes share one file per session |
| host payload -> state key | the session id and call id come from the host |
| tool output -> reminder | the output size is computed from untrusted command output |
