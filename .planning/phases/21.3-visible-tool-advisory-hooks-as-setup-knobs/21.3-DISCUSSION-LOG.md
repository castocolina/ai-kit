## Live facts that changed the plan

- Claude Code places PreToolUse `additionalContext` "alongside the tool result" (docs), so the
  large-read report informs the next read. ROADMAP SC3 and ADV-03 were amended in the SPEC
  commit (`37f303a`).
- rtk 0.44.1 is still on PATH on this machine, although the owner considers it uninstalled. No
  hook mentions it either way.
- `shlex` drops newlines unless they are added to the separators, and redirects become
  punctuation tokens (D-06).
- pi truncates bash/read output at 2,000 lines / 50 KB, so the outcome reminder reads
  `details.truncation` (D-13).
