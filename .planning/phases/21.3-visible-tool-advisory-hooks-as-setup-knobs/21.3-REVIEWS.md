## 21.3-01

**Summary:** The setup-to-advice tracer is strong, and the shared output gate, installed-tool detection and bounded large-read algorithm are well specified. The latest lexer correction handles its named regression but still mishandles valid shell quoting.

**Strengths**
- The tracer executes the stored command through `sh -c` with a spaced install path, testing configuration quoting rather than an equivalent argv call ([plan:185](.planning/phases/21.3-visible-tool-advisory-hooks-as-setup-knobs/21.3-01-PLAN.md#L185)).
- Extending the existing emitter preserves a single Claude output path; the current implementation already constructs its envelope centrally (`tools/hooks/claude_session_start.py:53–65`).
- The large-read task specifies regular-file checks, nonblocking open, bounded counting and explicit thresholds.

**Concerns**
- **NEW — LOW: Quote handling remains incorrect for concatenated shell words.** The prescribed preprocessing and non-POSIX lexer are at [plan:205–223](.planning/phases/21.3-visible-tool-advisory-hooks-as-setup-knobs/21.3-01-PLAN.md#L205). Reproducing those settings:
  - `echo x" | grep "y` produces a standalone `|` token and falsely identifies `grep`, although Bash executes only `echo`.
  - `echo '\'; grep x f` loses its closing quote during unconditional backslash masking, hiding a real `grep` command.
  
  These are distinct from the resolved standalone quoted/escaped-operator cases. I verified both against Bash without executing external commands.

**Suggestions**
- Preserve quote context when recognizing separators and masking escapes, including quotes beginning mid-word.
- Add these two cases to the existing table; no full shell-parser dependency is necessary.

**Risk Assessment: MEDIUM.** The main safety boundaries are sound, but command recognition still has reproducible false positives and negatives.

  Simulating the prescribed transitions for 25 distinct `grep` calls, each printing 500 lines:

  | Handler order | Calls displaying text | Final `big:grep` count |

  | Advisor → reminder | 1, 2, 11, 13, 21, 24 | 22 |
  | Reminder → advisor | 1, 11, 21 | 25 |
