## Pattern Assignments

### Hook entry scripts (`claude_tool_advisor.py`, `claude_tool_reminder.py`, `claude_decision_probe.py`)

**Analog:** `tools/hooks/claude_session_start.py` (96 lines). Copy it whole. Entry scripts stay thin and `importlib.import_module("advisor_core")` after `sys.path.insert` of the script's own realpath dir, so a missing or broken core degrades to `{}`.

**Fail-open excepthook** (lines 36-47). Must be installed before any fallible import, with no argparse:
```python
def _fail_open(*_exc_info):
    sys.stdout.write("{}")
    sys.stdout.flush()
    os._exit(0)
```

**Bounded stdin drain** (lines 50-73). The advisor needs the payload, so adapt it to accumulate chunks, with the same caps (16 iterations, 1 MiB, `select` 0.5 s, `os.read(fd, 65536)`) instead of discarding:
```python
readable, _, _ = select.select([sys.stdin], [], [], 0.5)
...
chunk = os.read(fd, 65536)
```

**Emit and main** (lines 76-96). Replace the SessionStart envelope with the single output gate: only `{}` or `hookSpecificOutput{hookEventName, additionalContext}` with `hookEventName` of `PreToolUse` or `PostToolUse`:
```python
def emit(message):
    if message:
        payload = {"hookSpecificOutput": {"hookEventName": "SessionStart",
                                          "additionalContext": message}}
    else:
        payload = {}
    sys.stdout.write(json.dumps(payload))
    sys.stdout.flush()

def main():
    sys.path.insert(0, os.path.dirname(os.path.realpath(__file__)))
    detect = importlib.import_module("detect")
    ...
    return 0

if __name__ == "__main__":
    sys.excepthook = _fail_open
    raise SystemExit(main())
```

**Subprocess style** (decision-probe, D-16, timeout 3 s). Copy the exception tuple and `stdin=DEVNULL` from `detect._probe_rtk_hook` (`detect.py:~85-100`):
```python
proc = runner([...], capture_output=True, text=True, timeout=..., check=False,
              stdin=subprocess.DEVNULL)
except (OSError, ValueError, subprocess.SubprocessError):
```
Per D-17, `subprocess` in `decision_probe` only; the advisor scripts must stay on `python3 -S` with `json, shlex, shutil, os, tempfile, select`.

## Shared Patterns

### Fail-open
**Source:** `tools/hooks/claude_session_start.py:36-47, 93-96`. Apply to every entry script: excepthook installed first, exit 0 with parseable JSON, `SystemExit` only from `raise SystemExit(main())`.

### Atomic config writes
**Source:** `_atomic_write_json` and `_read_json_checked` in `tools/setup.py` (about `:1389-1450`). Apply to all wire/unwire code. AGENTS.md requires `mkstemp` plus `os.replace`, and a three-state reader that never replaces an unparseable file.

### Ownership by script path
**Source:** `tools/setup.py:1777-1779` (`_entry_is_ours_nested`) and `:1515-1527`. Apply to wire and unwire for all five ids.

### Stdlib-only runtime
Hook scripts run under `python3 -S` with stdlib only (AGENTS.md). Mirror the timing budget of D-17.
