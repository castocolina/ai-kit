<domain>
## Phase Boundary

The 21.2 hook registry is extended to five ids: `session-briefing`, `tool-advisor`,
`tool-reminder`, `decision-probe` and `precompact`. Each has a wizard row, an additive
headless id and a per-id uninstall.

The phase delivers:
- a visible, rtk-free SessionStart briefing;
- a PreToolUse advisor (command shape and large reads) and a PostToolUse outcome reminder, from
  one host-neutral core for Claude Code and pi (opencode after a spike; Cursor a recorded gap);
- a decision-probe hook;
- live verification.

The SPEC (10 requirements; R1, R9 and one boundary amended 2026-10-18) is the locked WHAT.
</domain>

  - Laya script_per_id 0.41 fb, same choice.

  - Laya advisors_on 0.59 fb, same choice; the phase goal is to change habits.

### Advisor core
- **D-06: Command words are found with `shlex.shlex(posix=True, punctuation_chars=True)`,
  `whitespace_split=True`, with `\n` added to the separators.**
  - Redirect tokens (`2>&1`, `>&`) are not separators.
  - The lexer skips `VAR=value` assignments and a fixed wrapper list
    (`sudo env command time nohup xargs`), and takes the basename of a path command
    (`/usr/bin/grep`).
  - A `ValueError` (unbalanced quote) falls back to whitespace splitting.
  - Live (python 3.14.7): pipes, `&&`/`||`/`;`, `|&` and subshells split correctly; quoted
    words stay whole; newlines are lost without `\n`.
  - Laya shlex_plus_wrappers 0.39 fb, same choice.
- **D-07: The advice table uses live-verified flags** (2026-10-18: bat 0.26.1, rg 15.2.0,
  fd 10.5.0, sd 1.0.0).
  - Flags: `bat --plain --paging=never` (no ANSI when piped; an unknown `-l` exits 0;
    `-r N:M`), `rg -n`/`rg -l`/`--glob`, `fd --type f --glob`, and `sd -p` for preview.
  - `TOOL_GUIDANCE` in `detect.py` is refreshed and its version comment re-dated (fd moved
    from 10.4.2 to 10.5.0). `-l <lang>` comes from the file extension when known, else it is
    omitted.
  - Analyzer Confident.
- **D-08: The large-read counter reads bytes in 1 MiB chunks up to the 64 MiB cap and counts
  `\n`.**
  - Characters are approximated by bytes, and the token estimate is shown as "≈" (SPEC edge R4
    encoding). A 100 MiB sparse file took 22 ms (live).
  - Inputs: Claude Read `file_path`/`offset`/`limit`; pi read `path`/`offset`/`limit`
    (`dist/core/tools/read.d.ts:7-9`).
  - **Own reasoning** (Laya decode_chars 0.53 fb): decoding adds cost, and the SPEC already
    labels the estimate approximate.
- **D-09: Pre-call and post-call share one per-session state file, updated under
  `fcntl.flock`.**
  - It holds advice-id counters plus the set of tool-call ids the pre-call advisor advised.
  - Location: `$XDG_RUNTIME_DIR/ai-kit/advisor/` (0700, file 0600), falling back to
    `${XDG_CACHE_HOME:-~/.cache}/ai-kit/advisor/`, the same layout as 21.2 D-15. Files older
    than 24 h are swept.
  - Atomic replace alone allows a lost update: two parallel hooks both see count 0, breaking
    the R6 promise.
  - **Own reasoning** (Laya atomic_replace_only 0.53 fb).
  - Open research: whether Claude Code's `tool_use_id` matches across PreToolUse and
    PostToolUse.
- **D-10: `detect.py` drops the rtk probe** (`_probe_rtk_hook`, `RTK_*`, the `subprocess`
  import), and `compose_message` returns `(user_line, model_context)`.
  - Nothing imports the probe outside the hook: the doctor has its own reader
    (`tools/config_doctor_readers.py:211`).
  - The rtk cases in `tests/test_tool_substitution_hook.py` (`TestDetect` `:1096-1172`,
    `TestCompose` `:1211-1307`) are rewritten.
  - Analyzer Confident.

### Envelopes and hosts

  - `tool-advisor` is PreToolUse with matcher `Bash|Read`; `tool-reminder` is PostToolUse with
    matcher `Bash`.
  - Both emit only `hookSpecificOutput.{hookEventName, additionalContext}` or `{}`.
  - `_load_hook_config`/`_hook_entries_shape_ok` (`tools/setup.py:1454-1512`) are reused
    unchanged.
  - Analyzer Confident.
- **D-12: The briefing emits its `systemMessage` line and its `additionalContext` on every fire
  (`startup` and `compact`).**
  - Laya every_fire 0.91, consistent with the evidence: SPEC R2 asks for a user-visible
    briefing, and nothing forbids the line after a compaction.
  - The analyzer's startup-only variant was not taken.
- **D-13: pi gets one `tool_result`-only extension file per id**
  (`tools/hooks/pi/ai-kit-tool-advisor.ts`, `ai-kit-tool-reminder.ts`), linked into
  `extensions/` (21.2 D-10). The two dedupe through the D-09 state.
  - Neither registers a `tool_call` handler: "A `tool_call` handler failure blocks the tool"
    (`docs/extensions.md:263`).
  - Each returns `content: [...event.content, {type: "text", text: advice}]`, so the original
    stays byte-identical.

  - Transport is 21.2 D-07 (`node:child_process`, stdin JSON).
  - **Own reasoning** (Laya single_extension 0.51 fb): one file per id keeps links as the

  - Analyzer Confident.

  - The README headings `## What these hooks do`, `## Host coverage` and `## Non-goals` stay

    (`:361-391`) and `test_headless_with_hooks_*` (`tests/test_setup.py:2317-2335`).
  - SPEC boundary amended.

### Decision probe and performance
- **D-16: `decision-probe` runs `jev_review.py --probe` as a subprocess** (timeout 3 s), found
  from its own realpath at `<install>/skills/jev-fast-decision/scripts/jev_review.py`.
  - Matcher `startup` only; default off. It keeps only backend names and `host:port`.
  - **Own reasoning** (Laya import 0.55 fb): `tools/` importing `skills/` is called a layering
    violation (`tools/setup.py:1413-1414`), and 21.1 D-10 forbids in-process client imports.
- **D-17: No cache or long-running process.**
  - Measured over 20 runs (median/max): `python3 -S` with `json, shlex, shutil, os, tempfile,
    select` at 16.6/29.0 ms; today's briefing at 19.9/30.6 ms; five `shutil.which` at 0.1 ms.
  - Every entry script copies the `_fail_open` excepthook before any fallible import, with no
    argparse.
  - SPEC R9 is amended to scope the < 1 s budget to the three advisor hooks.
  - The R9 vs R8 contradiction was reported by the analyzer (Confident).
