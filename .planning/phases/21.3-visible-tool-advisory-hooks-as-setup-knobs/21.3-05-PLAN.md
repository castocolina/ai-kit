<objective>
Add the decision-system probe as its own SessionStart hook, then add the two checks that span
hooks: the R9 time budget over the briefing, advisor and reminder, and one forced-exception test
per new entry script; the installed-only test grows to cover the briefing and the reminder (SPEC
R8, R9, Prohibitions; D-16, D-17).

proven fast and silent on failure without repeating per-hook tests (ADV-01, ADV-03, ADV-04).
Output: `tools/hooks/claude_decision_probe.py`, `run_probe` in `precompact_core.py`, one stub
mode, `tests/test_decision_probe.py`, three tests in `tests/test_tool_advisor_core.py`.

Rules binding every task: the plan 21.3-01 rules. Every probe test sets
`AI_KIT_PRECOMPACT_CLIENT` to the stub (the client override the 21.2 core already reads) or a
temp install without a client, so no test reaches the real client or Laya. Timing tests run each
hook as `[sys.executable, "-S", <script>]` on fixtures with a fake PATH and a fresh
`XDG_RUNTIME_DIR`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hook -> decision client | the probe runs a repo script as a subprocess |
| client probe output -> transcript | backend names reach the user and the model |
| host -> every hook | stdin payloads and PATH come from the host process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21.3-06 | Information disclosure | the probe line leaking a key, host or URL credential | high | mitigate | only backend names matching a strict pattern are printed; `host` and `key_source` are never read; `test_probe_tracer_names_laya` asserts no stub host appears; acceptance grep that the script reads no host field |
| T-21.3-07 | Tampering | the probe running an attacker-chosen script | medium | mitigate | the client path comes from the core's realpath (or the explicit test override), argv list, no shell, no PATH lookup for the script; `test_probe_missing_client_gives_empty` |
| T-21.3-12 | Denial of service | a hung probe or a slow hook stalling session start or tool calls | high | mitigate | `run_probe` timeout 3 s (the child is killed), the 5 s entry timeout set in 21.3-06; `test_probe_timeout_gives_empty_within_bound`, `test_advisor_hook_budgets` |
| T-21.3-28 | Denial of service | the advisor, reminder or probe crashing and blocking a tool or session start | high | mitigate | shared `_fail_open` set before the core import in every entry script; `test_forced_exception_gives_empty` |
| T-21.3-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package is installed by this plan; any future install goes through the package-legitimacy gate with a blocking human checkpoint for [ASSUMED]/[SUS] |
