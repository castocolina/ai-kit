<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hook -> decision client | the probe runs a repo script as a subprocess |
| client probe output -> transcript | backend names and hosts reach the user and the model |
| host -> every hook | stdin payloads and PATH come from the host process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21.3-06 | Information disclosure | the probe line leaking a key or URL credential | high | mitigate | only names matching a strict pattern and `host[:port]` from `urlsplit`; `key_source` never read; `test_probe_strips_credentials` |
| T-21.3-07 | Tampering | the probe running an attacker-chosen script | medium | mitigate | the client path comes from the core's realpath (or the explicit test override), argv list, no shell, no PATH lookup for the script; `test_probe_missing_client_gives_empty` |
| T-21.3-12 | Denial of service | a hung probe or a slow PATH stalling session start or tool calls | high | mitigate | `run_probe` timeout 3 s (the child is killed), the 5 s entry timeout set in 21.3-06; `test_probe_timeout_gives_empty_within_bound`, `test_slow_path_still_fast`, `test_advisor_hook_budgets` |
| T-21.3-28 | Denial of service | the reminder or the probe crashing and blocking a tool or session start | high | mitigate | shared `_fail_open` set before the core import in every entry script; `test_forced_exception_gives_empty`, `test_entry_scripts_set_excepthook_first` |
| T-21.3-29 | Elevation of privilege | the briefing, reminder or probe output carrying a permission or rewrite field | high | mitigate | `test_no_hook_output_has_permission_keys` over every Claude hook's real output |
| T-21.3-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package is installed by this plan; any future install goes through the package-legitimacy gate with a blocking human checkpoint for [ASSUMED]/[SUS] |
</threat_model>
