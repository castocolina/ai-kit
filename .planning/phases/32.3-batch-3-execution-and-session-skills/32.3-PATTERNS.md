## Hazards for a haiku executor

- ruff line-length 100, `RUF` and `UP` rules; regex sources as raw strings; a long shape row needs implicit string concatenation, keep each source a single plain literal (the JSON line parse and `ast` check rely on literals).
- pylint limits: `max-args=5`, `max-locals=15`, `max-branches=12`, `max-statements=50`; do not grow `jev_ladder.py` and `scan_text` beyond them; the table is data so it costs nothing.
- pyright basic: `spec.loader` is Optional, assert it as `jev` tests do (`assert spec is not None and spec.loader is not None`).
- docstring and text-history: no phase, plan or decision IDs (D-xx, R1, T-26-xx) in code comments or docstrings (`tests/test_skill_text_history.py`); the existing `reset_parse.py` docstring cites D-xx today, do not copy that style into new text.
- Byte-identical copies: write the canonical file first, then copy with a script, not a hand retype; editing one copy alone fails the guard.
- Same-named module collisions: five `secret_shapes.py` files; in tests load by path under unique names, and in child processes insert only the one folder under test; plain `import secret_shapes` in jev must resolve to its own sibling (insert its own `__file__` dir first).
- `ensure-runner` is the only way to refresh `.planning/scripts/cross-ai.mjs`; `check-dogfood` fails on a hand edit. Re-record `tests/fixtures/cross_ai_selftest_secs.json` only if a shard goes over budget.
- Case rule: shape sources are case-sensitive and flagless; session-wake and runner lose upper-case `SK-` redaction by design (D-05); do not add `re.IGNORECASE` to shapes.
- Staged-tests hook refuses red commits: land the canonical module and `test_secret_shapes.py` together, each caller change with its test, the guard last (wave order D-16); a commit that adds the guard before all copies exist fails. Each task ends with its module plus `tests.test_arch` and `tests.test_skill_text_history`.
- Never write a whole live-looking key literal in source or this file; build with concatenation or repetition.
