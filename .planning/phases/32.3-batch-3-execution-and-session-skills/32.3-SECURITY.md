> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| untrusted text -> scanner | child output, prompts and evidence reach `detect` and `redact` | possible API keys, tokens, private keys |
| scanner result -> logs and reports | callers print a shape-name list or marker text | shape names and markers only |
| goal-prompt render input -> prompt file | a prompt holding a key is refused before it is written | user prompt text |
| ladder item -> client request and answer log | an item field holding a key never reaches a backend or the log | ladder item fields |
| host limit text -> session-wake state | redacted evidence is stored on disk and printed | host error text |
| gh output -> flow reports | redacted gh stdout and stderr reach the terminal and logs | gh output |
| committed eval evidence -> repository | the eval helper's scan gates evidence before commit | eval transcripts |
| child CLI output -> runner relay | redacted before any line reaches the terminal, logs or upstream fields | child stdout and stderr |
| repository -> installed skill copies | hosts receive whole copied skill folders only | skill code |
| test child process -> host | copy-install children never read the real home or the checkout | none |
