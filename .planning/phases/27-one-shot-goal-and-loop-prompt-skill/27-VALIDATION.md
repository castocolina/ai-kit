| **E2E tier module** | `tests.test_ai_kit_spec_goal_prompt_e2e` (real CLI subprocess runs, listed in `E2E_MODULES`) |
| **Estimated runtime** | quick command: seconds; `make test`: several minutes |

## Sampling Rate

- **After every task commit:** the task's own `<automated>` verify (a unit module run, lint, and the gate-scope check).
- **After every plan wave:** `make test-unit` plus `make arch-test`.
- **Before `/gsd-verify-work`:** `make test`, `make validate` and `make e2e-docker` green; skill-judge on `skills/ai-kit-spec-goal-prompt/` (at most three rounds).
- **Max feedback latency:** about 60 s for a module run.
