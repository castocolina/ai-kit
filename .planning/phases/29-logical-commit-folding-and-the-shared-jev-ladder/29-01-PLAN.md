Plans of this phase run in parallel (wave 1 runs five at once), executor worktrees sit under the checkout's `.claude/worktrees/`, and other agents work from their own worktrees, so the leave-nothing-behind check counts only what this plan's own run created (RULE-29: snapshot at the start, compare at the close; anything older or elsewhere is reported, never failed). Every plan writes its own copy of one stdlib-only script, `tmp/p29/NN/scope.py` (NN = the plan number, two digits; `tmp/` is gitignored), with three subcommands, plus `selftest`. The script never kills, stops or removes anything outside its own per-run temp dir.

- `start` (the plan's first step, before any other): `run_id = uuid.uuid4().hex[:8]`, written to `tmp/p29/NN/run_id`; create the per-run temp dir `R = os.path.join(tempfile.gettempdir(), f"ai-kit-p29-run-NN-{run_id}")`; write `tmp/p29/NN/start-<run_id>.json` holding `status` (the lines of `git status --short`) and `procs` (one `"<pid>:<starttime>"` key per numeric `/proc` entry; read `/proc/<pid>/stat`, split `fields = stat[stat.rindex(")") + 2:].split()`, starttime = `fields[19]`, ppid = `int(fields[1])`; an entry that vanishes or cannot be read is skipped); print `start <run_id> <R>`.
- `test` (the plan's one `make test`): `os.makedirs(R, exist_ok=True)` first (a clean `close` removed R, so a repeated `test` recreates it), then `subprocess.run(["make", "test"], env=<a copy of os.environ with TMPDIR=R and AI_KIT_REFUSE_REAL_HOME=1>, check=False)`; exit with its return code. Every tempfile-, mktemp- and node-made temp entry of this run's suite lands in R and nowhere else.
- `close` (the plan's last step, run in the plan's `<verification>` after the plan's last task commit, never inside a task: the executor verifies a task before committing it, so the task's own edits would read as leftovers): `root` = realpath of `git rev-parse --show-toplevel`; `others` = realpaths of every `worktree <path>` line of `git worktree list --porcelain` except `root`; `nested` = the `others` strictly under `root` (for example `.claude/worktrees/*` when this plan runs in the main checkout); a path is in this checkout when it is `root` or under it and not a `nested` worktree or under one. Leftovers (this run) are: (a) each `git status --short` line absent from the start snapshot; (b) each entry in R (a missing R counts as empty, so a second `close` after a clean pass still prints `clean`) except zero-byte files named `uv-*.lock` (uv's own lock file; `make test` under a fresh TMPDIR leaves exactly one, verified 2026-11-04); (c) each process whose `"<pid>:<starttime>"` key is not in the start snapshot, that is neither the script itself nor one of its ancestors (walk ppid up to pid 1), and whose cwd (`os.path.realpath(os.readlink(f"/proc/{pid}/cwd"))`, OSError → skip) is in this checkout or in R. Reported (not this run), never counted: processes from the start snapshot whose cwd is in this checkout, processes whose cwd is not in this checkout but is one of the `others` worktrees or under one, and entries named `ai-kit-p29-*` or `ai-kit-fold-index-*` in `tempfile.gettempdir()` other than R. No leftover: delete R's zero-byte `uv-*.lock` files, `os.rmdir(R)` (a `FileNotFoundError` is ignored), print `clean` as the last line, exit 0. Any leftover: keep R, exit 1. Without `/proc`, print `process check skipped: no /proc` and skip (c).

This is the check that the close logic is not vacuous (a wrong `/proc` field index would otherwise pass every run).
