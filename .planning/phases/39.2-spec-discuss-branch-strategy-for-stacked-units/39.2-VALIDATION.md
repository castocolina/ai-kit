| **Quick run command** | `python3 tools/run_unittest_parallel.py <module> [<module> ...]` (the modules named per requirement below) |

## Sampling Rate

- **After every task commit:** the modules named for the task's requirement (the staged-tests hook also runs covering modules)
- **After every plan wave:** `python3 tools/run_unittest_parallel.py --group unit` and `--group arch`
- **Before `/gsd-verify-work`:** `make test`, `make e2e-docker` and `make check-dogfood` green
- **Max feedback latency:** 120 seconds for a quick run
