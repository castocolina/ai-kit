```python
def _passes_floor(entry: dict, floor: dict) -> bool:
    """Check if a candidate passes the floor constraints (16 D-11). For each (axis, minimum),
    the candidate's raw entry["scores"][axis] must exist (scores must be a dict), pass
    _is_finite_number, and be >= minimum; otherwise False. If floor is empty, returns True."""
    if not floor:
        return True
    scores = entry.get("scores")
    if not isinstance(scores, dict):
        return False
    for axis, minimum in floor.items():
        value = scores.get(axis)
        if not _is_finite_number(value) or value < minimum:
            return False
    return True
```

## Hazards for a haiku executor

1. A `PHASE_FILE_RE` hit needs a capital letter after the first dash; `04-01-PLAN.md` and `15.1-02-SUMMARY.md` evade it, so the guard test passing does NOT prove those two usage-metrics lines are fixed. Fix them by hand and check with `rg -n "\d-\d+-[A-Z]+\.md"` on `skills/ai-kit-usage-metrics`.
2. `detection.py` labels and the `detect_current_runtime` docstring bullets must match exactly after whitespace collapse; change both in one task, then run `tests.test_ai_kit_spec_runtimes_table`.
3. `### MEDIUM            (optional)` style headings silently relabel severities in the parser; use bare headings and put optionality in prose.
4. A finding-shaped bullet under `### Non-blocking notes` flips an Approved report to Issues Found; LOW-only notes are plain `- text`.
5. Any file under `evals/files/` that no eval lists fails the shape test; any `~/` or `/home/x` string fails it too (`design-bad.md:19`, `design-good.md:5`, `sample-review-report.md:8`).
6. Only one new `tests/test_*.py` in the phase, then `python3 tools/gen_test_groups.py`; never hand-edit `Makefile` or `.pre-commit-config.yaml`.
7. The judge drivers are untracked scratch: copy them with a script and `git ls-files`-independent checks; do not edit tracked skill files while a lane runs (digest freezes); all checklist edits are committed before the judge run.
8. Do not edit `references/frameworks/`, the fixer, `fixtures/` or `ai-kit-spec-review/SKILL.md`.
9. Shell: one simple command per call, no `cd`, no heredoc, no `$(...)`, no `sed -i`; scripts under `tmp/`.
