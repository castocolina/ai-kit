## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | stdlib `unittest` through `tools/run_unittest_parallel.py` (one subprocess per module, tripwire PATH, baseline env) |
| **Config file** | runner sets in `tools/run_unittest_parallel.py`; listings generated by `python3 tools/gen_test_groups.py` |
| **Quick run command** | `AI_KIT_REFUSE_REAL_HOME=1 python3 tools/run_unittest_parallel.py tests.test_<module>` (uv modules: `uv run python tools/run_unittest_parallel.py tests.test_<module>`) |
| **Full suite command** | `make test` then `make pyright` (once per plan, at its end) |
| **Estimated runtime** | quick run under 10 seconds per module; `make test` several minutes |

---

## Sampling Rate

- **After every task commit:** Run the quick run command for the modules the task touches
- **After every plan:** Run `make test` and `make pyright` once
- **Before `/gsd-verify-work`:** Full suite green, plus `make check-dogfood` and `bash tests/test_install.sh`
- **Max feedback latency:** 10 seconds per task
