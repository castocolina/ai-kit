<objective>
Harden `tools/install.sh`'s primary git-clone fetch path with an explicit `--single-branch` flag
per REQ-multi-cli-install-single-branch, and pin it with a real automated assertion extending the
existing FAKEGIT test harness. Per 01.2-RESEARCH.md's own critical finding, this change is
**behavior-neutral for fetched refs** — `--depth 1` (already present on this line) implies
`--single-branch` per git's own documentation (git-scm.com/docs/git-clone) unless
`--no-single-branch` is explicitly passed, which this script never does. The value of this change
is explicitness/defensiveness against a future edit silently reintroducing all-branch fetching
(e.g. adding `--no-single-branch` for an unrelated reason, or dropping `--depth 1`), matching this
project's core value of never leaving a load-bearing property undocumented (per D-07: the
installer's shared-folder-plus-per-skill-symlinks pattern is already confirmed correct and is NOT
touched by this plan — only the clone flag).

Purpose: make the installer's single-branch fetch behavior self-documenting and independent of an
unstated git default, without changing what actually gets fetched.
Output: `tools/install.sh`'s clone line carries `--single-branch`; `tests/test_install.sh`
asserts its literal presence on the real command line invoked.
</objective>
