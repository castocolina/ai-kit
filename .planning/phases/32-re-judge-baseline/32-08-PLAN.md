The owner's shell rules, verbatim (pass them word for word to every subagent and executor you start):

- One simple command per shell call: a single program with plain arguments and absolute paths or `git -C <dir>`. Everything more complex goes into a `.sh` or `.py` file under `tmp/`, and the call just runs `bash <file>` or `python3 <file>`.
- Never `cd` into a directory, alone or chained (`cd <dir> && ...`, `cd <dir>; ...`).
- Never use heredocs (`<<EOF`), command substitution (`$(...)`, backticks), subshells (`( ... )`), process substitution (`<(...)`), `eval`, or long chains of `&&`, `||`, `;` or pipes.
- Never use `sed -i` or another in-place editor on a file; use the file-edit tool, or a script.
- Never delete outside `tmp/`, and never use `rm -rf` on a variable path.
- Write files with the file-write tool, not with `echo`/`printf` redirection, except appending one line to a ledger under `tmp/`.
- Pass these rules, word for word, to every subagent and executor you start.

Frozen tree (D-09): from Task 1 step 1 until `lanes.py status` prints `all lanes ended`, never edit, stage or commit a tracked file, never switch branches, never move HEAD, never write outside `tmp/`.
