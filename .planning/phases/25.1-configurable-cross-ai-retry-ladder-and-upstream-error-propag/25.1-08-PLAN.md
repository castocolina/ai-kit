   orchestrator re-renders the live dogfood copy `.planning/scripts/cross-ai.mjs` (25.1-13).

   copy credential files or the owner's real `~/.claude`, `~/.cursor`, `~/.config/opencode`,
   `~/.codex`, `~/.pi`, `~/.gsd` files. Tests use temp dirs and synthetic content; sentinel keys are

   first, then read only the named functions; line numbers here are hints, symbols are
   authoritative.

   the attempt count sets a small `retry` override (for example `max_retries: 1`).

   (`python3 skills/ai-kit-gsd-spec-discuss/scripts/decide.py ladder`, advisory), is checked
   against the evidence and logged in the SUMMARY; never a stop, never a silent skip.

   reset the tree; a claim that a failure is pre-existing is checked against `git stash`-free
   evidence (a run on the parent commit in a temp worktree) before it is written down.
9. Locked decisions D-01..D-24 in 25.1-CONTEXT.md are not re-opened.
