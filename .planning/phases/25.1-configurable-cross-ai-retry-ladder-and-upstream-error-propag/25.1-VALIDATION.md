## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Python `unittest` (stdlib) through `tools/run_unittest_parallel.py`; the runner's own black-box `--self-test` (Node built-ins) |
| **Config file** | `pyproject.toml` (ruff, pylint, pyright, vulture); runner groups in `tools/run_unittest_parallel.py` |
| **Quick run command** | `AIKIT_XAI_SELFTEST_CASES=<case,case> node skills/ai-kit-spec-review/references/cross-ai.mjs --self-test` plus `python3 tools/run_unittest_parallel.py <touched modules>` |
| **Full suite command** | `make test` and `make validate`; clean room `make e2e-docker` |
| **Estimated runtime** | subset seconds; full runner self-test about 120 s; `make test` about 6 min |

---

## Sampling Rate

- **After every task commit:** the task's `AIKIT_XAI_SELFTEST_CASES` subset and the touched Python modules.
- **After every plan wave:** the full runner `--self-test` (template, and the dogfood copy once re-rendered) and `make test-unit`.
- **Before `/gsd-verify-work`:** `make test`, `make validate` and `make e2e-docker` green; the skill-judge loop on every changed SKILL.md; a dogfood re-render (`ensure-runner`) with its self-test.
- **Max feedback latency:** about 60 s for a subset run.
