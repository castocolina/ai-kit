# Phase 25.1 Plan 06: One runtime, its own model grammar, a named tool set Summary

**The runner resolves one runtime per call, checks its model against that runtime's own grammar, and refuses any review argv element outside the runtime's closed allowlist.**

## Accomplishments

- `--runtime` wins over `--prefer`, which now runs only its first entry and prints a notice naming the rest; with no runtime and no prefer the call exits 2.
- Each runtime row carries its own `modelId` (`PI_MODEL_ID` allows only a pi thinking level, `OPENCODE_MODEL_ID` one `#variant`), declared above `RUNTIMES`, and Python pins both sources byte for byte.
- pi's tool flags moved into named `profiles`; `reviewArgvProblem` checks the initial and the resume review argv against the row's allowlist (pi `--skill` only) before any spawn.

## Decisions Made

- The review argv is checked in `main` before the model-list preflight. Checked inside `runCli`, a refused review still spawned the listing fake, so the "before any spawn" requirement would not hold.
- The allowlist's base is the review formula including the selected profile flags. Comparing against a flag-less base reported the profile's own `--tools` as a widening extra.
- `writeCopy` deletes a CONFIG key whose override value is `null`, so `runtime-none` can run a copy that has neither `runtime` nor `prefer`.
