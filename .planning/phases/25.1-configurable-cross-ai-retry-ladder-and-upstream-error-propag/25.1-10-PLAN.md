pin template-8 wording and the `--runtime` hook form that 25.1-09 ships.

Run rules (identical in every 25.1 plan):
1. Every plan carries `cross_ai: true`. `executor: cross-ai` plans run through
   `.planning/scripts/cross-ai.mjs` with full permissions and `AI_KIT_REFUSE_REAL_HOME=1` exported;
   they commit once per task unless a task says otherwise. `executor: orchestrator` plans open with
   a guard line and are never dispatched.
2. Plans that edit the runner template (01-07, 09) run strictly one after another. Only the
   orchestrator re-renders the live dogfood copy `.planning/scripts/cross-ai.mjs` (25.1-13).
3. Never run a real model or a real AI CLI in tests: fake CLIs only. Never read, print, list or
   copy credential files or the owner's real `~/.claude`, `~/.cursor`, `~/.config/opencode`,
   `~/.codex`, `~/.pi`, `~/.gsd` files. Tests use temp dirs and synthetic content; sentinel keys are
   built at run time.
4. The runner file is about 6,300 lines: never read it whole. Run `codegraph explore "<symbols>"`
   first, then read only the named functions; line numbers here are hints, symbols are
   authoritative.
5. Scratch goes under `tmp/p251/<plan>/` and is deleted after the SUMMARY records it.
6. The full runner `--self-test` stays under 180 s (SPEC constraint): a case whose subject is not
   the attempt count sets a small `retry` override (for example `max_retries: 1`).
7. A decision a plan does not settle goes through the jev ladder
   (`python3 skills/ai-kit-gsd-spec-discuss/scripts/decide.py ladder`, advisory), is checked
   against the evidence and logged in the SUMMARY; never a stop, never a silent skip.
8. Never switch harness, provider or model (owner rule). Never `--no-verify`, never stash, never
   reset the tree; a claim that a failure is pre-existing is checked against `git stash`-free
   evidence (a run on the parent commit in a temp worktree) before it is written down.
9. Locked decisions D-01..D-24 in 25.1-CONTEXT.md are not re-opened.

Writing rules for this plan: English only; Agent Skills frontmatter (`name`, `description` at most
1024 characters, trigger-style); the skill does not restate each runtime's flags or model grammar
(the runner owns them, D-19, D-21) and holds the only exit-code table outside the runner. Every
example status or report line is copied from a real runner run against a fake (for example the
`--print-argv` output, or a hermetic self-test case's stderr), never typed from memory. This plan's
SKILL.md goes through the skill-judge loop in 25.1-13; do not mark it judged here.
