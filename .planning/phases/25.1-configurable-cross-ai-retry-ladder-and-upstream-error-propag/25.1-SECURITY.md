## Cross-cutting boundary checks

- **Redaction in every relayed line.** Covered: the live stderr relay (normalize, then redact,
  with the per-run `seen` set), the report line (runner tokens only), the upstream body and
  string fields, and the state file (no upstream text). Repeated copies are replaced in the same
  line and across lines for values of 8 or more characters. CSI-colored keys, `?key=`/`&key=`,
  `password=`/`passwd`, `Basic` and `Bearer` (any case) are covered, verified by probe and
  self-test. Stdout (the answer) is not redacted by design: it is the product, not relayed
  error text. Listing-preflight stderr is never logged.
- **Config and overlay confinement.** Both resolve the file and root real paths and refuse an
  escape. Both check for a regular file (FIFO cases pass) and a size limit (1 MiB config,
  64 KiB overlay) before reading. With HOME unset they use `os.homedir()`, never a path
  relative to the cwd (`pure-retry-user-config-without-home`).
- **Review argv allowlist incl. resume.** Verified (T-25.1-29).
- **Copilot token pass-through.** Tokens pass by name; none is in argv or the logs.
  `COPILOT_ALLOW_ALL` is dropped (T-25.1-15, T-25.1-30).
- **No switch on failure.** One runtime per call (`resolveRuntime` 4418-4444; `--prefer`
  reads its first entry only). The ladder retries the same CLI and model. Cases
  `git-after-quota`, `review-edit-no-fallback` and `prefer-ignored-unknown-entry` pass. The
  superpowers classifier never re-dispatches.
- **Tests and the real home.** Each self-test spawn case gets a fresh `HOME`,
  `XDG_CONFIG_HOME` and `XDG_STATE_HOME` under its temp root (5406-5420), and the pure
  home-fallback case stubs `os.homedir`. One real-home read remains (W4).

## Unregistered flags

None of the 25.1 SUMMARY files has a `## Threat Flags` section. The audit found these:

- **W1 (redaction gaps, residual for T-25.1-07):** a probe shows three shapes reach the
  output unredacted:
  - an OSC-8 hyperlink-wrapped key, because `ANSI_RE` (1507) strips only CSI sequences;
  - `api_key => <value>`, because the `=` matches and the value is cut at `>`;
  - a bare JSON `"key": "<value>"` that does not match an sk, AIza or GitHub shape.

  None of these is a declared shape. Suggested: strip `\x1B\][^\x07]*(\x07|\x1B\\)` in
  `normalizeInput`, and add a JSON-only `"key"` rule.
- **W2 (redaction artifact, no leak):** in `redactSecrets` (1561-1565), a `SECRET_RES` rule with
  no capture group passes the match offset as `prefix`. A mid-line Bearer, Basic, UUID or
  GitHub token therefore becomes `<offset><redacted>` (probe output:
  `Authorization: 15<redacted>`). The secret is removed, but the relayed evidence loses its
  scheme word and gains stray digits. Suggested: check `typeof prefix === 'string'`.
- **W3 (documented shortcut):** values shorter than `SEEN_MIN_CHARS` (8) are redacted on
  their own line only, so a later copy on another line prints in clear. The set stops
  growing at `SEEN_MAX` (256) values (1577-1580).
- **W4 (real-home read in the self-test):** `main` calls `loadOverlay(process.env)` (10107)
  before it dispatches `--self-test` (10108). A self-test run therefore reads the real
  `${XDG_CONFIG_HOME:-~/.config}/ai-kit/cross-ai-errors.json`. The read is read-only and
  confined, and `blackBoxSelfTest` resets the table, so results are unaffected. It is still
  a real-home read and may print `cross-ai: overlay ...` lines.
- **W5 (vacuous assertion):** the state scan in `copilot-token-passthrough` (9895-9901) lists
  only top-level files of `XDG_STATE_HOME`. Records live under
  `ai-kit/spec/cycles/<hash>/` (3251), so the scan can never see one. The case also exits
  `ok`, so no record exists. Other sentinel cases cover the state-file path only indirectly.
- **W6 (info):** a relative `XDG_CONFIG_HOME` is not ignored, as the XDG spec requires
  (`aiKitConfigDir` 2936). Between the realpath check and the read there is a check-then-read
  window (2921-2928). Both are owner-local.
