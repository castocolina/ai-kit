<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| checker output -> LLM agent -> `/agent-md-refactor` | The remediation payload's `summary` strings are ai-kit's own canonical text (from `rules.py`), but the `blocked`/Makefile `recommendation` strings and any research-subagent output cached via `cache-update` are LLM-generated text that gets surfaced to the user and, indirectly, shapes what gets inserted into a target file |
| research subagent -> stack cache -> future invocations | A cache entry written once is reused, unreviewed, by every later `check`/`remediate` call against that stack until it goes stale |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04 | Tampering | stack-research cache poisoning (a bad/malicious tool recommendation gets cached and silently reused) | medium | mitigate | Cache entries are informational tool-NAME recommendations only — `cache-update`/`get_stack_tooling` never execute, install, or shell out to anything they return; a recommendation is always presented inline to a human-in-the-loop before any install/setup-env action is taken, and SKILL.md's Step 4 never instructs auto-running a recommended tool. |
| T-06-05 | Elevation of Privilege | `auto_apply: true` entries invoke `/agent-md-refactor` against the target repo's AGENTS.md without a per-change confirmation gate | medium | accept | Deliberate, user-locked departure from PROJECT.md's "every config write is atomic and explicitly confirmed" Core Value (D-08) — that Core Value is scoped to runtime AI-CLI config files (opencode.jsonc, Codex TOML, Claude JSON), a different artifact class from a git-tracked, human-reviewable, revertible documentation file. D-08 itself is rated `reversible`. |
| T-06-06 | Tampering | Prompt injection: target AGENTS.md content could contain text shaped like an instruction, read by the checker and then, indirectly, by the agent orchestrating `/agent-md-refactor` | high | mitigate | SKILL.md's Step 4 hand-off names, per entry, only `rules.py`'s own canonical `summary` string as the instruction payload to `/agent-md-refactor` — the target file's raw text is used ONLY as classification input (Plan 01's keyword match), never copied into an instruction to another skill/tool. Nothing in the target file can become something `/agent-md-refactor` is told to DO. |
| T-06-07 | Information Disclosure | Inline-only reporting (D-05) vs. a persisted report file | low | accept | Already the design: this skill never writes a findings report into the target repo, closing the leak vector a persisted artifact would otherwise create. |

No package-manager install tasks exist in this plan (no new third-party
dependency is added), so the Package Legitimacy Gate does not apply.
</threat_model>
