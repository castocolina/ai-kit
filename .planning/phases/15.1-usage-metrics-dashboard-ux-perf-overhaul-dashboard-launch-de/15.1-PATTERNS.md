```python
def _parse_ts(value: str | None) -> datetime | None:
    if not value:
        return None
    text = value[:-1] + "+00:00" if value.endswith("Z") else value
    try:
        return datetime.fromisoformat(text)
    except ValueError:

```

**Existing dispatch-by-shape pattern for command extraction** (lines 121-142, `_codex_command`/`_codex_parsed_cmd`) — this is the direct analog for D-19's new `custom_tool_call`/"exec" branch:
```python
def _codex_parsed_cmd(arguments: object) -> str | None:
    if not isinstance(arguments, str):
        return None
    try:
        parsed = json.loads(arguments)
    except json.JSONDecodeError:
        return None
    if not isinstance(parsed, dict):
        return None
    cmd = parsed.get("cmd")
    return cmd if isinstance(cmd, str) else None

def _codex_command(payload: object) -> str | None:
    if not isinstance(payload, dict):
        return None
    inner = payload.get("payload")
    if not isinstance(inner, dict):
        return None
    if inner.get("type") != "function_call" or inner.get("name") != "exec_command":
        return None
    return _codex_parsed_cmd(inner.get("arguments"))
```
The new `custom_tool_call`/"exec" branch (Pitfall 5) is a sibling dispatch, same `isinstance`-guard shape, but the argument JSON is embedded inside a JS-source string, not passed directly — use `json.JSONDecoder().raw_decode(text, idx)` after locating `tools.exec_command(` (see RESEARCH.md's "Don't Hand-Roll" table) rather than a plain `json.loads`.

### `skills/ai-kit-usage-metrics/ai_kit_usage_metrics/family.py` (utility, transform)

**Analog:** itself — `family_of()` is the direct pattern for D-11's new `subfamily_of()`

**Full existing function** (lines 29-58):
```python
_WRAPPERS = frozenset({"sudo", "env", "time", "nice", "ionice"})
_ASSIGNMENT_RE = re.compile(r"^[A-Za-z_][A-Za-z0-9_]*=\S*$")

def family_of(command_text: str) -> str:
    tokens = (command_text or "").split()
    i = 0
    while i < len(tokens):
        tok = tokens[i]
        if _ASSIGNMENT_RE.match(tok):
            i += 1
            continue
        if tok in _WRAPPERS:
            i += 1
            while i < len(tokens) and tokens[i].startswith("-"):
                i += 1
            continue
        break
    token = os.path.basename(tokens[i]) if i < len(tokens) else ""
    return _TOKEN_TO_FAMILY.get(token, token)
```
D-11's `subfamily_of()` reuses `_WRAPPERS`/`_ASSIGNMENT_RE` verbatim and extends the same skip-loop one token deeper (RESEARCH.md's Code Examples section has the full proposed body — same module, same constants, same loop shape, advance past the family token and its own leading flags, then take the next non-flag token).

**Note (A4, RESEARCH.md Assumptions Log):** whether `subfamily_of()` lands here in Python (refine-time, needs a schema column) or is duplicated into `dashboard.py`'s embedded JS pure-function block (render-time, no schema change) is still open per D-11/D-15 cross-reference — plan must make this explicit.
