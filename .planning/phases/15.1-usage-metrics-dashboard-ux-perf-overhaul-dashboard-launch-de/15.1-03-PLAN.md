<objective>
Rebuild the filter bar and the table columns on top of the tracer's proven Material and
virtualizer foundation: add the `runtime` and `subfamily` axes that do not exist today
(D-10 / D-11), reorder both surfaces to the sequence the user asked for (D-12), collapse
the four separate date inputs into one from/to range control (D-13), and make the table
tell the truth about null values instead of rendering them as blank cells (D-16 price,
D-16 date).

Purpose: the price complaint that opened this phase was "price always renders as 0", but
RESEARCH.md's live query proved the dashboard never renders a zero for those rows — it
renders an empty string, because the cell helper maps null to `""`. 37,231 of 84,082 rows
carry a null price and read as blank. Until a null is visually distinct from a real zero,
the same misreading recurs for every future observer.

Output: a filter bar and table that match the ordering decision, carry the two new axes,
express a date range as one control, and mark unknown values as unknown.
</objective>
