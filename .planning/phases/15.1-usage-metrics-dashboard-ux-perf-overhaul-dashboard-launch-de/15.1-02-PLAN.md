`family` computed from opaque script blobs (D-16 family), cursor's 41 NULL dates

backlog items precisely because the gate is the forcing function. Each defect has an

Pitfall 1 warns specifically that one shared "date is populated" fixture silently
leaves a second runtime broken.

tool-call shape that has been in use since 2026-07-27, tells the honest truth about
cursor dates, and a tested `subfamily_of()` that Plan 03's client-side mirror is checked
against for parity.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| raw JSONL records -> refiner | Untrusted, externally-shaped JSON and JavaScript-source strings authored by third-party CLIs cross into this project's parsing code |
| refiner output -> refined.db | Newly-recognised codex rows are written into the existing store |
| operator's own captured raw store -> enumeration step | Two tasks read this pipeline's own output read-only to ground a decision |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15.1-07 | Denial of service | `raw_decode` extraction over an attacker-shaped JS body in `refiner.py` | medium | mitigate | Extraction is a bounded regex match plus one `raw_decode` call on the remainder — no backtracking-prone nested quantifier, no loop over candidate offsets; every failure path returns `None` so a malformed body yields no rows instead of aborting the refine pass, pinned by `test_codex_custom_tool_call_malformed_body_does_not_abort` |
