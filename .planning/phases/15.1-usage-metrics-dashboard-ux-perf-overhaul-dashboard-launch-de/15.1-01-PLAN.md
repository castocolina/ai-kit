through refiner -> refined.db -> dashboard.py generation -> pinned CDN -> virtualized
DOM -> `webbrowser.open` retires that risk on the first commit.

Output: a production-quality end-to-end slice — not a prototype. Every layer this
phase will modify is really wired, with real error handling on the single path.
Plans 02-05 expand horizontally from here.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| raw JSONL / refined.db -> embedded JSON payload | Locally captured command text and model names, never authored by this project, cross into an HTML document |
| embedded JSON payload -> DOM | Row-derived strings become rendered page content |
| browser (file://) -> third-party CDN | The page fetches JS and fonts from jsDelivr / esm.run / Google Fonts at open time |
| generated dashboard.html path -> OS default browser | A local path is handed to `webbrowser.open` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15.1-01 | Tampering | New virtualized row-render path in `dashboard.py`'s embedded script | high | mitigate | Every cell built through the existing `td()` helper's `document.createElement` + `textContent`; the existing `test_no_data_driven_innerhtml_assignment` gate stays unmodified and must keep passing against the new render path |
| T-15.1-02 | Tampering | `_encode_payload` embedded JSON block | high | mitigate | `_encode_payload`'s script-close escaping is left byte-for-byte unchanged and no second inline JSON/script data block is introduced; `test_script_close_escaped_in_embedded_json` stays unmodified |
| T-15.1-03 | Tampering / Spoofing | `@material/web`, `@tanstack/virtual-core`, `chart.js` CDN loads | medium | mitigate | Exact-version URLs only — no unversioned path, no floating tag; version confirmed by the Task 1 blocking-human gate; verified by the pinned-version grep in `<verify>` |
| T-15.1-04 | Tampering | `webbrowser.open` in `cmd_dashboard` | medium | mitigate | Argument is always `"file://" + os.path.abspath(paths.dashboard_html_path(env))` — a path this process just wrote; no row-derived, payload-derived or argv-derived text ever reaches the call |
| T-15.1-05 | Tampering | Raw-store append-only / atomic-write guarantees | medium | mitigate | No `capture_*.py` module is modified in this plan; `refiner.py` reads raw records only; `_atomic_write_text` is reused verbatim and its 0600 default is asserted by the existing `TestPermissions` test |
