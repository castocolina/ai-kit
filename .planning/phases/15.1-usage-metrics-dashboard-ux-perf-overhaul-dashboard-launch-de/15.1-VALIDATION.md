## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Python stdlib `unittest` (no pytest) |
| **Config file** | none — invoked directly by module path via `Makefile`'s `test-unit` target |
| **Quick run command** | `python3 -m unittest tests.test_ai_kit_usage_metrics -v` |
| **Full suite command** | `make test` |
| **Estimated runtime** | ~0.1s (quick), full suite minutes |

JS-side pure-function tests additionally shell out to real `node` via `subprocess.run` inside the same `unittest` test methods (`node v24.18.0` confirmed present) — not a separate framework.

## Sampling Rate

- **After every task commit:** `python3 -m unittest tests.test_ai_kit_usage_metrics -v`

- **Before `/gsd-verify-work`:** `make test` full suite must be green
- **Max feedback latency:** ~30s
