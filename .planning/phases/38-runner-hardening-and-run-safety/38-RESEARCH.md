### 2c. Git form excluding a state home inside the checkout (D-29)
- Form: `git add -A -- . If it matches, the path is ignored. ## Architecture Patterns

### Pattern 1: one pure planner per feature, hooks stay thin
`planIdle(call, config, role)` returns `{idleS, checkS, pollTree, notices}`; `parseTasks`, `coverageOf`, `admissionHits`, `forbiddenHits`, `planFindings` are pure and table-tested with `pure-*` cases; `runChild`/`hostedChild`/`runOnce` only call them. `--print-argv` prints the plan (`cross-ai: idle watchdog off` or `on timeout=<N>s`, D-01).

### Pattern 2: one kill path
Idle end = `finalize('idle')` in `runChild` (:4597) and in `hostedChild` (:4994): SIGTERM, wait, SIGKILL, drain; the result carries `timedOut: true, idle: true`; `runCli` writes `rule=idle-watchdog` at :5814-5815 and the ladder behaves as for an attempt cap. Do not write a second kill routine.

### Pattern 3: single activity callback
Count activity in `runOnce`'s `childOpts` (:5360-5368) for both transports; heartbeat lines the runner prints itself never count; for a hosted lane `readNew` (:4963) feeds the same callbacks, so its truncation (D-30) must not reset or fake the clock (only newly read bytes count, as `pos` resets to 0 after a truncation).

### Pattern 4: lock = `wx` create, rename-to-unique clear
Lock path `<stateHome>/ai-kit/spec/locks/<sha16 root>.json` through a sibling of `cycleFilePath` (:4477) (checkout root = `git rev-parse --show-toplevel`-equivalent via the existing `inGitTree` :5151 walk, else `fs.realpathSync(cwd)`); update with `writeCycleState` (temp + rename; the create itself is `fs.openSync(file, 'wx', 0o600)`). Start time via `procStartTime` (Linux); the non-Linux `ps -o lstart= -p` read is new code with `-` fallback. Release in `finish()` (:1288) and the new `process.on('exit')` backstop beside `exitFlushed`.

### Anti-patterns
- `export function` on runtime functions (breaks `runner_source` extraction and arch scanners); use the one export list.
- A second herdr call site: `herdrCall` stays the one site and `HERDR_VERBS` + `HERDR_VERBS_ALLOWED` + fixture `herdr_verbs` move together.
- Reading herdr screen, agent status or a tab's existence as liveness (D-16): the sweep proves by `run.json` identity plus `tab list` id and complete label.
- Putting a new CONFIG key into runtime code without a default (test copies from `writeCopy` do not have it).
