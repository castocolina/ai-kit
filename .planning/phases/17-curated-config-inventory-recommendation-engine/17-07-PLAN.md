## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| project files and `~/.gsd/defaults.json` → inventory | user-controlled files are read and summarized |
| inventory → stdout | the document may be saved and shared with other agents |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-23 | Tampering | inventory writes | high | mitigate | no write call anywhere in inventory code; a chmod read-only, byte-identical test with fakes and with the real gsd-core |
| T-17-24 | Information disclosure | existing_config / global_defaults | medium | mitigate | top-level allow-lists: only managed-family and conflict keys are copied; a test plants `secret_token` / `brave_api_key` and asserts they are absent |
| T-17-25 | Tampering | malformed config files | low | mitigate | unreadable or non-object JSON is ignored with a warning, never a crash or a partial parse |
