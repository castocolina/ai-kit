`roles.py` contract (pure):
- `TIER_PURPOSE = {"opus": "planning", "sonnet": "general", "haiku": "mechanical"}`;
  `TIER_EFFORT_BAND = {"opus": "heavy", "sonnet": "standard", "haiku": "light"}`;
  `EFFORT_LADDER = ("minimal", "low", "medium", "high", "xhigh", "max", "ultra")` (copy of the
  module-internal `EFFORT_LADDER` in gsd-core 1.16 `bin/lib/model-catalog.cjs` line 134, not
  exported, so node cannot read it).
- `Ceiling(NamedTuple)`: `value: float | None`, `q: float | None`, `families: int`.
  `Pick(NamedTuple)`: `candidate: dict`, `rule: str`, `capped: bool`.
- `effort_token(model)`: split on `-`, drop a trailing `fast`, return the last token when it is
  in `EFFORT_LADDER`, else None (`gpt-5.6-sol-high-fast` -> high, `composer-2.5` -> None,
  `gpt-5.6-sol-none` -> None).
- `clamp_effort(target, modes)`: target when `modes` is empty or contains it; else the nearest
  lower ladder level in `modes`, else the nearest higher, else target.
- `tie_key(c, purpose)`: `(-c["purpose_scores"][purpose], math.inf if c["price"] is None else
  c["price"], c["model"])`. Test `price is None` explicitly, never truthiness: a price of 0 is a
  real price and sorts first.
- `price_ceiling(prices, q)`: None when q is None or no prices; else
  `sorted(prices)[max(0, math.ceil(q * n) - 1)]` (nearest rank).
- `host_ceiling(cands, q) -> Ceiling`: one price per `family` = min `price` over candidates with
  `score_axes > 0`, `fast_twin_of` None, not `is_router`, `price` not None.
- `ceiling_text(c)`: `no ceiling` when `c.q` is None; `no priced family` when `c.value` is
  None; else `<= {value:g}/1M, {int(q*100)}th pct of {families} families`.
- `pick_variant(members, purpose, target) -> tuple[dict, str]`: group by `effort_token`; rule
  `exact` (target present), `nearest lower` (highest ladder index below target), `nearest
  higher` (lowest index above), `bare` (token None); within the chosen group `min(tie_key)`.
  Carries the comment `# shortcut: the family grouping (vendor._MODEL_TIER_SUFFIXES) does not
  strip minimal/ultra, so such ids form their own family; upgrade when a host lists them`.
- `best_pick(cands, purpose, target, ceiling_value, keep=None) -> Pick | None`: pool =
  candidates with `purpose` in `purpose_scores`, `fast_twin_of` None, not `is_router`, and
  `keep(c)` when given; None for an empty pool; one `pick_variant` per `family`; in-cap =
  chosen variants with `ceiling_value` None, price None or `price <= ceiling_value`; best =
  `min(in_cap, key=tie_key)` (capped False), else `min(chosen, key=(price, tie_key))`
  (capped True; every chosen variant is priced here, since an unpriced one is always in-cap).
- `pick_why(pick, purpose, target, ceiling)`: capped -> `no family within ceiling
  ({ceiling_text}); cheapest eligible used`, else `best {purpose} score within ceiling
  ({ceiling_text})`; then `; effort variant {token or 'bare'} of inferred family {family} for
  target {target} ({rule})`;
  then `; price unknown` when the price is None.
- `choice_candidates(cands, purpose, ceiling_value, limit=3) -> list[dict]`: pool = non-fast-twin,
  non-router candidates; when any has `purpose` in `purpose_scores`, those sorted by `tie_key`,
  each `{"model", "runtime", "score": round(score_exact, 1), "price", "why": "<purpose> score"}`;
  otherwise (D-25) priced candidates within the ceiling first then the rest, each part sorted
  by `(price is None, price or 0, model)`, each with `score` None and `why` `no scores; ordered
  by price, not quality` (score_axes 0) or `no <purpose> score; ordered by price, not quality`;
  first `limit` items.
- `agent_tier(agent, gsd_core, profile, shifts)`: `shifts.get(agent_to_phase_type[agent])` or
  `model_profiles[agent][profile]`, None unless in `TIERS`. `used_tiers(gsd_core, profile,
  shifts)`: the distinct tiers over every agent of `model_profiles`, in `TIERS` order.
- `cheap_other_cli(cands, q) -> dict | None` (spec §5 "cheap candidate", I5): `ceiling =
  host_ceiling([c for c in cands if c["is_host"]], q).value`; None when `ceiling` is None;
  else the `min` by `(price, model, runtime)` over candidates with `is_host` False,
  `score_axes > 0`, `fast_twin_of` None, not `is_router`, a non-None `price` and
  `price <= ceiling`; None when that pool is empty.

(medium), haiku `gpt-5.6-luna` (medium); opencode natives are `anthropic/*` ids that opencode does
not enumerate; `RUNTIME_PROFILE_MAP` has no `cursor` key.
