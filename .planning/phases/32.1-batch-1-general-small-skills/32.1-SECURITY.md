## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| consent record and env -> jev client routing | user-owned files and variables decide which remote may receive a question | backend names, consent dates |
| jev client output -> caller | probe and consent JSON reach agents and logs | backend names and source labels only |
| client -> remote API | questions leave the machine only with consent | item text (summary-only) |
| skill text -> agent shell / edits | the usage-metrics lookup block runs in the user's shell; cst-refactor tells an agent how to rewrite code | file paths, user source code |
| user document -> converters | a Markdown file decides which local files a render reads | local image files |
| converter -> HTTP server | md-to-pdf serves `--basedir` over HTTP during the render | files under the served folder |
| script -> source folder | markdown-to-pdf writes the output and, for HTML decks, `<out>-assets/` | rendered PDF/HTML, diagrams |
| PyPI -> dev environment | LibCST enters the dev venv and `uv.lock` | third-party package |
| repo -> judge lanes; lane output -> committed records | read-only review lanes read the tree; verdict JSON enters `.planning/judge/` | skill text, verdicts |
