# Phase 32.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | stdlib `unittest`, one subprocess per module via `tools/run_unittest_parallel.py` |
| **Config file** | none; groups in `tools/run_unittest_parallel.py`, listings generated by `python3 tools/gen_test_groups.py` |
| **Quick run command** | `python3 tools/run_unittest_parallel.py tests.<module> [tests.<module> ...]` |
| **Full suite command** | `make test` (tiers: `make test-unit`, `make test-integration`, `make e2e-test`, `make arch-test`) |
| **Estimated runtime** | quick ~5-30 seconds per module; `make test-unit` ~120 seconds; `make test` ~330 seconds |

---

## Sampling Rate

- **After every task commit:** the module(s) the task touches plus `tests.test_skill_evals_shape tests.test_skill_text_history tests.test_skill_frontmatter`, plus `tests.test_gate_scope` when module membership changed
- **After every plan wave:** `python3 tools/run_unittest_parallel.py --group unit`, `uv run python3 tools/run_unittest_parallel.py --group unit-uv`, `--group arch` when `tests/test_arch.py` changed
- **Before `/gsd-verify-work`:** `make test` must be green
- **Max feedback latency:** 120 seconds
