<decisions>
## Implementation Decisions

### Flags for unverified segments and data differences (SPEC R3, R4, R7)
- **D-01: Flags live in the doctor and the wizard's segment descriptions only; the line gets no new mark.**
  `--doctor --host cursor` adds three statements beside its quota report, in a fixed order: the single billing
  cycle (named from the cycle data: monthly, weekly or unknown, 23 D-09), the inferred quota source (today's
  `_QUOTA_LABEL`), and each segment still unverified on Cursor (`alt_process_memory`, `alt_time_ago`). The
  wizard's Cursor descriptions carry the same words. A segment shows on the line only when its data is real (a
  matched process, an existing transcript), so a mark would label real data as doubtful; `≈` already marks the
  inferred quota.
  - Owner choice (recommended option).

### Process memory on Cursor (SPEC R4)
- **D-02: One ancestor walk in `common_probe`, one matcher per host.** `common_probe` gains a host-neutral
  bounded ancestor walk that takes a match function and returns the matched process's RSS in bytes (Claude's
  calculation: `VmRSS` of the one matched process, `/proc` first, `ps` fallback). Claude's `probe_rss_bytes`
  becomes a call with its `comm == "claude"` matcher, unchanged in behaviour. A Cursor probe module matches
  either the command line containing `cursor-agent` (`/proc/<pid>/cmdline` NUL-joined, decoded with
  replacement; `ps -o command=` off Linux) or the program path `/proc/<pid>/exe` ending in `/node` under a
  `cursor-agent` install directory. Live fact (2026-11-03): name `MainThread`, program
  `~/.local/share/cursor-agent/versions/<v>/node`, command line `~/.local/bin/cursor-agent … index.js`. Cursor's
  `seg_alt_process_memory` lives in `cursor_segments` with the same key, `🧮` and `fmt_bytes`; the inventory
  lists `alt_process_memory` for both hosts. The script's own process is never a match (the walk starts at the
  parent). Arch rules hold: common imports no host family.
  - Own reasoning (owner: self-decisions stand). Not ledgered.

### Configurable extra-spend alert (SPEC R12)
- **D-03: An alert switch and a dollar threshold in the Cursor TOML, edited from the wizard.**
  - Keys: a `[cursor]` table in `cursor-statusline.toml` with `extra_alert = true` and
    `extra_alert_usd = 0.0` (defaults); env overrides `AI_KIT_CURSOR_EXTRA_ALERT` and
    `AI_KIT_CURSOR_EXTRA_ALERT_USD`, bound like the `[git]` knobs (`cfg_bind_scalars`).
  - Plumbing: `ConfigSpec` gains a host scalar-defaults table (data only, so `common_config` names no host) and
    `Config` carries the resolved host knobs; validation is generic by default type (bool, non-negative number);
    an invalid value is a config problem the doctor reports, and the renderer keeps the default.
  - Rule: the alert fires when the switch is on and extra spend, at the two decimals the segment shows, is above
    the threshold. The proof of concept's "included at 100%" condition is dropped: extra spend only accrues past
    the included quota, and the threshold now owns the trigger. Only the amount turns bold red (`RED+bold`); the
    `🪙` icon, the `extra:` label, the sign and the `≈` marker are unchanged.
  - Wizard: the Cursor host pane gets one "Extra-spend alert" row with a toggle and a text box (Textual `Input`,
    the wizard's first text input). The box accepts a plain decimal with up to two places; `-1`, `abc`, an empty
    box, `$5` or `5,00` are refused with a message and nothing is written. A valid change writes both keys in one
    atomic write through `write_toml_preserving`, every other byte kept; an unchanged save writes nothing.
  - Owner direction ("provide a toggle and a text box to set it"), coordinator's reading confirmed; the
    included-100% drop is own reasoning. Not ledgered.

### Quota shape and restored items (SPEC R5, R6)
- **D-04: `_colored` keeps the gap colour and sign gate; the text around it changes.** Wide included:
  `⚡️ inc: <sign><pct>% (↺ <%b %d>, <N>d) ≈`; narrow: `⚡️ inc: <pct>% ≈` (sign only wide, as today); API:
  `⚡️ api: …` without the reset; extra: `🪙 extra: <sign>$<used>/$<ceiling> ≈`, unlimited `🪙 extra: $<used> ≈`,
  disabled `🪙 extra off ≈` (dim). `cursor_reset`, when on: `↺ <%b %d> (<N>d) ≈`. The time of day leaves the reset
  (the owner's target text has none). Days left are `ceil((end - now) / 86400)`, never below 0. Icons go through
  `util_icon` (`⚡` already gets VS16).
  - Own reasoning, from the owner's chosen text. Not ledgered.
- **D-05: Max mode through a neutral field.** `Context` gains `model_max: bool` (default false); only the Cursor
  payload adapter sets it from `model.max_mode is True`; the shared `seg_model` appends ` · max` after the name
  (which already carries ` · <param_summary>`). Claude's payload never sets it.
  - Own reasoning. Not ledgered.

### Shared segments (SPEC R2, R3, R8)
- **D-06: `alt_time_ago` moves to `common_segments`.** `Context` gains a neutral `transcript_path: str`; both
  payload adapters fill it from the payload's `transcript_path`; the modified-time age probe moves to
  `common_probe` (memoized per render); Claude's other transcript probes stay Claude-only. Output `⌛ <age>`;
  hidden for an empty path or a missing file. Inventory description: "Time since the last transcript write";
  `hosts = ["claude", "cursor"]`, the Cursor description saying unverified (D-01).
  - Own reasoning. Not ledgered.
- **D-07: Icons and the width-alone form.** Inventory icons as SPEC R2; `✏` joins `_ICON_VS16`; `seg_path`
  prefixes `📂` on every tier, the pinned floor included; `seg_git_dirty` renders `✏️ ~` / `✏️ ✗` and stays hidden
  when clean; `seg_model` prefixes `🤖`; `seg_alt_term_dimensions` renders `📐 <cols>` when `lines <= 0` and
  `📐 <cols>×<lines>` otherwise, keeping the `?` mark. Claude's expected-output fixtures change on purpose in the
  same commit as the icon change, which names them; the arch mirror test keeps inventory and renderer equal.
  - Own reasoning. Not ledgered.

### Defaults and samples (SPEC R9, R10)
- **D-09: Defaults and Cursor-shaped samples.** `cursor_host.SEGMENTS`: `render_time` and `slowest` on,
  `alt_process_memory` and `alt_time_ago` added off, `cursor_reset` off; the rest unchanged. The inventory gains an
  optional `cursor_sample` key (following `cursor_line`) for shared segments whose Cursor text differs (`model`);
  Cursor-only samples equal their render (`inc: +42% (↺ <date>, <N>d)`, `extra: +$2.50/$20.00` and so on, icons
  and clock parts excluded). `tests/fixtures/sample-input-cursor.json` drops `cost` and `rate_limits`; its keys
  stay within the Cursor payload fields of design §5.1. `core_synthetic_cache` moves to mid-cycle (end 15 days
  out of a 30-day cycle) with an included percent that renders green; the inventory samples follow the same
  numbers.
  - Own reasoning. Not ledgered.

### Live check and sample fallback (SPEC R11)
- **D-08: Live when Cursor is installed, labelled sample data otherwise; never install Cursor.**
  - Detection: the Cursor binary on PATH (`agent` or `cursor-agent`, as `detect_installed_clis` sees it). Logged
    in is shown by a live payload arriving; a login screen is recorded as "not logged in" and the fallback applies.
  - Live path: after the gates pass on the phase branch tip, and before any merge to main, the owner consents at
    that moment to `python3 tools/setup.py install --headless --with-statusline=cursor` from the branch tip; the
    owner opens `agent` in a herdr pane; the agent reads the pane's rendered line, checks the matched process
    through `/proc`, and the owner adds one screenshot. The record goes into `30.2-VERIFICATION.md` and closes
    Phase 23's S7. No copied credentials, no scratch copy of the Cursor config.
  - Fallback: with Cursor absent, the check renders `sample-input-cursor.json` through the real Cursor renderer, as
    the Claude preview does, and labels it "sample data"; the verification records that no live run was possible.
    The wizard's preview renders the sample payload on both hosts, so its title names sample data (coupling with
    30.1 D-12, amended there, needs confirmation).
  - Owner direction ("Do not install Cursor; if available fine, but if not installed show sample data like
    current Claude"). Not ledgered.
