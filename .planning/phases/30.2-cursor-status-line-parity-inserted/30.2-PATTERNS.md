### `tools/common_probe.py` (probe, request-response) + `tools/cursor_probes.py` (new)

**Analog:** `tools/claude_probes.py` `probe_rss_bytes` (lines 48-72). The new host-neutral walk is the

**Ancestor-walk core to generalize** (`tools/claude_probes.py` lines 48-72):
```python
def probe_rss_bytes() -> int | None:
    use_proc = os.path.isdir("/proc")
    comm_of = probe_comm_via_proc if use_proc else probe_comm_via_ps
    ppid_of = probe_ppid_via_proc if use_proc else probe_ppid_via_ps
    rss_kb_of = probe_rss_kb_via_proc if use_proc else probe_rss_kb_via_ps

    pid = os.getppid()                      # walk starts at the PARENT, never self
    for _ in range(8):                      # bounded walk
        name = comm_of(pid)
        if name is None:
            return None
        if os.path.basename(name) == "claude":   # the only match rule today
            kb = rss_kb_of(pid)
            return kb * 1024 if kb is not None else None
        parent = ppid_of(pid)
        if parent is None or parent in (0, pid):
            return None
        pid = parent
    return None
```
Planner note: D-02 turns this into `common_probe.probe_ancestor_rss_bytes(match)` where `match(pid) -> bool`
replaces the `comm == "claude"` test. `probe_rss_bytes` becomes a one-line call with the `claude` matcher.
The Cursor matcher needs `/proc/<pid>/cmdline` and `/proc/<pid>/exe`, which have no reader yet. Add them
beside the existing readers.

**Existing per-pid readers to copy the shape from** (`tools/common_probe.py` lines 193-220):
```python
def probe_comm_via_proc(pid: int) -> str | None:
    """Read process name from /proc/<pid>/comm, or None on error."""
    try:
        with open(f"/proc/{pid}/comm", encoding="utf-8") as f:
            return f.read().strip()
    except OSError:
        return None

def probe_rss_kb_via_proc(pid: int) -> int | None:
    try:
        with open(f"/proc/{pid}/status", encoding="utf-8") as f:
            for line in f:
                if line.startswith("VmRSS:"):
                    return int(line.split()[1])
    except (OSError, IndexError, ValueError):
        return None
    return None
```
Planner note: new readers `probe_cmdline_via_proc(pid)` (NUL-joined, `errors="replace"`) and
`probe_exe_via_proc(pid)` (`os.readlink`) follow this exact try/except-OSError shape. The `ps` fallback is
`probe_ps_field(pid, "command")` (lines 223-231), already present.

**Cursor matcher** (new `tools/cursor_probes.py`): matches `cursor-agent` in cmdline, or exe ending
`/node` under a `cursor-agent` directory. Keep it free of `claude_*` imports (arch rule, `tests/test_arch.py`
2660 test pattern). Live facts from SPEC: name `MainThread`, exe `~/.local/share/cursor-agent/versions/<v>/node`,
cmdline `~/.local/bin/cursor-agent … index.js`. Do not match on `comm`.

**Memo accessor pattern** (`tools/claude_probes.py` lines 283-285, `tools/common_probe.py` 251-262):
