## Goal

memory, `116×0`, borrowed samples) to the look of the approved proof of concept and of Claude's line on
every aspect the hosts share, with each real data difference flagged and the result confirmed in an
owner-attended live Cursor run.

carry; features it did not name were dropped without a decision. Phase 23's live spike S1-S7, including S7 "live
cursor-agent run with the wired status line" (visual, real host), is still `not run (owner)` and

Could we read it from there?" The threshold therefore defaults to that limit; the typed value became an optional override; the rule moved from "above" to "at or above" because Cursor stops extra usage at the limit (enforcement is not instant, so spend can briefly pass it), so "above the limit" would almost never fire.

## Constraints

- Status-line runtime stays stdlib-only; `tests/test_arch.py` host-family rules hold (common modules import neither
  host family; Cursor and Claude modules do not import each other). A shared probe or segment moves into
  `common_*` only when its logic names no host.
- The inventory's `icon`/`line` keep mirroring the renderer (arch test).
- Tests use scratch HOMEs and synthetic payloads only; never the owner's real `~/.cursor` or `~/.claude`.
- Process matching reads only process name, program path, command line and RSS, through `/proc` with the
  existing `ps` fallback.
