> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| other processes' `/proc` entries -> status line | command lines and program paths of ancestor processes are read and matched | process command lines (matched by substring, never printed) |
| payload JSON -> probe | `transcript_path` and `model.max_mode` from the host's stdin | a file path (only its mtime is read) and a boolean |
| hand-edited `cursor-statusline.toml` -> config loader | `[cursor]` values typed by the user | numbers and booleans |
| process env -> config loader | `AI_KIT_CURSOR_EXTRA_ALERT[_USD]` strings | strings coerced to a bool or a non-negative number |
| quota cache JSON -> renderer | numbers and enums from Cursor's undocumented API, normalized by `cursor_quota` | spend and usage figures (inferred, marked with `≈`) |
| resolved config -> renderer | `host_knobs` from TOML/env | typed knobs |
| payload JSON -> renderer | model names, `max_mode`, `render_width_chars` | display strings |
| inventory TOML -> wizard copy | descriptions and samples shown to the user as statements about Cursor's data | fixed wording |
| fixture payloads -> entry script | synthetic Cursor JSON in tests | synthetic data only |
| keyboard input -> wizard text box | the typed alert threshold | a typed amount |
| wizard state -> user config file | the `[cursor]` keys written into `cursor-statusline.toml` | two key lines in a user-owned file |
