## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `unittest` through `tools/run_unittest_parallel.py` (one subprocess per module); Textual pilot for the wizard row |
| **Config file** | runner groups in `tools/run_unittest_parallel.py`; listings regenerated by `python3 tools/gen_test_groups.py` |
| **Quick run command** | `AI_KIT_REFUSE_REAL_HOME=1 python3 tools/run_unittest_parallel.py tests.<module>` (uv/Textual modules: `uv run python` instead of `python3`) |
| **Full suite command** | `make test`, once per plan through the plan's `scope.py test`, plus `make pyright` |
| **Estimated runtime** | a few seconds per module (wizard modules 15 to 30 seconds); no `time.sleep` in tests (patched `time.time`, faked `/proc` readers and `os.getppid`, `await pilot.pause()`) |

---

## Sampling Rate

- **After every task commit:** the module(s) the task owns plus `tests.test_arch`.
- **After every plan wave:** `python3 tools/run_unittest_parallel.py --group unit --group arch`; `uv run` for `unit-uv` and `integration` after the wizard plan.
- **Before `/gsd-verify-work`:** `make test` green, the orchestrator's `uv run` wizard check, and the live Cursor run (or the labelled sample render).
- **Max feedback latency:** about 30 seconds per task.
