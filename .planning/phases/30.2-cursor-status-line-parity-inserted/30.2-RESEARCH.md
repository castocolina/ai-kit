## Summary

Everything the phase needs already exists as a small, well-factored seam: `util_icon` + `_ICON_VS16` for icons,
`common_probe` /proc and `ps` readers for the walk, `cfg_bind_scalars` for scalar knobs, `patch_segments` + 
`write_toml_preserving` for atomic TOML writes, and the inventory TOML for wizard copy. The risk is not design but
five hidden coupling points found by reading the tree (see Pitfalls): (1) `tests/fixtures/statusline_split/audit.md`
pins AST hashes of "reused" definitions and the module each lives in, so every definition this phase changes or
moves breaks `tests.test_arch` until its audit row is flipped to `generalized` / re-homed; (2) `util_char_width`
does not know `✏` (U+270F) so the VS16 fix alone makes the packer under-count by one cell; (3) the D-03 env names do
not follow from the `[git]` pattern (`cfg_env_label` would yield `AI_KIT_CURSOR_CURSOR_EXTRA_ALERT`); (4) with the
D-09 geometry (15 of 30 days) the 42% included gauge is YELLOW, not green; (5) `Makefile` and `.pre-commit-config.yaml`
carry generated module listings, so every new test module touches them.

**Primary recommendation:** 4 plans in 3 waves (foundations, then three disjoint plans, then wizard row + docs), new
test modules created in exactly one plan, the audit.md/test_arch edits owned by one plan per wave, and the wizard
alert row written against 30.1's post-state only after 30.1 lands.

```

   core_cursor_context(raw, config, theme, env)
```

### Alert threshold (D-12)
```python
class ExtraAlert(NamedTuple):
    fires: bool
    threshold: float | None
    source: str            # "off" | "config" | "cursor" | "none"

def core_extra_alert(knobs, quota) -> ExtraAlert:
    knobs = knobs or {}
    if not knobs.get("extra_alert", True):
        return ExtraAlert(False, None, "off")
    override = knobs.get("extra_alert_usd")
    if override is not None:
        threshold, source = float(override), "config"
    elif quota.od_kind == "fixed" and quota.od_ceiling_usd:
        threshold, source = quota.od_ceiling_usd, "cursor"
    else:
        return ExtraAlert(False, None, "none")
    used = round(quota.od_used_usd or 0.0, 2)
    return ExtraAlert(used > 0 and used >= round(threshold, 2), threshold, source)
```
