## Decisions Made

- The walk takes a `match(pid) -> bool | None` callable. `None` from `match` means an unreadable entry and ends the walk; `False` moves to the parent; `True` returns that process's RSS.
- `probe_is_cursor` checks the program path before the command line, so the real agent's `node` wins over a wrapper further up the chain.
- `probe_transcript_ago` uses the memo key `ago`, the same key Claude's `probe_ago` uses. Claude and Cursor never share a context, so the key is safe.
