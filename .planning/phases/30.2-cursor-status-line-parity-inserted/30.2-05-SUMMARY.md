## What was built

- `patch_host_keys(text, table, values)`: surgical patch of `extra_alert` and `extra_alert_usd`; a commented `# [cursor]` header is uncommented in place (as `patch_segments` does); a `None` value comments the live line out and never appends; equal values return the input unchanged.
- `current_host_keys(path, host)`: defaults for a missing file, table or invalid value; `{}` for Claude.
- `cursor_limit_text(env, now)`: reads `<cache base>/cursor/usage.json` through `probe_read_cache` and `core_quota_state` only. Texts: fixed limit with source and age, `unlimited`, `disabled`, and `not read yet`. Creates no directory and never spawns a refresher.
- `save_statusline_config(..., *, host_keys=None)`: applies `patch_host_keys` per table before the single `write_toml_preserving` call. `_persist_layout` passes only the keys that differ from the file and writes nothing when nothing differs.
- Wizard (Cursor pane only): `#alert-row` with `#alert-toggle`, read-only `#alert-limit`, `#alert-usd` (`max_length=10`, `can_focus=False` except after `e`), and `#alert-msg`. `x` flips the toggle; `e` focuses the box; Enter validates (`ALERT_AMOUNT_RE` full ASCII match, finite) and stores or refuses with `ALERT_BAD_INPUT`; Esc restores and leaves the box; a focused box owns every key except Esc. The row is locked with the board when the pane is off.
- Review names a changed alert setting: `<label>: extra-spend alert on|off, threshold $<x.xx> override | your Cursor spend limit (written with its status-line config)`.
- `load_segment_inventory(path, "cursor")` returns `cursor_description` and `cursor_sample` when present; `_SEGMENT_NOTES["alt_time_ago"]` is `time since the last transcript write`.
- `PREVIEW_TITLE = "preview — {host} (real renderer, sample data)"`; the 30.1 pins in `tests/test_wizard_app_2.py`, `tests/test_wizard_pty.py` and the README moved to the new text.
