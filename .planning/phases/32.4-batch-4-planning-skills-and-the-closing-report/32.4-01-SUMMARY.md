## Decisions Made

- `wrap_items` breaks only at item boundaries; a single item or command word longer than a line raises `GuardError` naming the section, as the plan's threat register (T-32.4-02) requires.
- The runner line is built from `command.split(" ")` with a space separator, so each command word stays intact.
- `_check_owner_fields` returns nothing and raises through `_require`, so the CLI's existing `UsageError` path reports the field name and exit code 2.
