### `gp_sections.py` wrap helper (utility, transform)

`fit_line` (lines 141-151) is the signature and docstring style; the wrap helper must not cut (opposite of `fit_line`), and refuses by raising `GuardError`:

```python
def fit_line(
    head: str, variable: str, tail: str = "", prefix: str = RULE_BULLET, cap: int = LINE_CAP
) -> str:
    """`head` + `variable` + `tail` as one line that, with `prefix` in front, fits LINE_CAP. ..."""
    room = cap - len(prefix) - len(head) - len(tail)
    if len(variable) > room:
        variable = variable[: max(room - len(ELLIPSIS), 0)].rstrip() + ELLIPSIS
    return f"{head}{variable}{tail}"
```

`assemble_rails` (478-485): a line starting with three spaces is not bulleted, so continuation lines of a wrap start with exactly three spaces:

```python
body += [line if line.startswith("   ") else f"- {line}" for line in lines]
```

## Shared Patterns

- **Field-name-only errors:** `_require` in `goal_prompt.py:505`; never put a value in a message.
- **One cap authority:** builders only produce lines; `gp_render.check_text` refuses over-cap renders (`GuardError`); do not add length checks in builders.
- **Atomic writes:** `atomic_write_text` / `atomic_write_json` (judge_loop), `write_atomic` (goal-prompt), `_atomic_write_json` (curated-config).
- **Safety for real-gsd tests:** temp HOME, `AI_KIT_REFUSE_REAL_HOME=1`, outer scratch is its own git repo, abort if `config-path` leaves the scratch (RESEARCH section 3).
- **Skill text:** whitespace-flattened substring asserts only; no regex over raw Markdown.
