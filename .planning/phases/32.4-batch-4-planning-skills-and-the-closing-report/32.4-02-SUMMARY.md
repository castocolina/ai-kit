- A `turn_cap` of null: the R3 must-have requires that the STOP IF cap line is removed and the `/goal` tail reads `If it does not hold, stop and report.`; the plan's Task 2 behaviour line calls that tail "absent", which contradicts the must-have. The must-have wording was followed and is what the test asserts.
- `phase_end` steps and a free-text `report_language` wrap through `_words`, so a long value splits between words onto three-space sub-lines and is never cut.
- The E2E list line is built by `_code_chunks`: each command splits into code spans only when it does not fit a line, the inferred suffix follows the last span of its command, and `;` separates commands.
- The render test for the R4 fixture uses `skills_dir=""` in its `CliSeams`, as the plan specifies; the golden scenarios use the stand-in skills directory.
