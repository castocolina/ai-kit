## Accomplishments

- **Task 1 (D-11):** Ported `family.subfamily_of()` (SD-1) into `dashboard.py`'s embedded pure-function block as a literal JavaScript translation — the wrapper set, assignment regex, option-arity table, and plausibility filter are all JS literals matching `family.py`'s constants. `decorateSubfamily(rows)` derives `row.subfamily` exactly once at load, gated on `command_shape === "simple"` so opaque `control_flow_script`/`unclassified` blobs never populate the new axis with garbage (mirrors Plan 02's Python-side family gate). A node-executed parity test asserts THREE things — JS vs the hardcoded `SUBFAMILY_SPEC_CASES` table, Python vs the same table, and JS vs Python — closing the Round-1 review's gap where a JS-vs-Python-only test could pass while both share one wrong rule.
- **Task 2 (D-10/D-12/D-13):** Rebuilt the filter bar in D-12's left-to-right order (runtime, model, family, subfamily, command, date range, tokens min/max, price min/max, group-by-session, clear-filters) using Material Web Components. Fixed `fillSelect` to SD-8's `md-select-option` contract — the previous bare `<option>` markup never rendered inside `md-outlined-select` at all. Replaced the 4 separate date controls (preset/day/start/end) with a single `filter-date-from`/`filter-date-to` range visually merged into one bordered control, removing `filterRows`'s preset branches and the now-caller-less browser-clock helpers (`currentMonthPrefix`, `currentWeekRange`, `pad2`, `ymd`). Added `clearFilters()`/`clearedCriteria()` per SD-9.
- **Task 3 (D-10/D-12/D-16):** Reordered the table header and flat-mode cell-builder in lockstep to runtime, model, family, subfamily, command, exec time, date, tokens_input, tokens_output, price, source_confidence, execution, session (11 → 13 columns). Rebuilt the command cell as a flex row whose `.command-text` child (not the `<td>`) carries the two-line clamp, with an optional `.step-marker` sibling reserving its own 48px so a compound command's step position/count marker can never be pushed out of view by the clamp. Added `priceCellText`/`dateCellText` display helpers so a null price/date renders an em dash (with the locked catalog tooltip on price) while a genuine zero price still renders `0`. The execution-uncertain marker is now an error-tinted "conditional" badge instead of plain parenthesised text.
