## Accomplishments

- `script_artifact` stores `config.runtime` as `targets[0].cli` and keeps the per-CLI maps as the owner's menu; `choices` holds only the runtime, and only when it has no model. An empty target list raises `ValueError`.
- `recommend` marks `workflow.cross_ai_command` `needs_choice` only when the selected runtime has no model.
- `plan_io` validates one runtime (a known runner id, never the plan host), requires it in exactly one of `models` and `choices`, and checks every model id through `runner_model_problem`. Schema 3 plans are refused by the exact schema match.
- `plan-set script:cross-ai.runtime` switches the runtime; the old `script:cross-ai.prefer` key is refused; the 17 goldens regenerated at schema 4.
