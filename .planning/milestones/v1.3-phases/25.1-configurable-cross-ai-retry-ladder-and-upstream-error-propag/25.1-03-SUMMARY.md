# Phase 25.1 Plan 03: Caller Hard Tier Summary

**Both soft-ladder classes now hand the caller one `hard_waits_s[cycle]` wait per cycle (600/900/1800) and end in a persisted `hard-waits`/`cap` stop on route-keyed state files, with a stopped record refusing the lane until it goes stale or the owner deletes it**

## Accomplishments

- `hardWaitFor(cycle, waits, capLeftS)` is the pure hard-tier selector: cycle n waits `waits[n]`, the list's end stops with `hard-waits`, a wait past the cap left stops with `cap`; `runCli` enters it on a spent series, a deadline cut and the cap admission, for transient and quota alike
- The state file name carries the route kind (`<cli>-router|other-<sha16(model)>.json`); every call loads, acts on and deletes only its own file, and the record gains the required `class` plus `stopped`/`stopped_at` on terminal paths
- A stopped record refuses every call on the lane without a model call (exit 69, the stored `stopped=` value, the record's class as status) and logs `cross-ai: state <path>` plus `cross-ai: lane stopped=<v> at <iso>; delete <path> to start a new episode`; the stale rule deletes it and starts a fresh episode
- The report line gains `due_at=` (ISO-8601 UTC with seconds, `-` otherwise) and every state-touching path logs `cross-ai: state <path>` once; the `AIKIT-XAI` line keeps its Phase 25 tail, so `STATUS_HEAD_RE` is untouched
- The expired-cap early return now persists its cap stop (D-09), and the unwritable-state rule holds on every new path: a failed save is a bare exit 75 with the notice, never an untracked hint
- `selftest_s=143` against the 25.1-02 baseline of 137; the full template self-test stays under 180 s and `make test-unit` is green (55/55 + uv)

## Decisions Made

- The route kind lives in the state file name with no ownership check (orchestrator decision 2026-10-25): `runCli` computes `router|other` once from `confirmedRoute(opts.route)` and every path acts on that one file.
- The expired-cap refusal writes its stop record through the same writer (`stopped: 'cap'`, `stopped_at`, null wait fields, every other field kept via spread); a write failure there keeps exit 69 and logs the unwritable notice.
- `caseCycleFile(ctx, cli, model, kind = 'router')` defaults to the router file, so the Phase 25 fixtures keep their lane; the transient cases pass `'other'` explicitly.
