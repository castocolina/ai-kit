## Pattern Assignments

### Runner CONFIG block (`cross-ai.mjs`, config, request-response)

**Analog:** the existing `// <config>` block (lines 62-98). The block is JSON-with-sorted-keys that Python rewrites (`cross_ai_script.py` `_CONFIG_START/_CONFIG_END/_CONFIG_MARKER`), so keep it plain JSON, keys sorted.

```js
// <config>
const CONFIG = {
  "attemptTimeoutS": 0,
  "backoffS": [30, 60],  // (multi-line in file) -> replaced by retry{}
  "capS": 14400,
  "cooldownS": 600,      // -> removed
  "heartbeatS": 30,
  "models": {},
  "newSessionRetries": 3, "sameSessionRetries": 3,  // -> removed
  "outerTimeoutS": 1800,
  "prefer": ["pi","cursor","opencode"],  // -> runtime (D-13 keeps prefer[0] fallback)
  "routerBacked": {},
  "scrubEnv": [ ... ]
};
// </config>
```

Target shape (D-04): `"retry": {"base_s":1,"factor":1.5,"max_retries":5,"session_resets":1,"hard_waits_s":[600,900,1800]}`, `"runtime": ...`, `capS` stays. Tuning never edits CONFIG (an edit makes the copy `edited`).

**Config lookup (R2/D-01)** - generalize, do not copy: `ownTimeout` (1722) and `liveOuterTimeoutS` (1733).


New `workflowValue(cfgPath, key)` replaces the hard-coded key; `ownTimeout` becomes a one-line caller. User file path uses `process.env.XDG_CONFIG_HOME` (already set per case by `hermeticEnv`, 2855-2871).

## Shared Patterns

### Atomic writes and file mode
**Source:** `writeCycleState` (cross-ai.mjs ~1881-1901, tmp + rename) and `cache.cache_write_bytes(write_path, data, mode=cache.umask_file_mode())` in `cross_ai_script.py`. Apply to the stop record and any generator output.

### Status tokens
Space-free `key=value`; the `AIKIT-XAI` line is always last; the new `cross-ai: upstream body=` / `fields=` lines go before it as JSON-encoded values so `parse_status_line`'s whitespace split and last-line rule are untouched (D-16).

### Hermetic tests
Self-test cases use temp repo + `hermeticEnv` (`PATH`=fake bin, `HOME`, `XDG_*`); Python tests use temp dirs and synthetic content, never real CLI config (AGENTS.md).

### Evidence labels
Rows and flags carry `label: verified|unverified` plus an `evidence` source; copilot error rows and cursor/codex body pass-through ship `unverified`.
