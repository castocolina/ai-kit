**The runner retries a transient or router-quota failure through the resolved soft series and one session reset on a shared episode clock, then hands the call to one hard handler without sleeping a hard wait**

- `ladderNext` walks `max_retries` same-session retries, then `session_resets` resets each followed by a full series, and returns `hard/soft-spent` for both soft classes with no cooldown check

## Decisions Made

- A persisted record from a different task no longer pre-spends the same-session retries. The Phase 25 branch that set `ladder.same = limits.same` is dropped: that task starts in a fresh session and gets a full soft series.
- The dirty-tree gate reads the caller's prompt only. The executor preamble names files the plan never listed, so judging the whole prompt would let any edit through.
- A fresh series is judged against the tree at the end of the previous series, snapshotted before the next child runs. Re-reading at decision time races the next attempt's own edits.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] A deadline stop after a real attempt was reported as a timeout**
- **Found during:** Task 2 (quota-deadline-cycle, quota-deadline-near-cap)
- **Issue:** The hard handler left `timedOut` unset, so `main` overrode the quota status with timeout/124, and the no-budget exception matched every first attempt
- **Fix:** The handler returns `timedOut: false`, and the timeout/124 exception is only the first attempt stopped before any retry was admitted
- **Files modified:** skills/ai-kit-spec-review/references/cross-ai.mjs
- **Verification:** `quota-deadline-cycle` exits 75 `stopped=deadline`; `ladder-timeout-no-budget` stays 124
- **Committed in:** `b5cabba` (part of the cut-over commit)

**2. [Rule 1 - Bug] The dirty-tree gate compared the wrong snapshots**
- **Found during:** Task 2 (ladder-dirty-inside, ladder-dirty-outside, ladder-transient-exhausted)
- **Issue:** `changedPaths` was given the head hash instead of the tree hash, the gate re-read the tree at decision time and raced the next edit, and the preamble's `<files>` block authorized every edit
- **Fix:** The gate receives the tree at the end of the previous series and the caller's prompt only, and a later series carries the resume note
- **Files modified:** skills/ai-kit-spec-review/references/cross-ai.mjs
- **Verification:** `ladder-dirty-inside` continues, `ladder-dirty-outside` stops, `ladder-transient-exhausted` shows resume-plus on the second series
- **Committed in:** `b5cabba`

**3. [Rule 2 - Missing] A re-entered task and a different task need different sessions**
- **Found during:** Task 2 (router-quota-second-cycle, router-quota-second-cycle-new-task)
- **Issue:** The task digest hashed the preamble's `<objective>` block, so every prompt looked like the same task, and a no-resume retry sent the resume note instead of the task
- **Fix:** The digest hashes the caller's prompt only, a re-entry repeats the task on the saved session, and a fresh session with nothing to resume gets the prompt itself
- **Files modified:** skills/ai-kit-spec-review/references/cross-ai.mjs
- **Verification:** `router-quota-second-cycle` resumes the saved session; `router-quota-second-cycle-new-task` starts a new one and receives the new prompt
- **Committed in:** `b5cabba`
