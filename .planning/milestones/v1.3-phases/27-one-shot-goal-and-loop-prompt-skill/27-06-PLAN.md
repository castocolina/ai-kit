## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| answers/detect JSON -> generated file | free-text fields (objective, plan titles) flow into a file the user pastes into an agent |
| generator -> repo | the only write is one new file in the chosen goals directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-14 | Tampering | prompt injection through free text | high | mitigate | free-text fields are placed on one line (newlines collapsed), never as section headings or flags; the OpenGSD block is checked for `--` after line 1 |
