Design notes:
- The diff's `from` is the live value read from the resolved config file (absent file -> `{}`),
  so re-running a dry run after a successful apply shows only `keep` (keeps SPEC R13/R15
  idempotency true); the plan's recorded `existing` is not used for the diff.
- Kinds: `set` with no live value -> `add`; `set` equal to live -> `keep`; `set` different ->
  `change`; `unset` with a live value -> `remove`; `unset` with none -> `keep`; `keep` -> `keep`.
- Until 18-18 lands, `apply` without `--dry-run` exits 2 with `apply without --dry-run is not
  available in this build`; 18-18 replaces that branch with the write path.
- Reuse, do not re-implement: dotted lookups go through `presets.get_dotted` (and
  `presets.flatten_config` where a leaf view is needed); the JSON-object reader is
  `plan_io.read_json_object` (promoted in 18-16), so apply imports no private helper.
- The destination binding compares resolved config paths, not project directories: the
  inventory recorded the path `gsd-tools config-path` gave for its project and workstream
  (`inventory.py` `_existing_config`), and the same call under apply's env must give the same
  file.
