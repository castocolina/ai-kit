| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-26-01 | Spoofing | `childEnv` | medium | mitigate | the marker is set after both scrub loops, so a parent value cannot fake its absence (`child-marker-env` runs with parent `0`); it carries no secret, only `1` |

note.

with the orchestrator's own user rights and no elevation.
