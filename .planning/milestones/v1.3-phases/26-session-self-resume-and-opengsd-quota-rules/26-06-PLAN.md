## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host text / hook payload -> `--reset-text` | free text from the host's limit message, possibly from a hook |
| parsed reset -> unit file | a time written into the timer |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-19 | Tampering | unit-file injection through reset text | high | mitigate | only `calendar_line` of a parsed UTC datetime reaches the unit; the raw text never does |
| T-26-20 | Information disclosure | `reset_evidence` | medium | mitigate | the runner's redaction policy ported (secret shapes, quote-aware key/value rules for plain and escaped JSON, copies replaced), plus hex runs; 2000 code-point cap; `TestResetEvidence` sentinels and opaque quoted values per key |
| T-26-41 | Denial of service | a half-written arm or a failed refresh | medium | mitigate | Task 3: a failed first arm disables and removes what it caused, a failed refresh restores the previous fields and unit bytes, both followed by `daemon-reload`; `TestArmRollback` |
| T-26-21 | Denial of service | a far-future or past reset | medium | mitigate | refused outside (now, now + 7 d]; the hourly wake stands, so the wake never idles longer than the bound (D-29) |
| T-26-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package is installed (stdlib `zoneinfo`; no `tzdata`) |

ASVS L1 (`security_asvs_level` 1): reset text and `--reset-at` values are validated by an anchored
grammar and the 7-day bound before any use; secret shapes are redacted before the evidence is
stored, and no environment value enters the state or units; arming runs as the user with no
elevation.
