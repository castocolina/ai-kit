## Pattern Assignments

### `tools/hooks/claude_precompact.py` and `precompact_core.py` (fail-open, entry)

**Analog:** `tools/hooks/claude_session_start.py`

Fail-open excepthook (lines 30-40) and entry (lines 83-125). Copy verbatim, but PreCompact emits nothing the host reads; the compact-SessionStart branch emits the `hookSpecificOutput` envelope (lines 68-80).
```python
def _fail_open(*_exc_info):
    sys.stdout.write("{}")
    sys.stdout.flush()
    os._exit(0)
...
def emit(message):
    if message:
        payload = {"hookSpecificOutput": {"hookEventName": "SessionStart",
                                          "additionalContext": message}}
    else:
        payload = {}
...
def main():
    sys.path.insert(0, os.path.dirname(os.path.realpath(__file__)))
    ...
if __name__ == "__main__":
    sys.excepthook = _fail_open
    raise SystemExit(main())
```
Rules from its docstring: no `argparse`/`SystemExit` beyond `raise SystemExit(main())`; invoked as `python3 -S`, so stdlib only. `_drain_stdin` (lines 43-65) is the bounded-stdin pattern; the new script must instead read the JSON payload (`hook_event_name`, `transcript_path`, `session_id`, `cwd`) with the same bound.

**Subprocess-with-timeout to the client** - analog `skills/jev-fast-decision/scripts/decide.py:285-301` (`call_client`). Copy the closed-set failure mapping (TimeoutExpired -> unavailable, OSError -> not runnable, bad JSON -> bad output), but use `[sys.executable, "-B", client]`, per-call timeout = min(remaining budget, cap) (D-02), a scrubbed env (drop `JEV_*`/`GSD_PATH_JEV*`, set `JEV_BACKEND`, `JEV_CALLER=ai-kit-precompact`). Client contract: `jev_review.py` `main` (line 1256) treats `["--probe"]` as the probe, otherwise screens stdin; always exit 0; `JEV_BACKEND` read at line 714.

**Compact-boundary reader** - copy from `tools/status-line.py:965-998`:

### `tools/setup.py` (registry, wiring, headless flag)

**Constants to extend** (lines 1379-1386): `CLAUDE_HOOK_EVENT`, `CLAUDE_HOOK_MATCHER`, `CLAUDE_HOOK_MARKER = os.path.join("tools","hooks","claude_session_start.py")`. New rows need distinct markers (`claude_precompact.py`) so unwire never removes the briefing entry.

**Wire pattern to generalize to `(settings, event, matcher, script)`** (lines 1514-1563):
```python
ok, data, _ = _load_hook_config(settings, CLAUDE_HOOK_EVENT, nested=True)
...
hooks = data.setdefault("hooks", {})
entries = hooks.setdefault(CLAUDE_HOOK_EVENT, [])
```

Gotcha (D-11): `_load_hook_config` (line 1495) validates ONE event key per call; the grouped writer must validate every event key, then do a single `_atomic_write_json` so PreCompact is never written without its compact-SessionStart injector. `_refresh_or_append_claude_hook` (1514-1527) hardcodes `CLAUDE_HOOK_MATCHER`/`CLAUDE_HOOK_MARKER`: parameterize both.

**Unwire** (lines 1800-1815): filter with `_entry_is_ours_nested(e, MARKER)`, write via `_commit_unwire`. Foreign PreCompact entries survive.

**Symlink rows (pi, opencode)** - `link_one` (1030-1056) / `unlink_one` (1059-1063): never clobber a real file or foreign symlink; `counts` dict keys `linked/relinked/skip_foreign/skip_real/unlinked`. Opencode dir precedence: `tools/config_doctor_checks.py:69-86`.

**Selection** (line 1239): items are `(category, name, enabled)`; add a `hooks` category per D-14, `apply_selection` ignores it, `commit()` (line 2433) routes to wire/unwire.

## Shared Patterns

- **Fail-open**: every hook path exits 0 with parseable output (`claude_session_start.py:30-40`).
- **Stdlib only, `python3 -S`**; ownership of a wired entry = command contains the ai-kit script path.
- **Atomic writes**: `mkstemp` + `os.replace` (`_atomic_write_json`, `tools/setup.py:1410`).
- **Symlink-as-selection**: no state file; links are the persisted choice.
- **Loopback-only client use**: pin `JEV_BACKEND` to the first `remote: false` row from `--probe`; scrub `JEV_ALLOW_REMOTE`.
