## Live facts that changed the plan

- opencode reads `~/.claude/skills`, `~/.agents/skills` and `~/.config/opencode/skills`, and
  duplicate-name handling is undocumented (opencode.ai/docs/skills, 2026-10-18). This is why
  there is no `~/.agents/skills` link.
- pi 1.3.0 reads `${PI_CODING_AGENT_DIR:-~/.pi/agent}/skills` and `~/.agents/skills`, follows
  symlinks, discovers recursively and keeps the first name it finds (installed docs and dist).
  This drives the backup location (D-15).
- `main` is not an ancestor of this branch, and `.planning/docs/` is absent here (D-04).
- Laya `score` was verified live on 2026-10-12 (llm-env `check-server`), against the 2026-10-18
  todo's "unverified" (D-24).
